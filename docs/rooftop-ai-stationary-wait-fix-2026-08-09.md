# 옥상 AI 제자리 맴돌기 수정 (2026-08-09)

## 확인한 문제

- 옥상 신호기에 도착한 AI가 신호기 주변의 두 지점을 `2.4초`마다 왕복하도록 만든 직전 순찰 로직 때문에, 플레이어에게는 목적 없이 제자리에서 맴도는 캐릭터로 보였다.
- 클라이언트는 서버의 이동 의도에 속도가 설정돼 있으면 도착 여부와 무관하게 걷기·상하 흔들림 애니메이션을 유지했다.
- AI 목표 좌표와 플레이어의 신호기 상호작용 좌표가 같아 캐릭터가 동선을 가리거나 서로 가까이 겹칠 수 있었다.

## 수정 내용

- 의미 없는 옥상 왕복 순찰을 제거했다. AI는 담당 신호기로 한 번 이동해 안내 또는 정찰 보고를 마치고, 신호 순서가 바뀔 때까지 대기한다.
- 실제 표시 위치와 목표점의 거리가 도착 반경 안이면 이동 애니메이션을 정지한다. 서버 의도에 이동 속도가 남아 있어도 제자리 걷기와 상하 흔들림이 발생하지 않는다.
- 대기 중인 AI는 신호기 본체 방향을 바라보도록 해 임무를 수행 중이라는 시각적 맥락을 유지한다.
- 세 옥상 신호기에 `aiApproachPosition`을 추가해 AI 대기 위치와 플레이어 상호작용 위치를 분리했다.
- 서버가 옥상 AI 목표를 정할 때 전용 접근 위치를 우선 사용하고, 이전 맵 계약과의 호환을 위해 없을 때만 기존 위치로 대체한다.
- HUD의 삭제된 순찰 상태 문구도 함께 제거했다.

## 검증

- 서버 전체 테스트: `364 passed, 1 skipped`
- 클라이언트 빌드, 린트, 학교 구조 검증 통과
- 맵 계약 테스트에서 각 AI 대기 위치가 플레이어 상호작용 위치와 최소 `1.15m` 떨어지고 신호기에서는 `2.25m` 이내인지 검증
- 실제 게임을 시작한 뒤 두 AI 미니맵 좌표를 약 `2.8초` 간격으로 세 번 측정했고, 두 AI 모두 세 측정값이 완전히 동일한 것을 확인
