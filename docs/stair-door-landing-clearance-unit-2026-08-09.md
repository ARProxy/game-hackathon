# 방화문 앞 계단 층계참 여유 공간 개선 단위

## 문제

- 방화문을 통과한 직후 첫 계단까지 평탄 구간이 약 `0.8m`뿐이었다.
- 열린 문짝의 회전 반경, 플레이어 캡슐, 계단 첫 단차가 한 공간에 겹쳐 문과 계단 사이가 답답하고 끼일 위험이 있었다.

## 변경

- 모든 U자 계단의 문 앞 평탄 진입 구간을 `0.8m → 1.55m`로 확대했다.
- 상부 층계참 깊이를 `1.4m → 1.84m`로 확대했다.
- 계단 비행부를 문에서 더 안쪽으로 옮기고 중간참·난간·충돌 램프를 같은 좌표 계약으로 재배치했다.
- 북서·남동 계단의 AI/동료 표시 이동 경로에 평탄 구간과 램프 시작·종료점을 추가해 허공을 가로지르지 않게 했다.
- 옥상 방화문부터 3층 방화문까지 12cm 간격으로 바닥 지지 구조가 끊기지 않는지 자동 검증한다.

## 검증

- `npm run export:collision`
- `npm run verify:campus`
- `npm run lint`
- `npm run build`
- 서버 전체 테스트 `386 passed`
