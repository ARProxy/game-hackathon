# AI 동료 경로 탐색·역할 판단 개선 작업 기록

> 작업일: 2026-08-09  
> 작업 단위: AI 동료의 목표 도달, 역할 분리, 판단 가시화  
> 상태: 구현·자동 검증 완료

## 사용자 관찰

- 이동 자체는 부드러워졌지만 AI 동료는 목적을 이해하지 못하는 것처럼 보인다.
- 동료가 방 안의 미션 장치로 가지 못하거나 두 명이 같은 위치에 몰린다.
- 화면에는 동료 1명의 추상 상태만 보여 두 동료가 왜 이동하는지 확인할 수 없다.

## 재현과 원인

1. 최신 학교 계약에는 층별 복도 내비게이션 노드가 있지만 서버 이동은 이를 전혀 사용하지 않는다.
2. 현재 AI는 목표 직선이 벽에 막히면 충돌 벽의 한 축으로만 이동한다. 문 위치를 기억하지 않아 같은 벽 끝에서 정체될 수 있다.
3. 반복 이동 시뮬레이션에서 2층 인터폰 A/B는 목표 8~10m 전, 1층 장치 A/B는 4~20m 전에 멈췄다.
4. 내비게이션 그래프는 복도 링만 있고 교실·미션 방의 문 포털이 없어 장치까지 완전한 경로가 아니다.
5. 3층·2층·1층에서 두 번째 동료의 전용 역할이 없어 첫 번째 동료나 플레이어의 목표로 겹쳐 이동한다.
6. 중정 벽이 중정 경계를 넘어 순환 복도의 네 코너를 막고 있었다.
7. 서버 충돌 export가 문 위 2.2m 높이의 인방까지 평면 벽으로 내려 모든 문 개구부를 차단했다.

## 구현 결정

- 학교의 실제 문 개구부 양쪽에 내비게이션 포털을 생성하고 복도 링과 연결한다.
- 중정 벽은 실제 중정 경계까지만 배치해 ㅁ자 순환 복도의 네 코너를 연다.
- 서버 평면 충돌은 actor 높이 아래의 벽만 내보내 문 인방과 계단 상부 난간을 바닥 벽으로 오인하지 않는다.
- 서버는 시작점과 목표점에서 보이는 노드들을 그래프에 연결해 최단 경로의 다음 waypoint를 선택한다.
- AI의 한 틱 이동은 최종 목표가 아니라 선택된 waypoint를 향하되, 기존 서버 벽 판정을 마지막 안전장치로 유지한다.
- 3층·2층·1층에서 `미션 지원`과 `다음 경로 정찰` 역할을 분리한다.
- 인터폰 담당 AI는 플레이어가 장치를 시작하기 전 미리 위치를 잡되, 시작 전에는 기호를 읽거나 목표를 소모하지 않는다.
- HUD는 두 동료의 현재 역할과 판단 이유를 각각 표시한다.

## 완료 조건

- 2층 인터폰과 1층 장치까지 AI가 벽을 통과하지 않고 도착한다.
- 가까운 직선 경로는 바로 이동하고, 장거리 실내 이동은 복도 그래프를 따른다.
- 잠긴 문은 내비게이션 포털을 만들지 않는다.
- 층별로 두 동료가 서로 다른 목표를 고른다.
- 동료의 위치 스냅샷 보간과 금기어 회피 계약은 유지된다.
- 내비게이션·AI 단위 테스트, 맵 계약, 전체 회귀 테스트가 통과한다.

## 기획 교차 감사

- 기획 2: AI의 `선택 → 이유 → 행동 → 재평가`가 월드 좌표와 UI 모두에서 관찰 가능해진다.
- 기획 3·4: AI 역시 플레이어와 동일한 최신 ㅁ자 학교 벽·문 계약을 사용한다.
- 기획 5: AI 역할 보고는 기존 금기어 회피와 서버 발화 검사 경로를 유지한다.

## 검증

- 내비게이션 노드 `32 → 84`: 순환 복도와 잠기지 않은 문 양면 포털 연결
- 서버 평면 장벽 `826 → 679`: 문 인방 등 actor보다 높은 조각 제외
- 내비게이션 84개 노드의 모든 link가 실제 서버 벽을 통과하지 않음을 검증
- 2층 인터폰 A/B, 1층 장치 A/B가 16~43 시뮬레이션 틱 안에 도달
- AI 경로·역할 선별 테스트 `89 passed`
- 서버 전체 테스트 `316 passed, 1 skipped`
- 클라이언트 프로덕션 빌드 통과
- 클라이언트 린트 오류 0개(기존 경고 유지)
- compact school 계약 검증 통과
