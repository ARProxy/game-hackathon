# Claude Design 시각 QA

2026-08-08 기준 ZIP 원본과 실제 게임 WebGL 렌더를 비교한 기록이다. 자동 캡처는 1440×900 Headless Chrome WebGL 환경에서 테스트 타이틀을 클릭해 서버 게임에 진입한 뒤 수행했다. 캡처 이미지는 제출 코드에 포함하지 않고 임시 QA 산출물로만 사용했다.

## 확인한 원본 구도

- `screenshots/school-finish.png`: 중정, 순환 복도, 계단, 다층 외벽 전경
- `screenshots/hall-check.png`: 1층 승객용 엘리베이터와 승강장 조명
- `shots/03-ev3.png`: 승강기 문틀 안쪽에서 바라본 복도

## 현재 게임 캡처 결과

### 3인칭 플레이

- 1440×900 WebGL 캔버스가 정상 생성되고 최신 학교 형상이 렌더됐다.
- 플레이어 손전등은 전방 벽과 바닥을 실제로 밝힌다.
- 옥상과 상층 통로는 원본 자유 시점보다 시야가 좁고 간접광이 약하다.
- 가까운 벽 뒤에서 카메라 충돌이 작동할 때 캐릭터가 화면 높이의 약 1/3을 차지한다.
- 공간 누락보다는 플레이 카메라·현재 위치·야간 조명의 차이가 첫인상 차이를 크게 만든다.

### CCTV 전경

- 최신 ㄷ자 본관, 중앙 운동장·중정, 옥상 난간, 계단 코어가 확인됐다.
- 구형 맵이 대신 렌더되는 현상은 재현되지 않았다.
- CCTV 보정광에서는 건물과 운동장 경계, 창, 순환 동선이 구분된다.
- 실제 플레이의 어두움은 형상 누락이 아니라 3D 야간 렌더 조건에 집중돼 있다.

## QA 중 발견해 수정한 문제

옥상 미션 완료 직후 서버는 F3에 술래를 공개한다. 기존 클라이언트는 행위자 종류와 무관하게 모든 `actor_floor_changed`를 “F3 구역으로 이동했습니다”라고 표시해 플레이어가 자동 이동한 것처럼 오해하게 했다. 이제 내 이동은 기존 문구, 술래 이동은 출현 경고, AI 이동은 동료 이동 자막으로 분리한다.

## 남은 구도 검증

- 플레이어를 엘리베이터 승강장으로 이동해 원본 `hall-check.png`와 근접 비교
- 카 내부 탑승 상태에서 원본 COP·거울·문틀 구도 비교
- 교실 내부에서 책상·칠판·조명 비율 비교
- 좁은 복도에서 카메라 최소 거리와 캐릭터 점유율 조정 여부 결정
