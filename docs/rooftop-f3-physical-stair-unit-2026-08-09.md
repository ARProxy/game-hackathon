# 옥상–3층 실제 계단 보행 단위

## 문제

옥상 신호 미션 완료 뒤 방화문 앞에서 `E`를 누르면 플레이어가 즉시 3층으로 순간 이동했다. 이미 제작된 북서 스위치백 계단과 방화문이 있는데도 플레이 경험은 로딩 포인트처럼 느껴졌고, 옥상 탈출의 공간적 긴장감도 사라졌다.

## 결정

- 옥상↔3층의 기존 `use_floor_transition` 텔레포트 경로를 제거했다.
- 플레이어는 `roof_to_f3` 방화문을 통과해 두 개의 실제 경사 계단과 중간참을 직접 걷는다.
- 서버 층 권위는 계단 중간이 아니라 물리 동선 끝에서만 바뀐다.
  - 하강: `[-38.35, 7.2, -40.8]`에서 `ROOF → F3`
  - 상승: `[-33.65, 10.8, -40.34]`에서 `F3 → ROOF`
- UI는 `E · 구역 이동` 대신 “방화문을 열고 계단을 직접 내려가세요”라는 동선 안내만 표시한다.
- 마지막 생존 도망자가 하강한 순간 기존 규칙대로 옥상이 폐쇄되며, 이후 상승 요청은 서버가 거부한다.

## 서버 권위와 악용 방지

- 계단 경계 요청은 `floor_3` 단계, 생존 도망자, 열린 두 층, 올바른 출발 층을 모두 검사한다.
- 요청 좌표는 작성된 경계에서 1.4m 이내여야 한다.
- 클라이언트는 실제 캐릭터 발 높이와 XZ가 경계를 통과했을 때 한 번만 요청한다.
- 층 변경 이벤트의 좌표는 현재 물리 경계와 같아서 화면상 공간 점프가 생기지 않는다.

## 검증 범위

- 옥상 하강과 3층 상승의 양방향 권위 전환
- 원격 요청, 잘못된 출발 층, 폐쇄된 옥상 복귀 거부
- 마지막 도망자 하강 후 옥상 폐쇄
- 전체 자동 플레이의 옥상→3층 구간을 실제 계단 경계 계약으로 교체
- AI 맵 도달성 회귀도 3층을 일반 전이 슬롯으로 가정하지 않고 실제 상·하단 경계를 검사
