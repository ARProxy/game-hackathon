# 술래 공포 비주얼 재설계 작업 기록

> 작업일: 2026-08-09  
> 작업 단위: 3층부터 등장하는 주 추격자 외형·보행·시선 연출  
> 상태: 구현·클라이언트 검증 완료

## 문제

- 기존 주 추격자는 1.7m 캐릭터 규격 안의 둥근 캡슐 조합이라 도망자와 실루엣 차이가 약했다.
- 얼굴 표정과 시선이 없어 가까워져도 공포보다 임시 저폴리 캐릭터처럼 보였다.
- 술래 이동 모델에 보행 강도가 전달되지 않아 실제 추격 중에도 팔다리 움직임이 거의 없었다.

## 방향

특정 인터넷 밈이나 기존 괴물을 복제하지 않고, 오래된 Source 계열 공포 모드에서 느껴지는 다음 특성만 재해석했다.

- 현실적인 얼굴과 불가능한 신체 비율의 충돌
- 지나치게 긴 팔과 좁은 몸통
- 낮은 해상도의 오염된 재질감
- 몸의 방향과 무관하게 플레이어를 응시하는 얼굴
- 매끄러운 생물 애니메이션 대신 간헐적으로 꺾이는 움직임

## 구현

- `imagegen` 내장 도구로 원본 공포 얼굴을 생성하고 크로마키 제거·알파 검증 후 `seeker-face-v1.png`로 저장했다.
- 생성 자산은 640×640 RGBA, 투명 모서리와 완전 불투명 얼굴 영역을 모두 검증했다.
- 주 추격자의 이름과 실루엣을 `우는 껍질`로 재설계했다.
- 키 약 2.8m의 마른 몸통, 긴 팔, 비대칭 등, 갈비뼈, 붉은 흉부 발광과 바닥 그림자를 추가했다.
- 공포 얼굴을 카메라를 계속 향하는 스프라이트로 결합해 몸이 복도에서 꺾여도 시선은 플레이어에게 남는다.
- 서버 의도 이동량을 캐릭터 보행 애니메이션에 연결하고, 정지·이동 모두에 작은 경련과 비대칭 기울기를 적용했다.

## 검증

- 클라이언트 TypeScript 프로덕션 빌드 통과
- 린트 오류 0개(기존 Fast Refresh·레거시 승강기 경고 유지)
- PNG 모드 `RGBA`, 크기 `640×640`, 알파 범위 `0..255`, 모서리 알파 `0`

## 생성 프롬프트 요약

원본 캐릭터나 밈을 모사하지 않는 정면형 언캐니 괴물 얼굴, 창백하고 갈라진 가면 피부, 흐린 작은 눈, 비정상적으로 늘어난 검은 입, 낡은 게임 텍스처 감각, 녹색 크로마키 배경, 고어·텍스트·워터마크 제외.
