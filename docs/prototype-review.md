# 프로토타입 리뷰 — 현재 문제와 방향

> 작성일: 2026-08-03
> 상태: Phase 4 완료 후 전체 리뷰
> 목적: 프로토타입의 근본적 문제를 정리하고, 남은 기간 동안의 개선 방향을 결정

---

## 현재 프로토타입이 증명한 것

기술 파이프라인이 동작한다:
- 음성 입력 → 금기어 판정 → 빙결 → 술래 추격 → AI 동료 구조
- 온보딩 → 금기어 채집 → 미션 → 주문 → 정산

**하지만 "게임으로서의 재미"는 아직 없다.**

---

## 문제 1: 맵이 너무 좁고 다 보인다

### 현상
- 25x25 맵에 zoom 30이면 맵의 절반이 한 화면에 보임
- 술래가 어디 있는지, 프롭이 어디 있는지 전부 노출
- "숨바꼭질"이 아니라 "체스" — 정보가 완전 공개된 게임

### 방향
- **맵 크기 확대**: 최소 50x50 이상. 구역 간 이동에 시간이 걸려야 경로 선택이 의미 있음
- **시야 극단 축소**: 플레이어 주변 3~4m만 보이게. 나머지는 완전한 어둠
- **카메라 클로즈업**: zoom을 올려서 캐릭터 중심 시점. 맵 전체가 절대 보이면 안 됨
- **소리가 핵심 정보가 됨**: 보이지 않는 공간의 정보는 소리로만 전달

### 확장 — AI 기반 맵 생성
- 온보딩 대화에서 추출한 키워드로 맵의 테마, 구조물, 분위기를 AI가 설계
- "바다 좋아해요" → 해변 테마 맵, 등대, 모래성 구조물
- "학교" → 교실, 복도, 운동장 변형
- 매 판마다 대화에 따라 다른 맵 → "내 말이 세계를 만든다"
- 이건 단순히 금기어만 바뀌는 것을 넘어서, 맵 자체가 개인화되는 경험

## 문제 2: 술래가 멍청하다

### 현상
- 웨이포인트를 도는 순찰봇
- 패턴을 외우면 완전 회피 가능
- 빙결 핑에만 반응 — 그 외에는 무해한 존재

### 방향
- **청각 반응**: 플레이어가 PTT로 말하면 음량/거리에 따라 술래가 해당 방향으로 이동. "말해야 미션이 진행되는데 말하면 술래가 온다" — 이게 이 게임의 핵심 딜레마
- **탐색 AI**: 마지막으로 플레이어를 본/들은 위치를 기억하고 주변 집중 수색. 시간이 지나면 탐색 범위 확대
- **예측 불가능성**: 가끔 순찰 패턴을 깨고 랜덤 구역 이동. "이 구역은 안전해"라는 확신을 불가능하게
- **도발**: "여기 있는 거 알아..." 같은 방향성 있는 대사로 공포 연출
- **시야 기반 감지**: 술래도 시야가 있어서, 플레이어가 시야에 들어오면 추격 시작

## 문제 3: AI 동료가 그림자다

### 현상
- 플레이어 주위를 공전하며 따라다님
- 빙결 시 달려와서 자동 구조 — 이게 전부
- "자동 구조 아이템"이지 "동료"가 아님

### 방향
- **자율적 탐색**: 동료가 스스로 다른 구역에 가서 프롭을 찾음. "나 B구역 가볼게!"
- **정보 전달**: 프롭 발견 시 "여기 뭔가 있어! 와봐!" — 플레이어가 가서 함께 조사
- **협동 미션**: T2(동시 조작)처럼 동료와 타이밍을 맞춰야 하는 미션. 금기어를 피하면서 소통해야 하는 긴장
- **동료도 위험에 처함**: AI 동료도 술래에게 잡힐 수 있음. 동료가 잡히면 플레이어 혼자 남는 공포
- **동료에게 음성 지시**: "왼쪽으로 가" 대신 "미끄럼틀 쪽으로 가줘" — 우회 표현으로 소통하는 게 이 게임의 핵심 재미

## 문제 4: 온보딩이 재미없다

### 현상
- "주말에 뭐 해요?" — 면접 질문
- 고정 질문 3개 → 예측 가능, 조작 가능
- "이게 금기어가 될 줄 몰랐는데!"라는 반전이 약함

### 방향
- **연상 게임**: 맵의 장소/사물 이미지를 보여주고 "떠오르는 단어를 말해주세요"
- **이야기 만들기**: "이 장면에서 무슨 일이 벌어지고 있을까요?" — 긴 발화에서 다양한 명사 추출
- **빠른 연상**: 색, 사물, 장소가 빠르게 지나가고 "보이는 대로 말해주세요!" — 시간 제한으로 무의식 유도
- **게임적 속임수**: 진짜 목적(금기어 채집)을 숨기고 다른 목적인 척 포장
- 핵심: 플레이어가 **자연스럽게 많이 말하게** 만들고, **나중에 "내가 한 말이 금기어가 됐다"는 반전**이 재미

## 문제 5: 콘텐츠 볼륨 부족

### 현상
- T1 미션 3개 = 2~3분이면 끝
- 기획서의 목표 플레이 타임(15분)에 한참 못 미침
- 멀티플레이(3~5명) 미구현

### 방향
- 미션 타입 다양화: T1(수집) x3, T2(동시 조작), T3(정보 전달) 조합
- 금기어 3개 → 미션 5~6개로 확장. 금기어 하나에 2개 미션 가능
- **중간 이벤트**: 금기어 교체, 술래 강화, 시야 축소 등 라운드 중 변화
- **정보 비대칭**: 멀티에서 플레이어마다 다른 금기어. 내 금기어를 상대는 모름
- 15분 구성: 온보딩 2분 + 미션 5~6개 10분 + 최종 주문 + 탈출 2~3분

## 문제 6: 디자인 퀄리티

### 현상
- 프리미티브 조합 → 최소한의 형태만 구분 가능
- 색 차이가 미세해서 구역 구분 어려움
- 연출(빙결, 구조, 추격)이 약함

### 방향
- 빙결 연출 강화: 화면 전체 서리 오버레이, 얼음 파티클, 사운드
- 술래 접근 시 비네트 + 심장박동 사운드
- 구역마다 특징적인 조명 색 (놀이기구=따뜻한, 창고=차가운)
- 캐릭터 감정 표현: 크기 변화, 색 변화, 이펙트로
- UI 폴리시: 폰트, 전환 애니메이션, 사운드 피드백

## 우선순위 정리

사전과제 마감(8/10)까지 남은 6일간 집중해야 할 순서:

| 순위 | 항목 | 근거 |
|------|------|------|
| 1 | 시야 축소 + 카메라 클로즈업 | 가장 적은 공수로 가장 큰 체감 변화. 맵 크기를 안 키워도 효과 있음 |
| 2 | 술래 청각 반응 | "말하면 위험하다" = 게임의 핵심 딜레마. 이게 없으면 금기어 시스템의 의미가 반감 |
| 3 | 맵 확대 + 구역 밀도 | 시야를 줄였으면 맵이 넓어야 탐색감이 살아남 |
| 4 | 온보딩 재설계 | 시연 영상의 첫 인상. "면접"이 아닌 "게임의 시작"이어야 함 |
| 5 | AI 동료 자율성 | 심사에서 "AI 활용의 깊이"를 보여주는 핵심. 하지만 구현 공수가 큼 |
| 6 | 사운드 + 연출 | 체감 품질을 올리지만, 코어 루프가 먼저 |
| 7 | AI 맵 생성 | 가장 임팩트 있는 차별점이지만 공수도 가장 큼. 본선용 |
| 8 | 멀티플레이 | Room 구조 준비됨. 여유 있으면 LAN 멀티까지 |

## 사전과제 vs 본선 구분

### 사전과제에서 보여줄 것 (8/10까지)
- 시야 제한된 어둠 속에서의 긴장감
- 말하면 술래가 오는 핵심 딜레마
- 한 판 완주 가능한 폴리시된 경험
- 시연 영상에서 "이 게임 하고 싶다" 느낌

### 본선에서 확장할 것 (48시간)
- AI 기반 맵 생성
- 멀티플레이 (인간 2~3명 + AI)
- 정보 비대칭 금기어
- AI 동료 음성 지시 (우회 표현 이해)
- 풍부한 미션 타입과 콘텐츠 볼륨
