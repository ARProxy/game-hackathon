# 옥상 기억 신호 탈취 미션 재설계 단위

## 문제

기존 옥상 미션은 중앙 콘솔에서 플레이어가 한 번 상호작용하면 AI 동료가 동쪽과 서쪽 콘솔을 정해진 순서대로 자동 조작했다. 플레이어에게 필요한 판단은 없었고, 실제 플레이는 E 한 번과 대기로 끝났다.

## 새 핵심 경험

옥상 시작 시 세 중계기가 한 번씩 강하게 점멸한다. 플레이어는 위치 순서를 기억한 뒤 안내가 사라진 옥상을 직접 횡단하며 같은 순서로 세 콘솔을 입력해야 한다.

## 진행 흐름

1. 라운드 시드로 중앙·동쪽·서쪽 중계기 순서를 무작위 섞는다.
2. 각 중계기에 6.2m 높이의 신호 기둥과 순서 번호를 1.4초씩 차례로 표시한다.
3. 전체 점멸이 끝나면 정답 위치와 다음 신호 안내를 숨긴다.
4. 미니맵에는 미입력 중계기 세 곳만 표시하고 순서는 노출하지 않는다.
5. 플레이어가 중계기 근처에 도착하면 E 입력 안내가 나타난다.
6. 서버가 실제 플레이어 좌표와 기억 순서를 함께 검증한다.
7. 세 입력을 모두 마쳐야 북서 계단실 방화문이 열린다.

## AI 동료 역할

- 동료 1은 동쪽, 동료 2는 서쪽 중계기로 독립 이동한다.
- 도착하면 해당 위치를 확보했다는 보고를 한 번만 보낸다.
- 동료는 콘솔을 대신 입력하거나 미션을 자동 완료하지 않는다.
- 따라서 동료는 장식이나 자동 해결사가 아니라 옥상 양쪽을 먼저 읽어 주는 현장 관측자가 된다.

## UI 변경

- 미션명: `옥상 · 기억 신호 탈취`
- 목표 설명에서 AI 자동 동기화 문구를 제거했다.
- 진행 표시가 정답을 노출하지 않고 `다음: 기억한 위치`로 표시된다.
- 월드 비콘은 점멸 중에만 금색 기둥과 순서 번호를 보여 준다.
- 점멸 후에는 플레이어가 실제로 접근한 콘솔에만 입력 안내가 나타난다.
- 미니맵은 미입력 콘솔의 위치만 보여 주고 정답 순서는 숨긴다.

## 서버 권한과 회귀 방지

- 동일 시드는 동일 순서를 만들고, 서로 다른 시드 집합은 여러 순열을 생성한다.
- 공개 상태는 최초 점멸 연출을 위한 순서를 포함하지만 HUD와 미니맵은 점멸 종료 뒤 이를 정답 화살표로 사용하지 않는다.
- AI 도착 보고는 메모리에 기록되어 한 번만 발생한다.
- 서버는 actor가 실제 콘솔 상호작용 반경 안에 있을 때만 입력을 허용한다.
- 수직 자동 플레이도 플레이어가 생성된 순서대로 세 콘솔을 직접 방문하는 계약으로 변경했다.
