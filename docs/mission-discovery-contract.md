# 프롭 단서·미션지·광분 탈출 계약

> 기획 1의 금기어·빙결·최종 주문과 기획 2의 독립 AI·능동 술래를 연결하는 현재 미션 정본이다.

## 한 판의 흐름

```text
랜덤 장소의 프롭 탐색
→ 인간 또는 AI가 프롭 조사
→ 프롭 안의 메모로 미션지 범위 추론
→ 숨겨진 미션지 발견
→ 솔로 또는 협동 미션 수행
→ 주문 조각 획득
→ 세 미션 완료
→ 술래 광분 + 랜덤 탈출구 빛기둥 점등
→ 세 도망자 집결 + 최종 주문
→ 문 개방 + 탈출
```

## 인원과 미션 수

- 활성 도망자 수와 미션 수는 같다.
- 솔로 기본 구성은 인간 1명과 AI 동료 2명이므로 미션지는 3개다.
- 도중 도망자가 제거되어도 이미 생성된 미션 수는 줄지 않는다.
- 각 미션지는 서로 다른 유효 슬롯에서 뽑되, 같은 층이나 인접 구역에 생성되는 것은 허용한다.

## 프롭과 메모

- 프롭은 미션 정답이 아니라 **미션지를 찾기 위한 단서 컨테이너**다.
- 프롭 슬롯은 교실 책상, 사물함, 교무실 서랍, 보건실 침대 옆, 급식실 배식대, 체육관 관중석, 운동장 조회대, 놀이터, 골목 집하장, 경비실 등 실제 공간 문법에 맞춘다.
- 매 판 전체 슬롯 중 일부를 시드 기반으로 선택한다. 프롭 종류와 슬롯은 독립적으로 섞되 크기와 표면 높이가 맞아야 한다.
- 인간과 AI 모두 가까이에서 프롭을 조사할 수 있다.
- 조사에는 짧은 유지 시간이 있으며, 중단되거나 완료될 때 소리가 발생해 술래의 청각 단서가 된다.
- 조사 완료 시 메모 UI가 열린다. 예: `미션지는 학교 2층 교실 쪽에 있지 않을까…`
- 메모는 정확한 좌표 대신 층, 공간 종류, 랜드마크, 방향 중 1~2개를 제공한다.
- 같은 미션지에 대한 메모가 여러 프롭에서 나올 수 있어 한 프롭을 놓쳐도 판이 막히지 않는다.
- 이미 읽은 메모는 팀 기록에 남고, 해당 프롭은 사라지지 않으며 `조사 완료` 상태로 변한다.

## 인간과 AI의 정보 전달

- 인간이 조사하면 메모 원문과 핵심 위치 태그를 HUD에서 확인한다.
- AI가 조사하면 그 AI의 기억에 메모가 저장되고 짧은 음성·자막으로 팀에 전달한다.
- AI 발화 예: `2층 교실 쪽에 뭔가 숨겨져 있다는 메모를 찾았어.`
- AI는 메모를 읽었다고 곧바로 정답 좌표를 아는 것이 아니다. 단서 범위 안에서 후보 미션 슬롯을 탐색한다.
- 두 AI가 같은 프롭이나 같은 미션지를 선택하는 것을 허용하며 강제 분담하지 않는다.

## 숨겨진 미션지

- 미션지는 시작부터 월드에 존재하지만 일반 프롭처럼 강하게 발광하지 않는다.
- 가까운 거리의 형태, 미세한 소리, 비정상적인 배치로 발견할 수 있다.
- 관련 메모를 얻으면 미니맵에 정확한 점 대신 탐색 범위가 표시된다.
- 미션 템플릿은 `solo` 또는 `coop` 태그를 가진다.
- 각 미션지는 라운드 생성 시 호환 가능한 템플릿 중 무작위로 선택한다. 솔로/협동 비율과 순서를 강제하지 않는다.
- 협동 미션은 생존한 둘 이상의 도망자가 실제로 서로 다른 행동을 해야 한다.
- 솔로 미션은 인간 또는 AI 한 명이 처음부터 끝까지 완료할 수 있다.
- AI도 미션 조건을 인식하고 수행을 시도하며, 성공 판정은 서버가 한다.

### 초기 템플릿 풀

| 종류 | 템플릿 | 핵심 행동 |
|---|---|---|
| solo | 퓨즈 복구 | 주변 부품을 찾아 배전반에 삽입 |
| solo | 사물함 암호 | 환경 기호 순서를 읽고 입력 |
| solo | 방송 장치 조율 | 주파수 다이얼을 목표 범위에 유지 |
| coop | 동시 스위치 | 떨어진 두 장치를 제한시간 안에 작동 |
| coop | 압력판 운반 | 한 명이 판을 누르고 다른 한 명이 물건 운반 |
| coop | 단서 중계 | 서로 다른 위치에서 본 기호를 음성으로 전달 |

## 세 미션 완료와 술래 광분

- 세 번째 미션 성공 순간 서버가 `ENRAGED`를 선언한다.
- 술래 이동 속도는 기본값의 `1.35배`를 초기 튜닝 기준으로 사용한다.
- 탐색 유지 시간과 청각 반응 우선순위를 높이고, 도망자를 놓쳐도 더 오래 마지막 위치를 수색한다.
- 술래 몸과 주변에 붉은 경광을 켜고 광분 사이렌·포효·HUD 경고를 동시에 낸다.
- 광과민성 보호 설정에서는 점멸 대신 강도가 낮은 고정 붉은 빛을 사용한다.

## 랜덤 탈출구

- 탈출구는 사전 검증된 후보 중 라운드 시드로 하나를 선택한다.
- 세 미션 전에는 위치를 공개하지 않는다.
- 세 미션 완료 시 탈출구에서 하늘까지 이어지는 빛기둥이 켜진다.
- 빛기둥은 벽과 층에 가려지지 않는 방향 표식이며, 정확한 경로는 직접 찾아야 한다.
- 미니맵에는 활성화 이후에만 탈출구를 표시한다.
- 세 도망자는 각자 탈출구로 이동한다. 최종 주문 성공 후 실제 센서를 통과한 도망자만 탈출 처리한다.

## 서버 권위 데이터

- 라운드 시드, 활성 도망자 수와 미션 수
- 프롭 슬롯, 메모 내용, 조사 완료자와 팀 공유 상태
- 미션지 슬롯, 템플릿 종류, 참여자와 진행 상태
- 세 번째 완료 시점과 술래 광분 상태
- 탈출구 후보와 활성화 시점
- 최종 주문, 문 개방과 개별 탈출 판정

## 완료 기준

- 프롭을 조사하기 전에는 미션지의 정확한 위치를 알 수 없다.
- 인간과 AI 모두 프롭을 조사하고 같은 메모 정보를 얻을 수 있다.
- AI가 읽은 메모를 음성·자막으로 전달한다.
- 매 판 프롭, 미션지, 미션 유형과 탈출구 조합이 달라질 수 있다.
- 미션지 3개가 도달 가능하고 솔로/협동 조건으로 실제 완료된다.
- 세 번째 완료 직후 술래의 속도와 붉은 연출 변화가 체감된다.
- 탈출구 빛기둥은 캠퍼스 어디서든 방향을 식별할 수 있다.
