# 옥상 진행 복구 및 3층 계단 전환 안정화 단위

## 증상

옥상 신호를 조작해도 다음 단계로 넘어가지 않는 것처럼 보였고, 계단 하단의 층 전환 요청이 한 번 실패하면 같은 라운드에서 다시 시도되지 않았다.

## 실제 재현 결과

- 실행 중 서버에 실제 WebSocket 클라이언트로 접속해 랜덤 신호열을 순서대로 입력했다.
- 신호 진행 `1/3 → 2/3 → 3/3`과 `floor_3`, 접근 가능 층 `ROOF,F3` 개방 이벤트는 정상 발생했다.
- 따라서 서버 완료 판정보다 실패·이동 안내와 계단 경계 복구가 부족한 것이 실제 체감 차단 원인이었다.

## 수정

- 잘못된 신호를 누르면 서버가 다음에 입력할 중앙·동쪽·서쪽 신호를 정확히 알려준다.
- 이미 입력한 신호를 다시 눌러도 현재 신호와 다음 신호를 함께 안내한다.
- 옥상 완료 후 아직 옥상에 있으면 HUD를 `옥상 완료 · 3층 계단 이동`으로 바꾸고 북서 방화문과 U자 계단 동선을 직접 안내한다.
- 계단 하단의 자동 층 전환 요청을 0.9초 간격으로 재시도해 일시적인 통신·판정 실패가 영구 진행 차단으로 이어지지 않게 했다.
- 계단 경계 요청이 서버에서 거절되면 이유를 HUD 자막으로 표시한다.
- 백엔드 연결이 없는 로컬 데모에서도 옥상 완료 후 실제 계단 경계 이벤트로 F3 상태를 적용한다.

## 검증

- 실행 서버 실제 WebSocket 신호 진행 `3/3` 및 `floor_3` 개방 확인
- 인앱 실제 플레이에서 중앙 신호 E 입력 후 진행 `1/3` 갱신 확인
- 서버 테스트 351개 통과, 1개 스킵
- 클라이언트 프로덕션 빌드 통과
- 린트 오류 0, 기존 경고만 유지
- 캠퍼스 구조·충돌 계약 검증 통과
