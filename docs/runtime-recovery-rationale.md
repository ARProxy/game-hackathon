# 3D 런타임 복구 사고 흐름

## 관찰

React Three Fiber의 Canvas 내부에서 예외가 발생하면 React가 해당 렌더 트리를 제거한다. 이전 `useRapier` 컨텍스트 오류처럼 시작 UI가 이미 사라진 뒤 Canvas가 중단되면 사용자는 원인과 복구 방법이 없는 흰 화면만 본다. Canvas의 `fallback`은 WebGL 생성 실패를 위한 것이며 렌더 중 JavaScript 예외를 처리하지 못한다.

## 판단

모든 런타임 오류를 사전에 제거할 수는 없으므로, 3D 씬을 별도 Error Boundary로 격리해야 한다. 오류 상세는 콘솔과 접을 수 있는 진단 영역에 남기고, 사용자는 전체 페이지를 닫지 않고 Canvas 재마운트 또는 메인 메뉴 복귀를 선택할 수 있어야 한다.

## 구현 계약

- Canvas와 게임 HUD를 `GameErrorBoundary`로 감싼다.
- 예외 발생 시 흰 화면 대신 복구 안내, 오류 메시지, 재시도, 메인 메뉴 버튼을 표시한다.
- 재시도는 Canvas key를 변경해 WebGL·물리 월드를 새로 마운트한다.
- 메인 메뉴 복귀는 게임 스토어를 초기화하고 실행 중 화면을 해제한다.
- 오류 stack은 개발자 콘솔에 기록하되 사용자 화면에는 민감한 전체 stack을 노출하지 않는다.

## 성공 기준

3D 렌더 예외가 앱 루트 전체의 흰 화면으로 이어지지 않아야 한다. 복구 화면에서 재시도와 메인 메뉴 복귀가 가능하고 production build와 lint가 통과해야 한다.
