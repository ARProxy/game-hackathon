# Phase 4: 온보딩 + 미션 + 전체 플로우

> 작성일: 2026-08-03
> 상태: 핵심 완료 (처음부터 끝까지 한 판 플레이 가능)

---

## 완료된 단계

### 4-1. 온보딩 화면
- `components/Onboarding.tsx`
- 3개 질문을 순서대로 출제 (진행도 바 표시)
- 스페이스바(PTT)로 음성 답변 또는 텍스트 입력(폴백)
- 답변 완료 → 서버에 `onboarding_complete` 메시지 전송

### 4-2. 금기어 채집 로직 (서버)
- `server/app/ai/onboarding.py`
- kiwipiepy 형태소 분석 → 명사(NNG, NNP) 추출
- 불용어/제외어 필터 (얼음, 땡, 조사, 추상어 등)
- 프롭화 가능성 사전(PROP_SCORES)으로 가중 점수
- 빈도 x 프롭화 점수 → 상위 3개 선택
- 후보 부족 시 기본 풀(열쇠, 시계, 빨간, 커피, 우산)에서 보충

### 4-3. 금기어 발표 화면
- `components/ForbiddenReveal.tsx`
- 채집된 금기어 3개를 하나씩 팝업 애니메이션으로 공개
- "이 단어를 말하면 얼어붙습니다" 안내
- 2초 후 페이드아웃 → playing 페이즈 전환

### 4-4. 프롭 메타데이터 + 맵 슬롯 배치
- `server/app/data/prop_dict.json` — 8개 금기어에 대한 프롭 데이터 (진짜 + 디코이 2개씩)
- `server/app/ai/mission.py` — 금기어 → 프롭 매핑 → 맵 슬롯(12개) 분산 배치
- 라운드마다 프롭 위치 랜덤 셔플
- 단서 단어 풀에서 랜덤 선택
- `client/src/game/Props.tsx` — 프롭 3D 렌더링 (mesh 타입별 지오메트리 + 자체 발광)

### 4-5. T1 미션 플로우
- 플레이어가 프롭 가까이 가면 "E키로 조사" 힌트 표시 (nearbyPropId)
- E키 → AI 동료 "확인해볼게!" → 1.5초 후 판별
- 진짜 → 단서 획득 + 프롭 소멸 + 미션 진행
- 가짜 → "이건 아닌 것 같아" + 프롭 소멸
- 3개 미션 완료 → final_spell 페이즈 자동 전환

### 4-6. 미션 진행 HUD
- 좌상단에 미션 진행도 (미션 1/3, 2/3, 3/3)
- 획득한 단서 표시
- final_spell 페이즈에서 주문 전체 표시 + 안내

### 4-7. 최종 미션 — 주문 외치기
- `server/app/ai/spell.py` — 퍼지 매칭 판정
- 직접 포함 + 자모 유사도(0.7 이상) 2단계 매칭
- 60% 이상 단서 매칭 시 관대 판정으로 통과
- 성공 → `spell_success` → result 페이즈
- 실패 → `spell_failed` + 빠진 단서 안내 → 재시도 가능

### 4-9. 정산 화면
- `components/ResultScreen.tsx`
- 승리: "탈출 성공!" (라임색) / 실패: "게임 오버" (마젠타)
- 통계: 획득 단서 수, 금기어 위반 횟수
- 금기어 출처 공개 ("온보딩 대화에서 추출되었습니다")
- 다시 하기 버튼 (페이지 리로드)

## 전체 플로우 (현재 동작)

```
[접속] → 서버 자동 연결 (solo 방 생성)
    ↓
[온보딩] → 3개 질문 음성/텍스트 답변
    ↓
[금기어 채집] → 서버에서 명사 추출 + 프롭화 점수 → 상위 3개
    ↓
[금기어 발표] → 하나씩 애니메이션 공개 → 2초 후 게임 시작
    ↓
[게임 플레이]
  - WASD 이동, 시야 조명
  - 프롭 찾아서 E키 조사 → 진짜/가짜 판별 → 단서 획득
  - 스페이스바 PTT → 금기어 말하면 빙결 → 술래 추격 → AI 동료 구조
  - 3개 단서 모으면 final_spell 페이즈
    ↓
[최종 주문] → 스페이스바로 주문 외치기 → 퍼지 매칭 판정
    ↓
[정산] → 승리/실패, 통계, 금기어 출처, 다시 하기
```

## 파일 구조 (Phase 4 추가분)

```
server/app/
├── ai/
│   ├── onboarding.py      # 금기어 채집
│   ├── mission.py         # 라운드 생성 (프롭 배치, 미션, 단서)
│   └── spell.py           # 최종 주문 퍼지 매칭
└── data/
    └── prop_dict.json     # 프롭 메타데이터 (8개 금기어 대응)

client/src/
├── components/
│   ├── Onboarding.tsx     # 온보딩 질문 UI
│   ├── ForbiddenReveal.tsx # 금기어 발표 애니메이션
│   ├── HUD.tsx            # 미션 진행, E키 힌트, 주문 표시 추가
│   └── ResultScreen.tsx   # 정산 화면
├── game/
│   └── Props.tsx          # 프롭 3D 렌더링 + 근접 감지
└── stores/
    └── gameStore.ts       # props, missions, spellWords, clues, nearbyProp 추가
```
