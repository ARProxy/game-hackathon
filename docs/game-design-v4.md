## 0. 문서의 역할

기획 3은 `옥상 → 3층 → 2층 → 1층 → 지하/운동장 파이널`의 수직 하강 구조를 정했다. 기획 4는 이 흐름이 실제 게임으로 작동하도록 다음을 구체화한다.

- 현재 층 미션을 깨기 전에는 다음 층으로 내려갈 수 없다.
- 시간 경과와 층 진행에 따라 술래가 서로 다른 방식으로 강화된다.
- 금기어 누적 위반이 층 진행과 별개로 술래를 강화한다.
- 1층부터 두 번째 술래가 등장해 `추격자(청각) + 차단자(시야)` 협공을 만든다.
- 층 사이에 규칙과 공간 상태를 바꾸는 중간 이벤트가 발생한다.
- AI 동료는 관찰·판단·질문·행동을 실제 음성으로 표현한다.
- AI 발화도 월드의 소리이며 거리 기반으로 술래에게 위험을 만든다.
- 실제 사실과 행동은 서버가 판정하고 LLM은 표현을 담당한다.

### 기획 4가 명시적으로 추가·개정하는 항목

- 술래 수는 전 구간 1명으로 고정되지 않는다.
- 1층에서는 기존 추격자와 신규 차단자, 총 2명의 술래가 활성화된다.
- 두 술래는 동일 복제가 아니라 감각 특화가 다르다(추격자=청각, 차단자=시야).
- 파이널에서는 두 술래가 모두 광분하지만 추가 시간 강화는 중지한다.
- 금기어 누적 위반은 층 진행과 독립적으로 술래를 강화한다.
- 금기어는 인간 플레이어에게만 빙결을 적용하고 AI 동료는 빙결하지 않는다.
- AI 발화의 소리 핑은 발화 길이와 방식에 따라 반경이 달라진다.
- 중간 이벤트는 한 판에 1~2개만 선택해 핵심 흐름을 방해하지 않게 한다.
- AI 대사는 장식이 아니라 정보·판단·협동·위험을 전달하는 게임 시스템이다.
- 엘리베이터는 빠른 이동 수단이자 소리·정전 위험이 있는 전략적 선택지다.

기획 4가 언급하지 않은 공간 구조와 미션 상세는 기획 3과 `room-mission-design.md`를 따른다.

## 1. 현재 최종 게임 정의

**옥상에서 깨어난 인간과 두 AI 동료가 금기어를 피해 말하며 층별 방탈출 미션을 해결하고, 시간이 흐르고 아래로 내려갈수록 강화되는 복수의 술래를 피해 지하 또는 운동장의 파이널 봉쇄를 해제하는 음성 협동 학교 탈출 게임이다.**

핵심 압박은 세 축이 동시에 상승하는 데서 나온다.

```text
공간 진행: 옥상 → 3층 → 2층 → 1층 → 파이널
술래 위협: 암시 → 제한 사냥 → 완전 사냥 → 2인 협공 → 광분
음성 부담: 안전한 지시 → 위험한 보고 → 분산 협동 → 긴급 관제 → 최종 역할 조정
```

## 2. 층별 진행과 잠금

### 기본 규칙

- 현재 층의 필수 미션이 완료되기 전에는 다음 층으로 내려갈 수 없다.
- 잠금 대상은 다음 층으로 이어지는 계단 방화문, 엘리베이터와 우회 낙하 경로다.
- 현재 층 안에서는 활성 방과 복도 사이의 여러 경로를 선택할 수 있다.
- 문 상태와 접근 권한은 서버가 판정한다.
- 인간, AI 동료와 술래는 동일한 잠금 상태를 사용한다.
- 메시·콜라이더·서버 벽이 서로 다른 통로를 허용해서는 안 된다.

### 진행 순서

```text
ROOFTOP_INTRO
  └─ 옥상 미션 완료 → 3층 방화문 개방

FLOOR_3
  └─ 3층 필수 미션 완료 → 2층 방화문 개방

FLOOR_2
  └─ 2층 필수 미션 완료 → 1층 방화문 개방

FLOOR_1
  └─ 1층 필수 미션 완료 → 지하 또는 운동장 파이널 경로 개방

FINAL
  └─ 파이널 미션 + 최종 주문 완료 → 최종 탈출문 개방
```

### 층 완료 피드백

- 잠금 해제 금속음
- 현재 층의 조명 상태 변화
- 다음 계단 유도등이 적색에서 녹색으로 전환
- 교내 방송이 정확한 층과 방향을 안내
- AI 동료가 "아래층 문이 열린 것 같아"라고 음성 보고
- 미니맵이 다음 활성 층과 열린 계단을 표시

### 이전 층 접근

기획 3의 슬라이딩 2개 층 계약을 유지한다.

- 2층 진행 중에는 2층과 3층 접근 가능
- 1층 진행 중에는 1층과 2층 접근 가능
- 파이널 진행 중에는 파이널과 1층 접근 가능
- 바로 이전 층은 구조·선택 단서 회수·술래 우회에 사용한다.
- 두 단계 이상 지난 층은 actor·필수 단서·AI 목표 안전 검사 후 닫는다.
- 옥상은 전원 하강 후 닫혀 영구 안전지대가 되지 않는다.

## 3. 금기어 시스템 — 통합 정본

금기어 관련 규칙이 기획 1~4에 흩어져 있었다. 본 섹션이 금기어의 현재 정본이다.

### 3.1 기본 규칙

| 항목 | 확정 내용 |
|---|---|
| 금기어 개수 | 한 판에 3개 고정 |
| 금기어 교체 | 한 판 끝까지 변경 없음 |
| 적용 대상 | **인간 플레이어에게만 빙결 적용** |
| AI 동료 | 금기어를 알고 피하려 노력하지만 빙결되지 않음 |
| 정보 공개 | 전원 동일 공개 (솔로 모드에서 정보 비대칭 불필요) |
| 빙결 시 사망 | 30초 내 구조 실패 시 해당 캐릭터 탈락 |
| 판정 방식 | STT + 3단계 파이프라인 (정규식 → 형태소 → 자모 퍼지) |

### 3.2 금기어 생성

- 게임 시작 전 AI(Ollama gemma3:4b)가 매 판 새로운 연상 질문을 생성한다.
- 플레이어의 음성 답변에서 kiwipiepy로 명사를 추출한다.
- 게임에서 지원하는 프롭 어휘와 대조해 금기어 3개를 선택한다.
- AI 서버 장애 시: 지원 풀에서 무작위 3개를 선택하는 폴백.
- 자유 생성 단어를 그대로 적용하지 않는다. 미션과 우회 설명이 검증된 프롭 어휘만 허용.

### 3.3 AI 동료와 금기어

AI 동료는 금기어에 의해 빙결되지 않는다. 대신 다음과 같이 동작한다.

- AI는 금기어 목록을 인식하고 발화 시 해당 단어를 회피한다.
- 금기어를 말할 뻔하다가 멈추는 연출을 사용한다: "그건 열... 아, 그 금속 물건 말이지?"
- 이 연출은 플레이어에게 금기어를 리마인드하는 역할을 한다.
- AI가 금기어를 완벽히 피하며 말하는 것 자체가 AI 지능의 증거다.

### 3.4 금기어 유인 전략

플레이어는 금기어를 전략적 도구로 사용할 수 있다.

**시나리오 예시:**

```text
상황: 2층 미션을 해야 하는데 술래가 2층에 있음

1. 플레이어가 3층 교실에서 의도적으로 금기어를 외침
2. 플레이어 빙결 + 술래에게 핑 전송
3. 술래가 3층으로 이동
4. AI 동료가 플레이어를 구조 ("땡!")
5. 그 사이 다른 AI가 2층 미션 진행
```

**유인의 비용:**

- 플레이어 본인이 빙결됨 → 30초 내 구조 필요
- 금기어 누적 카운터 증가 → 광분 트리거에 가까워짐
- 구조 실패 시 탈락 → 영구적 손실

비용이 있으므로 남발하면 광분 발동 + 구조 실패로 자멸한다. 위험을 감수한 고급 플레이로만 성립한다.

### 3.5 금기어 누적 → 술래 광분 트리거

금기어 위반은 빙결 외에도 술래를 영구 강화하는 숨겨진 비용이다.

| 팀 누적 위반 | 술래 변화 | 플레이어 체감 |
|---|---|---|
| 3회 | 속도 1.1배 | 거의 못 느낌 |
| 5회 | 광분. 속도 1.25배 + 청각 범위 확대 + 붉은 경광 | "갑자기 빨라졌어!" |
| 7회+ | 극대 광분. 속도 1.35배 + 시야 확대 + 최근 위치 감지 | "어떻게 알고 와?" |

**핵심 설계:**

- 층 진행 강화와 **별개로 누적**된다. 3층에서 5회 위반하면 3층인데도 광분이 발동한다.
- 한번 올라간 단계는 **해제되지 않는다**. 실수의 누적이 영구적 비용이다.
- 플레이어는 **술래 변화의 원인을 모른다**. "왜 갑자기 빨라졌지?"만 느낀다.
- 결과 화면에서 "금기어 N회 위반 → 술래 광분 발동"을 공개하여 반전 연출.
- 잘하는 플레이어는 광분 없이 클리어 가능 → 스킬 보상.

**층 강화와의 관계:**

```text
최종 술래 난도 = max(층 진행 강화, 금기어 누적 강화)
```

- 2층인데 금기어 7회면 → 극대 광분 (층 강화보다 금기어 강화가 높음)
- 1층인데 금기어 2회면 → 협공 (층 강화가 금기어 강화보다 높음)
- 두 강화가 겹쳐도 상한을 넘지 않는다. 파이널 광분(1.35배)이 최대치다.

**자연스러운 난이도 스케일링:**

- 금기어를 많이 실수하는 플레이어 → 술래가 빨라짐 → 게임이 어려워짐
- 금기어를 잘 피하는 플레이어 → 술래가 기본 난도 → 게임이 공정함
- 별도 난이도 선택 없이 플레이어 실력에 따라 자동 조절

## 4. 술래 난도 모델

술래 강화는 단순 속도 증가가 아니다. `층 진행 강화`는 새로운 능력과 역할을 열고, `시간 강화`는 해당 능력의 강도를 조금씩 올리고, `금기어 누적 강화`는 층과 독립적으로 압박을 높인다.

### 4.1 층 진행 강화

| 구간 | 술래 수 | 상태 | 주요 변화 |
|---|---:|---|---|
| 옥상 | 0 | 비활성 (시각 연출) | 아래층 창문으로 붉은 실루엣 순찰이 보임. 판정 비활성 |
| 3층 초반 | 1 | 암시 | 실루엣·발소리·붉은 반사광 |
| 3층 후반 | 1 | 제한 사냥 | 큰 소리·직접 목격에 반응, 짧은 추격 |
| 2층 | 1 | 완전 사냥 | 인간·AI 감지, 추격, 수색, 포획 |
| 1층 | 2 | 협공 | 기존 추격자 + 신규 차단자 |
| 파이널 | 2 | 광분 | 강한 압박, 붉은 경광, 사이렌 |

### 4.2 시간 강화

시간 압박은 플레이어가 퍼즐을 천천히 푸는 것을 처벌하기보다, 지나친 정체와 안전 대기를 막기 위해 사용한다.

- 수색 포기까지 걸리는 시간이 길어진다.
- 마지막 소리와 목격 위치를 기억하는 시간이 증가한다.
- 문과 미션실을 확인하는 빈도가 증가한다.
- 발화 소리의 조사 우선순위가 높아진다.
- 차단자가 퇴로를 예측하는 빈도가 증가한다.

### 시간 단계 예시

```text
3층 진입
- 제한 수색 해금
- 라운드 4분 이상: 수색 지속시간 소폭 증가

2층 진입
- 완전 추격 해금
- 라운드 8분 이상: 소리 기억시간 증가

1층 진입
- 두 번째 술래 등장
- 라운드 12분 이상: 차단 경로 예측 빈도 증가

파이널 진입
- 현재 난도 고정
- 추가 시간 강화 중지
```

시간 기준은 플레이 테스트로 조정한다. 층 강화와 시간 강화가 동시에 과도하게 누적되지 않도록 상한을 둔다.

### 4.3 금기어 누적 강화

3.5절 참조. 층 진행·시간과 독립적으로 팀의 금기어 위반 횟수에 따라 술래가 영구 강화된다.

### 강화 공정성

- 변화는 방송, 사이렌, 발소리, 조명과 AI 보고로 미리 알린다.
- 술래 속도가 도망자의 최대 회피 가능성을 넘지 않는다.
- 추격 실패와 포획 후 짧은 목표 재평가 시간을 둔다.
- 필수 미션 상호작용은 언제든 중단하고 도망칠 수 있다.
- 파이널에서는 시간 때문에 추가 강화하지 않는다.
- 금기어 누적 강화의 원인은 플레이 중 공개하지 않는다. 결과 화면에서 공개한다.

## 5. 1층의 두 번째 술래

### 결정

1층 진입 또는 1층 미션 시작 이벤트에서 두 번째 술래가 등장한다. 동일한 추격자 두 명을 복제하지 않고 서로 다른 감각과 역할을 가진다.

### 술래 A — 추격자 (청각 특화)

- 3층부터 플레이어를 압박한 기존 술래
- **핵심 감각: 청각**. 발화·조사·이동 소리를 정확히 추적
- 소리 나는 곳으로 빠르게 이동해 직접 추격
- 속도가 빠르고 접근 경고가 명확함 (발소리 + 사이렌)
- 목표를 놓치면 마지막 소리 위치 주변을 수색
- **대응법: 조용히 있으면 안전**

### 술래 B — 차단자 (시야 특화)

- 1층에서 처음 활성화되는 두 번째 술래
- **핵심 감각: 시야**. 넓은 시야각으로 순찰하며 시각적으로 발견
- 직접 장거리 추격보다 계단·미션실·구조 경로와 예상 퇴로 차단
- 발견 시 직접 잡는 대신 **추격자에게 위치를 공유** → 추격자가 달려옴
- 추격자보다 느리지만 위치 선점과 경로 예측에 강함
- 얼어 있는 도망자 주변을 제한 시간 동안 경계
- 손전등 빛 + 정적으로 접근 (사이렌 없음)
- **대응법: 시야 밖으로 숨어야 안전**

### 두 술래의 게임 임팩트

- 추격자에게 통하던 "조용히 숨기"가 차단자에게는 안 통함 (시야로 찾음)
- 차단자에게 통하던 "벽 뒤에 숨기"가 추격자에게는 안 통함 (소리로 찾음)
- 둘이 동시에 오면 **조용히 있으면서 시야도 피해야** → 극한의 긴장
- 차단자가 발견 → 추격자 호출 → 약간의 시간 여유 → "지금 도망쳐!" 순간
- 플레이어는 1층에서 "이 술래는 뭔가 다르다"를 체험으로 발견
- 결과 화면에서 두 술래의 감각 차이를 공개

### 등장 연출

기본안은 `지하에서 올라오는 차단자`다.

1. 1층 진입 후 잠겨 있던 지하 방화문에서 충격음이 들린다.
2. 교내 조명과 CCTV가 불안정해진다.
3. 경비실 화면에 기존 술래와 다른 두 번째 실루엣이 보인다.
4. 지하 문이 열리고 차단자가 1층으로 올라온다.
5. AI 동료가 두 위치의 소리 또는 CCTV 모순을 보고한다.

이 연출은 지하 파이널 가능성을 미리 암시한다.

### 두 술래의 제한된 정보 공유

완전한 좌표 공유는 피할 틈을 없애므로 사용하지 않는다.

- 차단자가 도망자를 시야로 발견하면 **구역 수준** 정보를 추격자에게 전달
- 추격자는 해당 구역으로 이동해 청각으로 정밀 추적
- 서로 일정 거리 안일 때 상대의 추격 상태 인식
- 같은 목표를 일정 시간 이상 쫓으면 한 명이 차단 역할로 전환
- 두 술래가 같은 출입문을 동시에 막지 않음
- 정확한 실시간 목표 좌표와 미래 경로는 공유하지 않음
- 포획 직후 둘 다 같은 구조 대상을 영구 캠핑하지 않음

### 협공 성공 기준

- 플레이어가 두 술래의 역할 차이를 소리와 움직임으로 구분한다.
- 단순 직선 도주가 아니라 교실 관통, 계단 우회와 AI 유인이 필요하다.
- 두 술래가 한 줄로 같은 목표만 따라다니지 않는다.
- 구조가 어렵지만 불가능하지 않다.
- CCTV와 AI 보고가 실제 판단 가치를 가진다.

## 6. 파이널의 술래 상태

지하 또는 운동장 파이널 진입 시 두 술래 모두 `ENRAGED`로 전환한다.

### 공통 변화

- 붉은 경광과 사이렌 활성화
- 추격자 재탐색 시간 단축
- 차단자의 파이널 목표 지점 순찰 강화
- 인간과 AI 모두 동일한 포획 대상
- 파이널 진척과 구조 상태를 고려한 목표 재평가
- 파이널 시작 후 시간·금기어 기반 추가 강화 중지 → 난도 예측 가능

### 운동장

- 추격자는 직접 유인 대상을 쫓는다.
- 차단자는 활성 발판과 최종 게이트 사이를 압박한다.
- 넓은 시야 때문에 술래 위치도 판독 가능하다.
- 속도만 올리지 않고 엄폐물·회복·목표 전환 틈을 제공한다.

### 지하

- 추격자는 소리와 마지막 목격 위치를 집중 수색한다.
- 차단자는 기계실 문과 비상 터널 경로를 선점한다.
- 좁은 공간에서는 속도보다 소리 기억과 경로 차단을 강화한다.

## 7. 엘리베이터

엘리베이터는 계단의 대안 이동 수단이자 전략적 선택지다.

### 기본 규칙

- 엘리베이터는 열린 층 사이에서만 이동 가능하다. 잠긴 층으로 보내지 못한다.
- 계단보다 빠르지만 **소리가 크다**. 도착 층에 큰 소리 핑을 발생시킨다.
- 술래는 엘리베이터 소리를 감지하고 도착 층을 안다.
- 술래도 엘리베이터를 사용할 수 있다.

### 전략적 선택

| 계단 | 엘리베이터 |
|---|---|
| 느리지만 조용함 | 빠르지만 소리가 큼 |
| 도중에 방향 전환 가능 | 탑승하면 도착까지 이동 |
| 술래와 마주칠 수 있음 | 술래가 도착 층에서 기다릴 수 있음 |

### 중간 이벤트 연동

- **정전 이벤트(E02) 발생 시 엘리베이터 정지** → 탑승 중이면 갇힘
- 갇힌 상태에서 AI에게 음성으로 배전반 복구를 지시해야 함
- 엘리베이터를 빈 상태로 보내서 술래를 유인하는 고급 전략 가능

## 8. 중간 이벤트 시스템

중간 이벤트는 컷신이 아니라 월드 규칙, 정보 또는 동선을 바꾸는 사건이다.

### 선택 규칙

- 한 판에 1~2개만 활성화한다.
- 같은 기능을 방해하는 이벤트를 동시에 선택하지 않는다.
- 필수 미션을 해결 불가능하게 만들지 않는다.
- 이벤트 시작 전 최소 하나의 시청각 전조를 제공한다.
- 라운드 시드로 재현 가능해야 한다.

### E01. 층 개방 이상

- 잠금 해제 순간 현재 층 조명이 잠시 꺼진다.
- 다음 층 유도등만 켜진다.
- 술래가 마지막 목표 대신 열린 계단을 조사한다.
- 도망자는 즉시 내려갈지 술래를 먼저 유인할지 선택한다.

### E02. 국지 정전

- 활성 두 층 중 한 구역의 일반 조명이 꺼진다.
- 손전등과 비상등만 사용한다.
- 술래 시야도 감소하지만 소리 조사 우선순위가 올라간다.
- AI가 배전반 또는 안전한 우회 경로를 음성으로 보고한다.
- **엘리베이터 탑승 중이면 정지** → 갇힘 위험.

### E03. 방송 왜곡

- 학교 방송이 닫힌 계단이나 잘못된 방향을 안내한다.
- AI 한 명은 방송을 신뢰하고 다른 AI는 기록과 모순을 발견할 수 있다.
- 플레이어가 팀 기록과 AI 판단을 비교한다.
- 광분 전에는 방송의 거짓 비율을 낮게 유지한다.

### E04. 팀 분리

- 셔터나 방화문이 일시적으로 닫혀 인간과 AI가 두 구역으로 나뉜다.
- 서로 보이지 않는 상태에서 음성으로 정보를 교환한다.
- 반대 구역의 장치를 조작해야 다시 합류한다.
- 구조가 필요한 actor를 완전히 고립시키지 않는다.

### E05. 가짜 구조 요청

- 교내 방송 또는 술래가 AI 동료 음성을 흉내 낸다.
- 팀 상태·미니맵·최근 보고와 비교하면 거짓임을 알 수 있다.
- 한 판에 최대 한 번만 사용한다.
- 실제 AI 음성에 대한 신뢰가 영구적으로 무너지지 않게 명확한 이상 징후를 남긴다.

### E06. 술래 전환 예고

- 기존 술래의 소리가 잠시 사라지고 지하에서 새로운 충격음이 들린다.
- CCTV에 서로 다른 두 위치의 실루엣이 잡힌다.
- 1층 두 번째 술래 등장을 준비하는 고정 또는 선택 이벤트다.

## 9. AI 동료의 음성 역할

AI가 생각하고 있어도 말하지 않으면 플레이어는 그 지능을 체감할 수 없다. AI 발화는 다음 네 기능을 가진다.

### 관찰 보고

- "2층 과학실에서 파란 삼각형을 봤어."
- "동쪽 계단에서 사이렌 소리가 들려."
- "이 문은 아직 잠겨 있어."

관찰은 AI가 실제 센서와 서버 상태로 확인한 사실만 사용한다.

### 판단 설명

- "방송 내용과 칠판 기록이 맞지 않아."
- "미션보다 얼어 있는 동료를 먼저 구하는 게 좋겠어."
- "술래가 동쪽에 있으니 서쪽 계단으로 갈게."

모든 내부 점수를 읽지 않고 플레이어가 이해할 수 있는 핵심 근거 하나만 짧게 말한다.

### 확인 질문

- "작은 금속 물건이 은색 사물함을 말하는 거야?"
- "먼저 밸브를 돌리라는 뜻이야, 전원을 끄라는 뜻이야?"

확신도가 낮을 때 자동 정답 행동 대신 질문하고, 플레이어의 교정으로 후보를 다시 평가한다.

### 행동 선언

- "내가 구조하러 갈게."
- "나는 이 스위치를 맡을게."
- "술래를 반대편으로 유인해볼게."

선언한 행동과 실제 목표가 일치해야 한다. 목표가 바뀌면 이유를 다시 보고한다.

### 금기어 회피 연출

- AI는 금기어를 알고 발화 시 회피한다.
- 금기어를 말할 뻔하다가 멈추는 연출: "그건 열... 아, 그 금속 물건 말이지?"
- 이 연출은 플레이어에게 금기어를 리마인드하는 역할을 겸한다.

## 10. AI 발화 모드와 위험

AI의 목소리도 월드 안에서 발생하는 실제 소리다. 인간만 음성 위험을 부담하지 않도록 AI 발화 역시 술래에게 감지될 수 있다.

### 발화 모드와 소리 핑 반경

| 모드 | 사용 상황 | 소리 핑 반경 | 표현 |
|---|---|---:|---|
| 짧은 반응 | "응", "큰 거?", 확인 | 8m | 자연스러운 음성 + 자막 |
| 일반 발화 | 안전하거나 일반 보고 | 18m | 자연스러운 음성 + 자막 |
| 속삭임 | 술래가 가까운 상황 | 8m | 낮은 음량 + 자막 |
| 긴급 외침 | 구조·술래 발견·즉시 위험 | 18m+ | 짧고 강한 음성 + 경고 자막 |
| 인터폰/방송 | 미션 중 인터폰·방송실 사용 | 해당 층 전체 | 스피커 효과음 + 자막 |
| 무전 | 서로 다른 층·폐쇄 구역 | 매우 작음 또는 없음 | 무전 효과음 + 자막 |
| 침묵 | 정보 가치가 낮고 위험이 큼 | 없음 | 상태 아이콘만 표시 |

무전이 항상 안전하면 인간 음성 위험을 우회하는 최적 해법이 된다. 배터리, 사용 횟수, 특정 설비 복구 또는 잡음 등 제한을 둔다.

### 플레이어 명령

플레이어는 다음과 같은 의미의 음성 명령을 사용할 수 있다.

- "조용히 해." → 긴급 상황 외 발화 보류
- "보고해." → 보류 중인 가장 중요한 사실 한 개 보고
- "무전으로 말해." → 가능한 경우 무전 모드 요청
- "크게 알려줘." → 팀 전체에 긴급 방송

고정 문장만 인식하지 않고 `SILENCE`, `REPORT`, `RADIO`, `BROADCAST` 의도로 매핑한다.

### 중복 억제

- 같은 사실은 상태가 바뀌지 않으면 반복하지 않는다.
- 다른 AI가 방금 같은 정보를 보고했으면 확인 또는 차이만 말한다.
- 긴급도 낮은 대사는 추격·미션 음성과 겹치지 않게 큐잉한다.
- 오래된 정보는 현재 사실처럼 말하지 않고 "아까 봤을 때"라고 표시한다.

### 긴급 발화의 캐릭터성

AI가 항상 최적의 침묵만 선택해서도 안 된다. 동료가 얼거나 술래를 갑자기 발견하면 위험을 감수하고 외치는 행동이 동료성을 만든다. 단, 같은 경고를 반복해 플레이어를 계속 노출시키지 않는다.

## 11. AI 음성 생성 아키텍처

자유 대화 LLM이 월드 사실과 행동을 창작하지 못하도록 판정과 표현을 분리한다.

```text
월드 관찰
→ 서버가 구조화된 사실 생성
→ AI 의사결정기가 목표·행동·확신도 선택
→ 발화 정책이 말할지와 모드 결정
→ 대화 생성기가 허용된 사실을 짧은 한국어 문장으로 표현
→ Piper TTS로 음성 합성 (로컬, 무료, 한국어)
→ 발화 모드에 따라 월드 소리 핑 생성
```

### 음성 생성 기술 스택

| 계층 | 기술 | 역할 | 비용 |
|---|---|---|---|
| 고정형 대사 (80%) | 대사 풀 + 조건 매칭 | 빈번한 상황의 즉시 응답 | 무료 |
| 동적 대사 (20%) | Ollama (gemma3:4b) | 우회 표현 이해, 맥락 보고 | 무료 |
| 음성 합성 | Piper TTS (로컬) | 텍스트 → 한국어 음성, ~50ms | 무료 |

- 고정형 대사: "확인해볼게", "술래가 가까워!", "큰 거? 작은 거?" 등
- 동적 대사: "2층 교실 쪽에 뭔가 숨겨져 있다는 메모를 찾았어" 등 맥락 의존 문장
- Piper TTS: 로컬 실행, Mac 지원, 한국어 모델 사용, 50ms 이내 합성

### 발화 이벤트 예시

```json
{
  "speaker": "partner-2",
  "intent": "REPORT_SEEKER",
  "facts": {
    "floor": "F2",
    "zone": "동쪽 계단",
    "observed_at": 128.4,
    "confidence": 0.78
  },
  "decision": {
    "next_action": "MOVE_WEST_STAIR",
    "reason": "AVOID_SEEKER"
  },
  "delivery": {
    "mode": "whisper",
    "ping_radius": 8,
    "urgency": "high"
  }
}
```

LLM은 위 사실을 바탕으로 문장을 만들 수 있지만 다음을 바꿀 수 없다.

- 술래의 실제 위치와 관찰 시각
- 문 잠금 상태
- 미션 정답과 진척
- AI의 실제 목표와 행동
- 구조 대상과 제한시간
- 소리 핑 반경과 게임 판정

### 폴백

- LLM이나 TTS가 실패하면 intent별 템플릿 문장과 자막을 즉시 사용한다.
- 음성 생성 실패가 AI 행동을 멈추지 않는다.
- 문장 생성이 늦으면 오래된 발화를 폐기하고 최신 긴급 사실을 우선한다.

---

## 12. AI의 행동과 음성 일치

AI가 말만 그럴듯하고 실제로 다른 행동을 하면 신뢰가 무너진다.

- `내가 구조할게`를 말한 AI의 서버 목표는 해당 구조 대상이어야 한다.
- 술래 때문에 목표를 포기하면 "길이 막혀서 우회할게"처럼 변경 이유를 알린다.
- 같은 목표를 두 AI가 선택할 수 있으며 강제 중복 방지는 하지 않는다.
- 두 AI가 같은 발판으로 가면 서로 또는 플레이어 보고를 통해 이후 재판단할 수 있다.
- 위험 상태에서는 말을 완료한 뒤 움직이는 것이 아니라 움직이면서 짧게 보고한다.
- 말하기 애니메이션과 월드 음성 위치는 실제 AI actor 위치를 사용한다.

## 13. 맵 없이 먼저 구현 가능한 계약

### 13.1 라운드 상태 머신

- `ROOFTOP_INTRO`
- `FLOOR_3`
- `FLOOR_2`
- `FLOOR_1`
- `FINAL_ROUTE_REVEAL`
- `FIELD_FINAL` / `BASEMENT_FINAL`
- `ESCAPE_OPEN`

### 13.2 술래 난도와 역할

- 시간 단계 계산
- 층 진행 강화
- 금기어 누적 강화 (3/5/7회 임계값)
- 추격자(청각)·차단자(시야) 역할과 감각 차별화
- 차단자 발견 → 추격자 호출 협동
- 제한된 정보 공유
- 같은 목표 중복 추격 해소
- 파이널 난도 고정

### 13.3 금기어 시스템

- 3개 고정, 한 판 변경 없음
- 인간만 빙결, AI는 회피 연출
- 누적 카운터와 술래 강화 임계값
- 유인 전략 비용 계산
- 결과 화면 공개 데이터

### 13.4 AI 대화 계약

- 관찰·판단·질문·행동 선언 intent
- 금기어 회피 연출
- 중요도와 중복 억제
- 짧은 반응(8m)·일반(18m)·속삭임(8m)·외침(18m+)·인터폰(층 전체)·무전·침묵 모드
- LLM/TTS 폴백
- AI 발화의 술래 소리 핑

### 13.5 미션 인터페이스

- 미션 ID와 활성 층
- 필요한 역할과 정보 슬롯
- 음성 의미 슬롯
- 솔로·협동 태그
- 진행·중단·완료 상태
- 실패 시 소리·조명·술래 이벤트
- 다음 층 개방 이벤트

### 13.6 중간 이벤트 선택기

- 라운드 시드
- 층과 선행 조건
- 동시 선택 금지 태그
- 시작 전조와 종료 조건
- 교착 방지 검사
- 엘리베이터 정전 연동

## 16. 구현 우선순위

### P0 — 상태 계약

1. 층별 진행 상태와 다음 층 잠금
2. 슬라이딩 2개 층과 안전 폐쇄
3. 맵 슬롯 ID와 문 계약
4. 시간·층·금기어 기반 난도 단계
5. 술래 actor를 여러 명 지원하는 서버 상태
6. 금기어 누적 카운터와 광분 임계값

### P1 — 술래 2인 구조

1. 기존 술래를 추격자(청각) 역할로 명시
2. 차단자(시야) 목표 효용과 경로 선택
3. 차단자 발견 → 추격자 호출 협동
4. 제한된 정보 공유
5. 동일 목표 중복 추격 해소
6. 1층 등장 이벤트와 파이널 광분

### P2 — AI 음성

1. 구조화된 발화 이벤트
2. 템플릿 자막 폴백
3. Piper TTS 재생과 actor 위치 연결
4. 발화 모드와 거리별 소리 핑 (8m/18m/층 전체)
5. 금기어 회피 연출 ("열... 아, 그 금속 물건")
6. 중복 억제와 중요도 큐
7. LLM 자연어 표현 계층

### P3 — 금기어 통합

1. 인간만 빙결, AI 회피 로직
2. 누적 카운터 서버 상태
3. 3/5/7회 술래 강화 트리거
4. 유인 전략 비용 계산
5. 결과 화면 공개 데이터

### P4 — 중간 이벤트

1. 국지 정전 + 엘리베이터 연동
2. 방송 왜곡
3. 팀 분리
4. 가짜 구조 요청
5. 시드 선택과 교착 방지

### P5 — 새 맵 결합

1. 의미 슬롯에 실제 좌표·문·경로 연결
2. 엘리베이터 경로와 소리 구역 연결
3. 층별 도달성 자동 검사
4. AI와 술래 다층 경로 검증
5. 미션실과 음향 구역 연결
6. 10~15분 전체 플레이 테스트

## 17. 테스트 계약

### 층 진행

- 현재 필수 미션 전에는 다음 층 문이 열리지 않는다.
- 미션 완료 이벤트를 서버가 한 번만 처리한다.
- 인간과 AI가 동일한 문 상태를 받는다.
- 폐쇄 예정 층에 actor나 목표가 있으면 `CLOSING_PENDING`이 유지된다.

### 금기어 시스템

- 금기어 3개가 한 판 끝까지 변경되지 않는다.
- 인간 플레이어만 금기어 발화 시 빙결된다.
- AI 동료는 금기어를 피하며 빙결되지 않는다.
- 금기어 누적 3/5/7회에서 술래 강화가 정확히 발동한다.
- 누적 강화는 해제되지 않는다.
- 금기어 누적 강화와 층 진행 강화 중 높은 쪽이 적용된다.
- 결과 화면에서 위반 횟수와 광분 발동 여부가 공개된다.

### 복수 술래

- 1층 전에는 차단자가 활성화되지 않는다.
- 추격자는 청각, 차단자는 시야를 핵심 감각으로 사용한다.
- 차단자가 발견하면 추격자에게 구역 수준 정보를 전달한다.
- 같은 목표를 오래 추격하면 한 명이 차단으로 재배정된다.
- 둘이 같은 문을 동시에 영구 차단하지 않는다.
- 파이널 진입 후 시간·금기어 강화 단계가 더 오르지 않는다.

### AI 음성

- 발화 사실은 서버 관찰 범위를 벗어나지 않는다.
- 행동 선언과 실제 목표가 일치한다.
- 같은 정보를 무한 반복하지 않는다.
- LLM/TTS 장애에도 AI 행동과 게임 진행이 유지된다.
- 짧은 반응(8m)·일반(18m)·인터폰(층 전체)에 서로 다른 소리 핑 반경이 적용된다.
- 오래된 발화보다 최신 긴급 이벤트를 우선한다.
- AI가 금기어를 발화하지 않고 회피 연출을 사용한다.

### 엘리베이터

- 잠긴 층으로 엘리베이터를 보낼 수 없다.
- 엘리베이터 도착 시 소리 핑이 발생한다.
- 정전 이벤트 시 엘리베이터가 정지한다.
- 술래도 엘리베이터를 사용할 수 있다.

### 중간 이벤트

- 한 판에 선택된 이벤트 수가 예산을 넘지 않는다.
- 상충 태그를 가진 이벤트가 동시에 실행되지 않는다.
- 이벤트 때문에 필수 문·미션·구조 경로가 영구 차단되지 않는다.
- 같은 시드에서 이벤트 선택이 재현된다.

## 18. 플레이 테스트 질문

- 현재 층 미션을 완료해야 내려갈 수 있다는 목표가 명확한가?
- 시간 압박이 서두르게 만들지만 퍼즐 사고 자체를 불가능하게 하지는 않는가?
- 금기어를 많이 실수한 판이 적게 실수한 판보다 체감 난도가 높은가?
- 플레이어가 금기어 실수와 술래 강화의 관계를 플레이 중에는 눈치채지 못하는가?
- 결과 화면에서 금기어 누적 → 술래 광분 공개가 반전으로 작동하는가?
- 플레이어는 1층에서 두 번째 술래의 등장을 미리 감지하는가?
- 추격자(청각)와 차단자(시야)의 역할 차이가 실제 동선으로 보이는가?
- 차단자가 발견 → 추격자 호출의 시간차가 도망의 기회를 만드는가?
- 두 술래 때문에 구조가 어려워져도 가능한 선택이 남는가?
- 엘리베이터의 속도 이점이 소리 위험과 균형을 이루는가?
- 중간 이벤트가 규칙을 풍부하게 만드는가, 진행을 방해하는가?
- AI의 관찰·판단·질문·행동이 말과 실제 움직임으로 일치하는가?
- AI 음성이 도움인 동시에 적절한 위험을 만드는가?
- AI의 금기어 회피 연출이 자연스럽고 리마인드 효과가 있는가?
- 플레이어가 AI에게 침묵·보고·무전 방식을 지시할 이유가 있는가?
- 금기어 유인 전략이 비용 대비 가치 있는 선택으로 존재하는가?
- 맵 좌표가 바뀌어도 슬롯 연결만 교체해 로직이 유지되는가?

## 19. 금지 사항

- 현재 층 미션을 건너뛰고 다음 층으로 낙하·우회 진입한다.
- 술래 강화 수단을 이동속도 증가 하나로만 구현한다.
- 1층에 동일한 추격 AI를 단순 복제한다.
- 두 술래가 정확한 목표 좌표를 계속 공유한다.
- 두 술래가 구조 대상을 영구적으로 캠핑한다.
- 중간 이벤트를 한 판에 모두 발생시킨다.
- 가짜 AI 음성을 반복해 실제 동료 보고의 신뢰를 없앤다.
- LLM이 월드 사실, 문 상태, 미션 정답 또는 AI 행동을 결정한다.
- AI가 말한 행동과 실제 서버 목표가 다르다.
- AI 음성을 술래가 절대 들을 수 없는 무료 정보 채널로 만든다.
- AI가 불필요한 대사를 반복해 플레이어를 강제로 노출시킨다.
- 새 맵 좌표를 상태 머신과 AI 로직에 직접 하드코딩한다.
- AI 동료를 금기어로 빙결시킨다.
- 금기어 누적 광분 트리거를 플레이 중에 직접 공개한다.

## 20. 현재 미결정 사항

다음은 코드로 고정하기 전에 추가 대화 또는 프로토타입으로 결정한다.

- 두 번째 술래 등장 조건: 1층 진입 즉시 또는 1층 미션 시작 시점
- 차단자의 얼어 있는 도망자 경계 시간
- 두 술래가 공유할 구역 정보의 정확도와 지연
- 시간 강화의 실제 분 단위 임계값
- 금기어 누적 광분의 정확한 위반 횟수 임계값 (3/5/7은 초기 가설)
- AI 일반 발화와 인간 발화의 소리 반경 차이
- 무전의 제한 방식: 배터리, 횟수, 설비 복구 또는 잡음
- TTS 음성과 미리 녹음한 캐릭터 음성의 혼합 방식
- Piper TTS 한국어 모델의 음질과 캐릭터별 음색 구분
- 가짜 구조 요청 이벤트의 표현과 판별 단서
- 파이널에서 두 술래의 속도와 목표 전환 상한
- 엘리베이터 소리 핑의 정확한 반경과 지속시간
- 엘리베이터 정전 갇힘의 최대 지속시간과 탈출 조건
