# 운동장·지하 파이널 협동 폐루프 구현 기록 (2026-08-09)

## 목적

옥상부터 1층까지 내려온 뒤 파이널이 단순한 개인 상호작용으로 끝나지 않도록, 운동장과 지하 경로 모두에서 세 명의 역할이 실제 서버 규칙으로 분리되고 최종 주문·탈출까지 막힘없이 이어지게 한다.

## 기획 대조

- 운동장: 플레이어와 AI 동료 2명이 각자 지정된 장치에 도착해야 한다.
- 지하: AI가 설비 상태를 보고하고 플레이어가 음성으로 작동을 지시한다.
- 잘못된 지하 순서는 전체 리셋과 큰 소리 핑을 발생시킨다.
- 파이널 완료 뒤 금기어를 잠그고 주문 조각을 합쳐 탈출구를 연다.

## 이번 변경

### 지하 역할 분리

- 배전반은 `partner`, 급수 밸브는 `partner-2`, 발전기는 인간 플레이어 담당으로 고정했다.
- 플레이어가 `Q` 음성으로 “배전반을 켜 줘”, “밸브를 돌려 줘”처럼 장치와 행동을 함께 말하면 서버가 현재 대기 장치인지 검증한다.
- 지시를 받은 담당 AI만 해당 장치를 실제로 작동한다.
- 인간이 배전반·밸브 앞에서 `E`를 눌러 협동을 건너뛰거나, AI가 지시 없이 장치를 작동하는 우회는 서버가 거절한다.
- 발전기는 인간 플레이어가 장치 앞에서 `E`로 직접 작동한다.

### 실패와 복구

- 현재 대기 순서가 아닌 장치 지시는 거절하고 AI가 재확인을 요청한다.
- 장치 상태가 바뀐 순간의 오래된 AI 행동은 취소하고 다시 상태를 확인한다.
- 잘못된 순서로 작동하면 기존 기획대로 모든 장치를 끄고 명령 상태도 비우며, 술래가 들을 수 있는 기계음 핑을 남긴다.
- 성공한 장치 뒤에는 두 AI의 설비 기억을 갱신해 다음 대기 장치를 다시 확인한다.

### 화면 피드백

- HUD와 목표 문구에 AI 담당 장치는 `Q`, 발전기는 직접 `E`라는 역할을 명시했다.
- 지시 전달, 담당 위반, 지시 대기, 순서 리셋, 최종 복구 상태를 각각 다른 자막으로 표시한다.

## 검증

- 순수 미션 규칙: AI 담당 장치 지시·소유권·명령 소비 검증
- AI 행동: 담당 장치에 도착한 AI가 지시 후 `basement_device_activate`를 생성하는지 검증
- 서버 흐름: 인간이 AI 담당 장치를 직접 조작할 수 없는지 검증
- 결정적 자동 플레이: 배전반 음성 지시 → AI 조작 → 밸브 음성 지시 → AI 조작 → 인간 발전기 → 주문 → 탈출 개방 검증
- WebSocket 폐루프: 실제 음성 메시지와 백그라운드 AI 틱을 통해 두 AI가 장치를 작동하고 최종 주문·탈출까지 전환되는지 검증

운동장 경로는 기존 자동 완주 테스트에서 3명이 각자 지정 장치에 도착해야만 주문 단계가 열리는 구조를 계속 검증한다.
