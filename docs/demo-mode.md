# Zero-Dependency Demo 계약

FastAPI WebSocket을 2.5초 안에 열 수 없거나 최초 연결이 거절되면 클라이언트는 로컬 데모 transport로 전환한다. 실제 서버가 열린 경우에는 폴백이 개입하지 않는다.

로컬 데모도 기존 WebSocket 수신 이벤트를 그대로 생성하므로 온보딩, 금기어 공개, 세 번의 AI 후보 판단과 조사, 주문 조각, 게이트 도착, 주문과 실제 통과, 승패 화면은 동일한 Zustand/UI 경로를 사용한다. 고정 금기어는 `열쇠`, `커피`, `빨간`이며 주문은 표식 순서대로 `달 별 새벽`이다.

술래는 현재 미션 후보 구역을 수색하고 플레이어가 12m 안에 들어오면 추격한다. 실제 좌표가 1.5m 안에 들어왔을 때만 포획 이벤트를 확정한다. 금기어 또는 트랩 빙결은 AI 동료가 1.8초 뒤 구조하는 결정적 시연 흐름을 사용한다.

이 모드는 심사 환경의 서버 실행 실패에 대비한 폴백이다. 정상 플레이와 authoritative 검증 기준은 FastAPI 서버 모드가 정본이다.
