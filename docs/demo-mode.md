# 레거시 로컬 데모 폐기 기록

> 갱신일: 2026-08-10
> 상태: 제출 빌드에서 제거

초기 프로토타입은 서버 연결이 2.5초 안에 열리지 않으면 클라이언트 내부의 고정 프롭·고정 금기어 데모로 전환했다. 이후 본편이 `옥상 → 3층 → 2층 → 1층 → 운동장/지하` 수직 구조와 비공개 동적 금기어로 개정되었지만, 데모는 과거 3개 프롭 조사와 고정 주문 흐름에 남아 있었다.

구형 데모로 조용히 전환하면 심사자가 현재 기획과 다른 게임을 보거나 완주할 수 없는 상태에 빠진다. 따라서 제출 버전에서는 `DemoTransport`를 제거하고 다음 계약으로 통일한다.

- production에서는 FastAPI가 빌드된 클라이언트와 WebSocket을 같은 origin에서 제공한다.
- 연결 실패는 HUD에 명확히 표시하며 다른 게임 규칙으로 폴백하지 않는다.
- 마이크나 브라우저 STT 장애는 게임 서버와 무관하므로 Enter 텍스트 입력으로 폴백한다.
- Ollama 장애는 서버의 Kiwi·결정론적 규칙 폴백을 사용하며 게임 진행을 멈추지 않는다.
- 배포와 로컬 실행은 루트 `README.md`의 단일 production 절차를 따른다.

다시 오프라인 데모를 제공하려면 본편의 모든 층 미션, 두 파이널, 비공개 금기어 세대, 술래와 AI 상태를 같은 계약으로 구현하고 전체 완주 테스트를 추가한 뒤 별도 기능으로 복구해야 한다.
