# 멀티플레이 월드 동기화 보완 단위

- 기준일: 2026-08-09
- 발견 경로: 최종 기획-코드 재감사

## 발견한 불일치

대기방과 서버 방 계약은 연결돼 있었지만 실제 3D 월드는 항상 로컬 인간 1명과 AI 2명을 그렸다. 따라서 다른 인간의 이동이 보이지 않았고, 인간 3~4명 방에서 서버가 제거한 AI가 클라이언트 화면에는 남았다.

## 수정

- 서버의 `player_moved` 방송을 클라이언트 플레이어 상태에 병합한다.
- 다른 인간 플레이어를 서버 좌표 사이에서 보간해 렌더하고 이동 방향·보행·빙결 상태를 표시한다.
- 대기방의 서버 권위 캐릭터 선택을 다른 인간 캐릭터 모델에 적용한다.
- AI 동료는 서버의 실제 `ai_partner` 참가자만 렌더한다. 2인 방은 AI 2명, 3인 방은 AI 1명, 4인 방은 AI 0명이다.
- 탈락·탈출한 원격 인간은 월드에서 숨긴다.

## 검증

- 두 실제 WebSocket 클라이언트가 같은 방을 시작한 뒤 한 클라이언트의 위치가 다른 클라이언트에 `player_moved`로 전달되는 통합 테스트 통과
- 서버 전체 테스트: `385 passed`
- 클라이언트 lint 오류·경고 0
- TypeScript·프로덕션 빌드·학교 구조 계약 검증 통과
