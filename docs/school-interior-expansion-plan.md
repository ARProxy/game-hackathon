## 문제 정의

현재 맵은 외형상 본관 3층과 별관·체육관이 있지만 실제 한 판의 데이터는 이를 사용하지 않았다.

- 인간은 현관 밖, AI 동료는 운동장 조회대 옆에서 시작했다.
- 미션 프롭 12개는 오래된 운동장 A/B/C/D 구역 좌표를 사용했다.
- 교실 폭은 약 7m, 깊이는 6.7m지만 3×3 책상과 3인칭 카메라를 함께 넣어 체감 통로가 좁았다.
- 복도는 길지만 분기와 회유 동선이 약해 왕복 통로로만 작동했다.
- 2·3층은 시각적으로 존재하지만 서버 AI와 프롭은 층 정보를 갖지 않아 핵심 플레이에 참여하지 못했다.
- 학교 밖은 시작부터 열려 있어 “잠긴 학교에서 탈출한다”는 목표가 성립하지 않았다.

## 목표 경험

플레이어는 밤의 학교 1층 안에서 깨어난다. 현관 방화문은 잠겨 있고 AI 동료 두 명도 서로 다른 복도 지점에서 움직이기 시작한다. 교실, 행정실, 보건실, 급식실과 별관을 수색하며 미션을 완료해야 현관 통제가 풀린다. 그 뒤에야 운동장으로 나가 빛기둥이 켜진 최종 탈출구를 향한다.

시각 구현은 `platform-8-school-realism-benchmark.md`의 저사양 실세계형 스타일라이즈드 리얼리즘을 따른다. 평면 확장보다 정상 학교의 공간 문법, 재질 분리와 생활 흔적을 우선하며, 반복 모듈은 이후 상태 변화와 공포 연출의 기준으로 사용한다.

## 공간 규모 계약

단순 월드 스케일 확대는 가구와 사람 크기를 망가뜨리므로 `1 unit = 1m`는 유지한다.

| 요소 | 현재 | 목표 |
|---|---:|---:|
| 일반 교실 | 약 7 × 6.7m | 8.4 × 8.2m |
| 주 복도 | 폭 3.6m | 폭 4.2m, 추격 교행 가능 |
| 본관 직선 길이 | 약 42m | 약 58m |
| 1층 핵심 방 | 교실·기능실 혼재 | 10개 이상, 방별 실루엣 구분 |
| 순환 경로 | 사실상 직선 왕복 | 중앙 계단홀과 동·서 연결 복도를 통한 최소 2개 루프 |

- [x] 교실·복도 바닥 재질과 경계선을 추가

### Phase 1 — 1층 평면 확장

- [ ] 본관 길이를 58m로 늘리고 일반 교실 폭을 8.4m로 통일
- [ ] 교실 깊이를 8.2m로 늘려 책상 사이 주 통로 1.4m 확보
- [ ] 복도 폭을 4.2m로 늘려 술래와 도망자의 교행·추월 공간 확보
- [ ] 동쪽 끝에 음악실·준비실, 서쪽 끝에 급식실·조리실 루프 구성
- [ ] 중앙 계단홀 뒤편 연결 통로를 추가해 막다른 직선 구조 해소
- [ ] 클라이언트 벽과 서버 `WALL_RECTS`를 동일 좌표 계약으로 교체

### Phase 2 — 방별 장소성

- [ ] 일반 교실: 4×3 책상, 칠판, 교탁, 사물함, 게시판, 커튼, 청소도구
- [ ] 과학실: 실험대, 싱크, 시약장, 준비실
- [ ] 보건실: 침대, 가림막, 약품장, 체중계
- [ ] 행정·교무실: 책상 군집, 파티션, 복사기, 서류장
- [ ] 급식·조리실: 배식대, 긴 식탁, 냉장고, 조리대
- [ ] 화장실: 세면대, 칸막이, 거울과 타일 재질
- [ ] 방마다 바닥 색, 벽 하부, 조명 온도와 큰 실루엣을 다르게 지정

### Phase 3 — 다층 실제 플레이

- [ ] 플레이어·AI 상태에 `floor/y` 권위 좌표 추가

- [ ] AI 계단·엘리베이터 경로 그래프 추가
- [ ] 미션 3개가 최소 2개 층에 분산될 확률 규칙 추가

## 재미 검증 기준

- 시작 후 미션 완료 전에는 물리적으로 학교 밖에 나갈 수 없어야 한다.
- 첫 프롭까지 최소 두 개의 의미 있는 경로 선택이 있어야 한다.
- 술래와 마주쳤을 때 직선 후퇴 외에 교실 관통, 계단홀 우회, 연결 복도 선택이 가능해야 한다.
- 어떤 방에 들어왔는지 HUD 없이 가구·바닥·조명만 보고 구분할 수 있어야 한다.
- 한 판에서 최소 세 종류의 방과 두 개 이상의 복도 분기를 사용해야 한다.
- AI 동료와 술래가 확장된 벽에 멈추지 않고 목표로 이동해야 한다.

## 구현 금지

- 사람과 가구까지 함께 비례 확대해 거대한 장난감 학교를 만드는 방식
- 시각 메시만 옮기고 서버 벽·AI 경로 좌표를 그대로 두는 방식
- 방 이름만 바꾸고 같은 책상 배열을 모든 특별실에 복사하는 방식
- 넓이를 빈 바닥으로만 채워 이동 시간만 늘리는 방식
