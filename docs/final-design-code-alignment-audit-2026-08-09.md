> 감사일: 2026-08-09  
> 대상: 현재 `main`의 광고된 제출 범위  
> 이전 감사: `full-design-code-alignment-audit-2026-08-09.md`의 67% 상태에서 시작

## 최종 판정

현재 광고된 제출 범위의 **자동 검증 가능한 맵 구조·코드·서버 계약·기능 완주 경로는 모두 통과**했다. 운동장과 지하 두 경로, 승리·부분 승리·패배, 솔로와 인간 2명+AI 2명 협동에서 알려진 진행 교착은 없다.

반면 사람이 느끼는 카메라 멀미, 밝기, 구조물 미감, 음량 밸런스를 자동 테스트 결과만으로 100%라고 판정할 수는 없다. 사용자가 맡기로 한 화면 검증이 마지막 체감 승인 단계다.

또한 역사적 기획서의 확장 목표 전체를 현재 제출 범위와 혼동하지 않는다. 3~4인 인간 역할 대체, 진행 중 재접속, Piper 기반 위치 음성은 현재 UI가 광고하지 않는 후속 확장이다.

## 3. 실제 플레이 기능 체감

자동 플레이가 확인한 순서는 다음과 같다.

```text
옥상 기억·AI 신호 협동
→ 실제 계단 하강
→ 3층 AI 추론과 잘못된 후보 교정
→ 2층 인터폰 기호 전달
→ 1층 CCTV 음성 관제와 동시 장치
→ 운동장 3인 집결 또는 지하 음성 역할 분담
→ 답을 직접 보여주지 않는 주문 추론
→ 탈출·부분 탈출·포획 결과와 원인 분석
```

AI 동료는 자막과 실제 브라우저 음성으로 보고하며, 효과음·환경음·발소리·사이렌·문·빙결·구조 피드백이 분리된 음량 설정을 사용한다. 원격 인간과 AI 수는 서버 실제 참가자와 화면이 일치한다.

## 4. 수동 승인 체크

사용자 화면 검증에서는 다음만 확인하면 된다.

- 이동 2~3분 동안 카메라 떨림이나 프레임 급락이 없는가
- 모든 계단의 폭·난간·문 간격이 캐릭터 체형에 자연스러운가
- 문·바닥의 겹침 깜빡임과 Z-fighting이 보이지 않는가
- 미니맵이 화면을 침범하지 않고 실제 위치와 직관적으로 일치하는가
- AI 음성, 술래 발소리, 사이렌, 환경음의 상대 음량이 적절한가
- 광과민성 보호에서 붉은 경광 점멸이 실제로 사라지는가

## 5. 후속 확장과 제출 범위의 경계

아래는 현재 게임이 지원한다고 표시하지 않으며, 구현 완료로 계산하지 않는다.

- 인간 3~4명이 AI 전용 역할을 대신하는 미션 변형
- 진행 중 새로고침·일시 단절 재접속 토큰
- OS별 브라우저 음성 대신 동일 음색을 보장하는 Piper 모델과 위치 기반 음성 패닝
- 층별 미션 템플릿 수를 늘리는 콘텐츠 확장

따라서 결론은 다음과 같다.

> **제출 범위의 자동 계약은 전부 녹색이다. 전체 역사 기획과 주관적 화면 체감까지 100%라고 주장하려면 수동 화면 승인과 후속 확장이 별도로 필요하다.**
