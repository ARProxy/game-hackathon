# 3층 방송실 AI 의미 교정 협동 단위

## 문제

3층 방송실은 옥상과 다른 음성 우회 미션과 제한 추격을 갖고 있었지만, AI 동료는 콘솔까지 이동한 뒤 장치를 발견했다는 말만 했다. 플레이어가 우회 표현에 실패해도 시스템 UI만 누락 의미를 표시해 AI가 함께 미션을 푼다는 감각이 없었다.

## 수정

- 방송실에 도착한 AI가 `의미 감시 담당` 역할을 선언한다.
- AI 도착을 `broadcast_ai_ready` 사건으로 클라이언트에 전달한다.
- 플레이어 발화에서 필수 의미가 빠지면 서버 판정 결과를 AI의 확인 질문으로 바꿔 전달한다.
- AI는 정답 문장을 대신 읽지 않고 `문을 여는 도구`, `잠긴 출입구`, `개방 행동` 중 빠진 의미만 알려준다.
- AI 피드백도 금기어 회피 필터를 거치며, 인간은 표현을 다시 만들어야 한다.
- 방송 미션 시작과 동시에 기존 `omen → limited_hunt` 전환 및 인간 발화 소리 핑은 유지한다.

## 플레이 결과

3층의 역할은 다음처럼 분리된다.

- 플레이어: 원문을 그대로 읽지 않고 세 의미를 우회 표현한다.
- AI 동료: 방송 수신을 확인하고 빠진 의미를 질문으로 되돌린다.
- 술래: 방송 연결 뒤 큰 소리와 직접 시야에 반응하는 제한 추격을 수행한다.

따라서 실패는 단순 UI 오답이 아니라 `플레이어 표현 → AI 교정 → 재발화`의 협동 루프로 돌아간다.

## 검증

- 3층·술래·WebSocket 선별 테스트 80개 통과
- 클라이언트 프로덕션 빌드 통과
- 누락 의미가 `개방 행동`일 때 AI가 해당 의미만 질문하고 정답 문장을 노출하지 않는 통합 테스트 추가
