# Batch 009 — 적대 QA와 외부 환경 정본 제안

## 상호 검토 결과

QA 에이전트는 행정실 설계에 대해 200개 seed 붕괴 위험, 교장 desk와 hole buffer의 1cm 여유, 상담실 벽걸이 보드 오프셋, 저상 collider 소비자 부재를 지적했다. 구현에서는 붕괴 위치 고정, desk 횡방향 이동, 보드 벽 부착, `forceCollider` 전 소비 경로와 자동 검증으로 이를 해결했다. 신규 미션은 실제 vertical 소비 경로가 없으므로 선언하지 않았다.

설계 에이전트는 외부 983개 primitive 중 raw HEX가 690개이고 OUT/ROOF 고유색이 과도하다고 분석했다. 다음 외부 개선 묶음은 임의 색을 13개 exterior token과 PBR family로 축소하고, 본관 plinth·층간 facade band·중앙 현관·정문 위계를 정본화하는 것으로 결정했다.

## 다음 배치 수용 기준

- 외부 raw HEX 비율과 고유색 수를 정량적으로 낮춘다.
- 본관은 층별로 제각각인 표면 대신 plinth와 일정한 수평 band를 공유한다.
- 중앙 현관, 정문, 후문, 체육관 출입구는 크기와 조명으로 위계가 읽혀야 한다.
- 운동장·앞마당·주차·녹지의 지면 zone은 겹치지 않고 서로 다른 기능을 보여야 한다.
- 배경 나무·건물은 플레이 경계를 가리되 실제 출입 동선을 침범하지 않아야 한다.
