# Campus Rebuild Sprint

이 경로는 2026-08-08 학교 맵 재구축 작업만 기록한다. 기존 진행 문서와 분리해, 각 배치의 문제 제기·결정·검증·커밋을 추적한다.

## 정본 원칙

- 건축 프로그램과 기능 인접성은 고정한다. 시드는 미션·소품·상태만 바꾼다.
- 정상 학교 문법을 70~80% 유지하고 파손은 희소한 overlay로 취급한다.
- 같은 교실 모듈 안에서도 출입 동선·책상 군집·중앙 여백·큰 랜드마크가 달라야 한다.
- 렌더, 서버 충돌, 슬롯, 문, 미니맵은 장기적으로 하나의 방/좌표 계약을 공유한다.
- 검증되지 않은 가구 collider 대량 추가는 금지한다. Rapier 안정성과 게임플레이 장애물은 별도 예산으로 다룬다.
