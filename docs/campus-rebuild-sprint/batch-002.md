# Batch 002 — 미션·프롭 표면 앵커 복구

## 문제

특별실 셔플을 전제로 만든 `relocate()`가 모든 미션과 프롭을 대상 방의 중심으로 덮어썼다. 이 때문에 “흄후드 안”, “사물함 위”, “피아노 위” 같은 표면 계약이 이름만 남고 실제 좌표는 사라졌다.

## 변경

- 방 중심 재배치를 제거하고 원래의 표면 좌표를 보존했다.
- room ID, 층, 방 경계 0.12m 안쪽, `surfaceY` 층고 범위를 생성 시점에 검증한다.
- 경계 밖이던 학생회실·현관·지하 기계실 좌표를 실제 방 안으로 교정했다.
- 방으로 모델링되지 않은 운동장 조회대는 잘못된 `room: field` 참조를 제거했다.
- 생성 결과와 원본 슬롯 좌표가 동일한지 자동 계약에 추가했다.

## 다음 공간 감사 결과

두 에이전트의 다음 특별실 감사 대상으로 도서실 방 밖 열람대, 시청각실 문을 막는 계단석, 영어실 원탁 중첩, 급식 suite 서비스 동선 단절, 방송실-준비실 연결 부재를 기록했다. 이들은 Batch 003에서 room-local 배치와 suite 연결 계약으로 처리한다.
