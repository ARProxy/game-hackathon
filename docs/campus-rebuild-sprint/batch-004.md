# Batch 004 — 특별실 공간 문법과 실제 문 접근 검사

## 문제

도서실·시청각실·영어전용실이 각 방의 방향과 실제 출입문을 무시한 월드 좌표 가구 배치를 사용했다. 그 결과 방마다 다른 이름은 있어도 내부 실루엣과 이동 경험이 일반 교실의 변형처럼 보였고, 회전된 윙에서는 스크린과 가구가 엉뚱한 벽을 기준으로 배치될 가능성이 있었다.

## 변경

- 세 특별실을 방 로컬 좌표 `u/v`로 전환했다.
- 도서실은 평행 서가 3열, 열람 섬 2개, 대출대와 반납함으로 탐색축과 입구 랜드마크를 만들었다.
- 시청각실은 문 반대편 스크린, 무대, 3단 계단석, 천장 프로젝터로 명확한 정면성을 만들었다.
- 영어전용실은 일반 교실의 행렬과 겹치지 않는 3개 원형 대화 포드와 언어 스크린·알파벳 띠로 구성했다.
- 로컬 박스와 원기둥에 `roomId`, `layoutId`, `local`, `navRole` 메타데이터를 남겼다.
- 모든 태그된 가구의 방 경계 이탈과 실제 `campus.doors` 기준 1.5m 진입부 점유를 자동 검사한다.
- 벽·천장 부착물과 바닥 데칼은 데이터에서 명시해 보행 장애물과 구분한다.
- 검사가 찾아낸 시험형 교실의 문 옆 독서대를 안쪽으로 이동했다.

## 검증

- `npm run verify:campus` 통과: 방 80개, 문 122개, 정상 상태 71.4%, 교실 레이아웃 5종 유지.
- `npm run build` 통과.
- 남은 검증: 실제 플레이 화면에서 세 방의 입구 실루엣, 시야선, 계단석 높이와 원형 포드 간격을 수동 확인한다.
