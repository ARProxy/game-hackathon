# 옥상 콘솔 끼임 및 안전 동선 복구 단위

## 증상

옥상 신호 미션을 진행하려고 구조물 사이로 접근하면 플레이어가 끼어 움직이지 못했고, 특히 서쪽 신호기 주변에서는 미션 진행 자체가 막힐 수 있었다.

## 원인

- 세 신호기의 미션·상호작용 좌표가 물리 콘솔 중심을 가리켜 플레이어가 충돌체 방향으로 계속 접근하게 됐다.
- 서쪽 신호 콘솔과 세 번째 HVAC 설비의 충돌체가 실제로 겹쳐 있었다.
- 옥상 주요 목표 사이에 플레이어 캡슐 폭을 고려한 연속 동선 검증이 없었다.

## 수정

- 콘솔의 물리 위치는 유지하고, 플레이어와 AI가 사용하는 상호작용·접근 위치를 콘솔 앞 안전 지점으로 분리했다.
- 서쪽 신호기와 겹치던 HVAC 한 대를 외벽 쪽으로 옮겨 설비 밀도를 유지하면서 회전·통과 공간을 확보했다.
- 스폰에서 중앙 신호, 중앙에서 동·서 신호, 서쪽 신호에서 옥상 계단문까지 0.25m 간격으로 바닥과 충돌 여유를 검사한다.
- 안전 지점 검사는 플레이어 캡슐보다 0.12m 넓은 여유 폭을 요구하도록 강화했다.

## 검증

- 옥상 안전 동선을 포함한 캠퍼스 계약 검증 통과
- 프로덕션 빌드 통과
- 린트 오류 0, 기존 경고만 유지
- 서버 테스트 350개 통과, 1개 스킵
- 인앱 실제 플레이에서 연속 이동 입력 후 플레이어 위치와 방향이 정상 변경되는 것을 확인
