# 옥상→3층 문 개방·계단 여유 폭 수정 (2026-08-09)

## 증상

- 옥상 기억 신호 미션을 완료하고 실제 계단을 내려가도 3층 복도 방화문이 열리지 않았다.
- 계단 층계참과 방화문의 폭이 플레이어 캡슐에 비해 좁았고, 열린 문짝도 계단 쪽으로 회전해 통로를 다시 침범했다.

## 원인

- 옥상 펜트하우스 문 `roof_to_f3`는 `F3` 해제 조건을 사용했지만, 계단 아래 문 `stair_nw_F3`는 `F2` 해제 조건만 사용했다.
- 모든 도망자가 옥상 경계를 통과하면 서버 접근 층이 `F3` 하나로 축소된다. 도착층 문이 인접 과거 층만 검사하면 이 순간 다시 닫혀 플레이어를 계단실에 가둘 수 있었다.
- 북서 방화문의 양의 회전 방향이 문짝을 계단 층계참 쪽으로 밀어 넣었다.
- 방화문 유효 폭은 `1.17m`, 상부 층계참 깊이는 `0.92m`여서 반경 `0.4m` 플레이어가 회전하며 통과할 여유가 작았다.

## 수정

- 층계참 문에 여러 해제 층을 표현하는 `unlockFloors` 계약을 추가했다.
- `stair_nw_F3`는 옥상 도착 시 열리고, 옥상이 닫힌 뒤에도 `F3`가 활성인 동안 계속 열린다.
- 같은 문제가 다음 층에서 반복되지 않도록 F3·F2·F1의 북서/남동 층계참 문을 도착층 활성 조건까지 포함하도록 정리했다.
- 북서 계단문은 계단이 아닌 복도 방향으로 열리도록 회전 방향을 반전했다.
- 모든 계단 방화문과 옥상 펜트하우스 방화문 개구부를 `1.8m`로 확장해 실제 문짝 유효 폭 `1.72m`를 확보했다.
- 계단 층계참 깊이를 `0.92m`에서 `1.4m`로 확장했다.
- 변경된 벽 개구부를 기준으로 서버 충돌 계약을 다시 생성했다.

## 회귀 검증

- `ROOF + F3`: 옥상 문과 3층 북서 문 모두 개방
- `F3` 단독: 옥상 폐쇄 직후에도 3층 문 개방 유지
- `F3 + F2`: 3층에서 2층으로 내려가는 문 개방
- 두 방화문 유효 폭 `1.7m` 이상
- 북서 문 복도 방향 회전
- 층계참 깊이 `1.3m` 이상
- 옥상 문부터 3층 복도까지 전 구간 연속 바닥 지지
- 클라이언트 골조와 서버 벽 충돌 계약 일치
