# 맵 & 시야 리디자인 계획

> 작성일: 2026-08-03
> 상태: 계획 수립 중
> 목적: 현재 25x25 프로토타입 맵을 기획서 수준으로 확장하고, 시야 시스템을 근본적으로 재설계

---

## 현재 문제

1. 맵이 25x25로 좁아서 한 화면에 거의 다 보임
2. 시야 제한이 PointLight 하나뿐 — 어둠이 불완전하고, 멀리 있는 것도 희미하게 보임
3. 구조물이 프리미티브 조합 수준 — 구역 간 시각 정체성이 약함
4. 숨을 곳, 막다른 길, 경로 선택이 의미 없는 수준
5. 가로등 트레이드오프, 트랩 위치 등 맵 기믹 미구현

---

## 목표

- 플레이어 시야 밖은 **완전한 어둠** (실루엣조차 안 보임)
- 시야 반경 안에서만 바닥, 구조물, 캐릭터가 보임
- 맵이 충분히 넓어서 **"저쪽에 뭐가 있는지 모르는"** 탐색감이 생김
- 구역마다 **뚜렷한 시각 정체성** — 어느 구역인지 즉시 인지 가능
- 술래, 프롭, 트랩이 어둠 속에서 의미 있는 존재가 됨

---

## 작업 분할

### Phase A: 시야 시스템 재설계

현재 PointLight 방식의 한계:
- Three.js PointLight는 거리에 따라 서서히 어두워짐 → "완전한 어둠"이 안 됨
- 멀리 있는 밝은 색 오브젝트(프롭 emissive 등)가 여전히 보임

검토할 방식:

| 방식 | 설명 | 장점 | 단점 |
|------|------|------|------|
| **A. 원형 마스크 셰이더** | 화면 위에 검은 원형 구멍 오버레이. 구멍 안만 보임 | 완전한 어둠 보장, 구현 간단 | 2D 느낌, 벽 뒤도 보임 |
| **B. Fog + PointLight 조합** | Three.js Fog로 일정 거리 이상 완전히 안 보이게 | 3D 느낌 유지 | Fog 색이 배경과 맞아야 함 |
| **C. 커스텀 셰이더** | 플레이어 거리 기반으로 오브젝트 alpha/visibility 제어 | 완벽한 제어 | 구현 복잡 |
| **D. Fog + 마스크 하이브리드** | Fog로 3D 느낌 + 화면 마스크로 시야 밖 완전 차단 | 최선의 결과 | 중간 공수 |

→ **B 또는 D로 결정 예정.** 프로토타이핑 후 확정.

작업 항목:
- [ ] 시야 반경 결정 (기획서 기준 플레이어 주변 몇 m?)
- [ ] Fog 설정 (near/far 거리, 색상 #07090D)
- [ ] 기존 PlayerLight 제거 또는 Fog와 병용
- [ ] 시야 밖 오브젝트의 emissive/발광 차단
- [ ] 프롭은 시야 밖에서 **아주 희미한** 발광만 (방향 힌트)
- [ ] 빙결 플레이어 시야 유지 (관제탑) — 빙결 시 Fog 해제? 또는 시야 확대?
- [ ] 가로등 구역: Fog 안에서도 고정 광원으로 밝은 영역 유지

### Phase B: 맵 크기 확대

현재 25x25 → 목표 크기 결정 필요.

고려 사항:
- 기획서: "대각선 횡단 8~10초"
- 현재 이동 속도: 5 unit/s
- 대각선 횡단 10초 → 대각선 길이 = 50 → 한 변 = 약 35
- **50x50으로 확대하면** 대각선 ~70 → 14초. 너무 클 수 있음
- **40x40이 적정선?** 대각선 ~56 → 11초. 기획서 범위 내

작업 항목:
- [ ] 맵 크기 결정 (40x40 또는 50x50)
- [ ] MAP_EXTENT 상수 업데이트
- [ ] 구역 크기 비례 확대
- [ ] 웨이포인트 좌표 재배치
- [ ] 프롭 슬롯 좌표 재배치
- [ ] 카메라 zoom 조정 (더 클로즈업)

### Phase C: 구역별 지형물 재설계

기획서 기준 4개 구역의 역할:

| 구역 | 시각 정체성 | 플레이 기능 | 필요한 구조물 |
|------|------------|------------|-------------|
| **A. 놀이기구** | 수직 실루엣, 따뜻한 색 조명 | 숨을 곳 많음, T2 레버 | 미끄럼틀(높이감), 정글짐(격자 은신), 그네(움직이는 요소) |
| **B. 창고** | 직선적, 차가운 색 조명 | 좁은 통로, 막다른 길 1개, T3 장치 | 컨테이너(벽 역할), 적재물(시야 차단), 좁은 통로(추격 긴장) |
| **C. 운동장 중앙** | 개방적, 노출 | 최단거리 vs 안전 선택 | 조회대(유일한 엄폐물), 골대(랜드마크), 넓은 빈 공간 |
| **D. 골목·출구** | 가로등 빛, 벤치 | 탈출 게이트, 구조 지점, T2 상자 | 가로등(트레이드오프 광원), 벤치, 화단, 탈출 게이트 |

추가 요소:
- **벽/울타리**: 구역 간 이동 경로를 제한하는 구조물. 중앙을 지나가거나 우회하거나 선택
- **통로**: B구역 창고의 좁은 통로. 술래에게 몰릴 수 있는 위험
- **막다른 길**: B구역에 1개만. "몰리는 공포"
- **트랩 위치 슬롯**: 구역에 상관없이 배치 가능한 트랩 앵커

클로드 디자인 활용 가능 영역:
- 구역별 배치도 시각화
- 색상 팔레트 확인
- 구조물 프리미티브 조합 레퍼런스

작업 항목:
- [ ] 구역별 구조물 목록 확정
- [ ] 구역 배치도 (좌표 기반)
- [ ] 벽/울타리 배치 — 이동 경로 설계
- [ ] 통로/막다른 길 설계
- [ ] 가로등 위치 + 광원 반경
- [ ] 트랩 슬롯 위치
- [ ] 탈출 게이트 후보 위치 (랜덤 선택용)
- [ ] 구역별 조명 색 차이 (따뜻한/차가운)

### Phase D: 맵 기믹

- [ ] 트랩: 시각적 표현 (어둠 속에서 약간 보이는? 완전 안 보이는?), 밟으면 빙결
- [ ] 가로등: 항상 밝은 구역, 술래 시야에도 노출 트레이드오프
- [ ] 탈출 게이트: 오브젝트 + 활성화 연출 + 랜덤 위치
- [ ] 데코 프롭 슬롯: 매 판 다른 배치물로 맵 인상 변화

---

## 작업 순서 (의존 관계 기반)

```
Phase A: 시야 시스템
    ↓ (시야가 확정돼야 맵 크기 체감 가능)
Phase B: 맵 크기 확대
    ↓ (맵 크기가 확정돼야 구조물 배치 가능)
Phase C: 구역별 지형물
    ↓ (구조물이 있어야 기믹 위치 결정 가능)
Phase D: 맵 기믹
```

---

## 확정 사항

- **시야 반경: 5m (5 unit)**
- **맵 크기: 50x50**
- **구조물 충돌: 있음** (캐릭터가 벽/구조물에 막힘)
- 대각선 횡단: ~70 unit / 이동속도 5 = 약 14초 (시야 5m이면 체감상 넓음)

## 미결정 사항

- 시야 구현 방식 최종 결정 (Fog vs 마스크 vs 하이브리드)
- 빙결 시 시야 처리 (확대? 유지? 서리 오버레이?)
- 충돌 구현 방식 (R3F 물리엔진 vs 수동 AABB)
- 클로드 디자인으로 구역 배치도 시각화할지

---

## 시간 예상

| Phase | 예상 | 비고 |
|-------|------|------|
| A. 시야 | 2~3시간 | Fog 설정 + 테스트 + 프롭 발광 조정 |
| B. 맵 확대 | 1시간 | 상수 변경 + 좌표 재배치 |
| C. 지형물 | 3~4시간 | 구조물 프리미티브 조합 + 배치 |
| D. 기믹 | 2시간 | 트랩, 가로등, 게이트 |

총 8~10시간. 하루 집중 작업으로 가능한 범위.
