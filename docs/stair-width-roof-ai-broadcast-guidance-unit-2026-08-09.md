# 계단 폭·옥상 AI 하강·3층 방송 안내 개선 단위

## 문제

- 계단 레인과 방화문이 좁아 플레이어와 AI가 교행하기 답답했다.
- 서쪽 옥상 중계기에 있던 `partner-2`가 펜트하우스 벽 앞 두 지점을 왕복하며 3층으로 내려오지 못했다.
- 기존 AI 회귀 테스트는 동료를 계단 목표 좌표로 옮긴 뒤 층 전환만 확인해 실제 길찾기 교착을 발견하지 못했다.
- 3층 방송 안내가 플레이 순서를 충분히 설명하지 않았고, 서버 시작 문구가 비공개 금기어가 포함된 원문을 노출했다.

## 변경

- 모든 U자 계단의 레인 유효 폭을 `3.0m → 3.3m`로 확대했다.
- 계단 방화문 구조 개구부를 `1.8m → 2.4m`, 실제 문짝 유효 폭을 `1.72m → 2.32m`로 확대했다.
- 옥상 순환 경로와 북서 펜트하우스 방화문 정면을 잇는 전용 AI 내비게이션 포털을 추가했다.
- 두 AI를 동·서 중계기에서 실제로 출발시켜 계단까지 걸어간 뒤 층 전환하는 회귀 테스트로 교체했다.
- 방송실 안내를 `E로 연결 → Q로 세 뜻 우회 설명 → AI 조사 대기 → 질문 시 특징 추가` 순서로 명확히 표시했다.
- 방송 시작 문구에서 금기어 원문을 제거하고 비공개 상태를 테스트로 고정했다.
