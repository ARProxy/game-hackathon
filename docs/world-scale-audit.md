# 월드 스케일·환경 미술 기준

> 기획 1·2의 학교 술래잡기 공간을 실제 사람 크기로 읽히게 만드는 제작 계약이다. 좌표와 에셋을 추가할 때 이 문서를 함께 확인한다.

## 기준 단위

- Three.js 좌표 `1`은 현실의 `1m`다.
- 플레이어 키는 `1.7m`, 발바닥은 바닥 `y`와 일치한다.
- 게임 동선을 위해 폭은 현실보다 최대 20% 넓힐 수 있지만, 높이와 가구 비율은 실제 치수를 유지한다.
- GLB는 파일의 원본 스케일을 믿지 않는다. 바운딩 박스를 측정하고 목표 실측 크기로 정규화한 뒤 배치한다.

## 환경 치수 계약

| 대상 | 목표 치수 | 현재 판단 |
|---|---:|---|

| 교실 출입문 | 폭 0.9–1.0m / 높이 2.0–2.1m | 모든 문을 후속 전수 점검 |
| 복도 | 폭 2.4–3.0m | 현재 3.6m, 추격 가독성을 위한 의도적 확장 |
| 학생 책상 | 0.68 × 0.48m / 상판 0.69m | 1차 교정 완료 |
| 학생 의자 | 좌판 0.42m / 좌면 0.43m | 1차 교정 완료 |
| 교사용 책상 | 1.35 × 0.70m / 상판 0.72m | 1차 교정 완료 |

## 발견한 원인

1. 기존 활성 가구는 상판·좌판·다리가 아니라 하나의 직육면체로 표현되어 사물이 아니라 상자로 읽혔다.
2. 학생 책상 상판 중심이 `y=0.38`이어서 플레이어 무릎보다 낮았다.
3. 비활성 Kenney GLB도 원본 크기가 현실 단위가 아니다. 측정값 기준 벤치는 폭 `0.40`, 싱글 침대 길이는 `1.13`이므로 스케일 1 배치는 절반 크기다.
4. 실외 구조물 일부는 술래잡기 엄폐 크기에 맞췄지만 실제 학교 시설 비율과 어긋난다. 골대·놀이기구·벤치·조명 순으로 교정한다.

## 에셋 채택 규칙

- 출처와 라이선스가 명확한 CC0를 우선한다.
- 현재 저폴리곤 색면 스타일과 맞지 않는 사실적 PBR 에셋은 라이선스가 좋아도 채택하지 않는다.
- 다운로드 전 미리보기에서 실루엣과 재질 수를 확인하고, 적용 전 바운딩 박스·삼각형·재질·텍스처 수를 기록한다.
- 반복 배치는 인스턴싱하고, 장식 에셋 때문에 기존 약 350 드로우콜 기준선이 크게 악화되지 않게 한다.

## 공식 CC0 후보

- Kenney Nature Kit: 교정된 나무·관목·돌로 경계 풍경을 만든다.
- Kenney City Kit (Suburban): 정문 너머 원경 건물과 주차장 소품 후보로 검토한다.
- Kenney Building Kit: 이미 사용 중이며 학교 외벽 모듈 보강 후보로 유지한다.

## 다음 환경 패스

1. 운동장 골대·조회대·벤치·가로등을 실측 비율로 교정한다.
2. 본관 외벽의 검정 단색 면을 재료 구획, 창틀, 기단으로 나눠 깊이를 만든다.
3. 체육관 내부와 운동장 경계에 역할이 읽히는 소품을 배치한다.
4. CC0 후보를 별도 샌드박스 장면에서 측정한 뒤, 현재 스타일과 맞는 것만 정식 편입한다.
