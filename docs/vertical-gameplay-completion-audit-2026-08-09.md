# 수직 게임플레이 완성 감사

> 작업일: 2026-08-09  
> 범위: 옥상 종료부터 파이널 탈출까지, 추가 승인 없이 기획 정본으로 확정 가능한 항목  
> 기준 문서: `game-design-v4.md`, `game-design-v5.md`, 층별 미션·학교 구조 계약

## 감사 결론

현재 빌드는 옥상 협동 신호, 층별 미션의 기본 서버 판정, 미니맵과 AI 이동까지는 연결되어 있다. 그러나 실제 한 판의 위협 곡선과 수직 동선에는 다음 네 가지 진행 차단 또는 기획 이탈이 남아 있다.

1. 옥상 완료 뒤 전원이 내려왔는지 확인하지 않아 옥상이 영구 안전지대로 남을 수 있다.
2. 3층은 전체 구간이 `암시` 상태라 후반의 큰 소리·직접 목격 기반 제한 추격이 발생하지 않는다.
3. 1층 차단자는 서버 전용 상태를 클라이언트가 해석하지 못해 이동 속도가 `NaN`이 될 수 있고, 구역 공유가 실제로는 정밀 좌표에 가깝다.
4. 진행 중 현재 층으로 내려가는 길만 제공되어, 기획에 명시된 바로 이전 층 복귀와 actor 안전 검사 후 폐쇄가 구현되지 않았다.

## 구현 단위

### 1. 옥상 종료와 슬라이딩 2개 층

- 옥상 미션 완료 시 3층 방화문을 연다.
- 살아 있는 도망자 전원이 3층으로 내려오기 전에는 옥상을 `closing_pending`으로 유지한다.
- 전원 하강 후 옥상을 닫아 재진입을 거부한다.
- 2층 이후에는 현재 층과 바로 이전 층 사이의 왕복 계단을 서버 권위로 허용한다.
- 두 단계 이전 층은 자동으로 접근 목록에서 제외한다.
- 전이 이벤트에 접근 가능 층과 폐쇄 대기 층을 포함해 HUD·미니맵이 같은 상태를 사용한다.

### 2. 술래 등장과 층별 위협 곡선

- 옥상에서는 술래 이동·소리 수신·포획 판정을 모두 비활성화한다.
- 3층 미션 장치를 활성화하기 전에는 실루엣과 경고만 제공한다.
- 3층 방송 미션을 시작하면 임의 시간값 없이 명확한 게임 이벤트로 후반 제한 추격을 연다.
- 제한 추격은 직접 목격과 큰 소리만 추적하고, 정보가 끊기면 무작위 완전 수색을 하지 않는다.
- 2층부터 완전 추격, 1층부터 두 술래 협공, 파이널에서는 고정된 광분 상태를 유지한다.
- 서버 포획 판정도 해당 위협 상태와 활성 술래 수를 확인한다.

### 3. 추격자·차단자 역할 분리

- 차단자의 `BLOCK`, `GUARD`, `PATROL` 상태를 클라이언트 이동 계약에 추가한다.
- 차단자는 사이렌 대신 정적인 손전등으로 구분한다.
- 얼어 있는 도망자 경계 타이머를 실제 첫 경계 시점부터 시작하고 제한 후 해제한다.
- 공유 좌표는 actor의 실시간 위치나 계산된 측면 좌표가 아니라 월드 계약의 구역 중심으로 양자화한다.
- 차단자 순찰 목표는 현재 층 내비게이션 노드에서 선택해 맵 밖 좌표를 만들지 않는다.
- 차단 상태에서는 직접 포획 요청을 보내지 않는다.

### 4. 층별 미션과 파이널 교착 방지

- AI 층 이동 목표와 열린 층 계약을 왕복 계단 규칙에 맞춘다.
- 운동장 3인 장치와 지하 3장치가 인간 또는 AI 이탈로 영구 교착되지 않는지 자동 플레이로 검증한다.
- 단계 완료, 술래 등장, 다음 문 개방을 서로 다른 피드백으로 전달한다.
- 최종 주문과 탈출문 개방 후 선택된 경로에서만 탈출하도록 서버 판정을 유지한다.

## 이번 작업에서 고정하지 않는 값

다음 항목은 기획서가 플레이 테스트 조정 대상으로 명시하므로 새 상수를 임의로 확정하지 않는다.

- 3층 제한 추격의 초 단위 지속시간과 포획 후 유예 시간
- 시간 강화의 최종 분 단위 경계값
- 차단자 호출 지연과 문별 선점 확률의 최종 수치

이번 구현은 이미 확정된 단계·이벤트·권한 계약과 치명적 교착을 먼저 완성하고, 수치 조정이 가능한 구조와 테스트를 남긴다.

## 완료 게이트

- 옥상에서 술래 포획 불가, 전원 하강 후 옥상 재진입 불가
- 3층 전반 `omen`, 방송 시작 뒤 `limited_hunt`, 2층 `full_hunt`
- 1층 두 번째 술래가 유효한 속도와 맵 내부 좌표로 이동
- 2층↔3층, 1층↔2층, 파이널↔1층 왕복 동선 승인
- 서버 전체 테스트, 클라이언트 빌드·린트, compact school 계약 검증 통과
- 작업 단위별 문서와 Gitmoji 커밋 생성
