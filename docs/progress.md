## 원칙

- Phase N이 완성되지 않으면 Phase N+1로 넘어가지 않는다
- 각 Phase 끝에 "검증 기준"을 통과해야 다음으로 간다
- 시간이 부족하면 Phase 5를 축소하고 Phase 6(제출물)은 반드시 지킨다
- 어느 Phase에서 멈춰도 그 시점까지의 결과물로 제출 가능한 상태를 유지한다
