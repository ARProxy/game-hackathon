# 문·바닥 깊이 깜빡임 수정 단위

## 사용자 피드백

문과 바닥 주변에 하나의 회색 구조물이 겹쳐 보이고, 카메라가 움직일 때 화면이 계속 깜빡이는 현상이 있었다.

## 확인한 원인

- 모든 문틀을 좌우 문선과 인방이 아니라 출입구 전체 크기의 회색 박스 하나로 렌더링했다.
- 회색 박스와 동적 문짝이 같은 출입구 평면을 점유해 깊이 버퍼가 어느 면을 앞에 그릴지 불안정했다.
- 회색 박스가 열린 문 뒤 공간까지 가려 문이 아니라 판이 겹친 것처럼 보였다.
- 방별 바닥 마감의 아래 면과 원본 슬래브 사이 간격이 5.5mm에 불과해 원거리 카메라에서 깊이 정밀도가 부족했다.
- 얇은 바닥 장식은 일반 구조물과 같은 렌더 재질 묶음에 들어가 별도 깊이 우선순위가 없었다.

## 수정

- 42개 모든 문틀을 좌측 문선, 우측 문선, 상부 인방의 3개 부재로 다시 구성했다.
- 출입구 전체를 막던 회색 박스를 제거해 문짝과 문틀의 평면 중첩을 없앴다.
- 방 바닥 마감을 슬래브에서 최소 2.8cm 분리했다.
- 바닥 마감, 복도 유도선, 옥상 이음매, 점검 발판, 운동장 선 같은 얇은 표면을 별도 인스턴스 묶음으로 분리했다.
- 얇은 표면 재질에 깊이 오프셋을 적용해 먼 카메라에서도 원본 바닥보다 안정적으로 앞에 렌더링한다.

## 회귀 방지

- 모든 문에 정확히 3개의 문틀 부재가 존재하는지 학교 구조 계약에서 검사한다.
- 문틀 부재는 비충돌 시각 구조물이어야 한다.
- 모든 방 바닥 마감은 원본 층 높이보다 최소 2.5cm 이상 분리되어야 한다.

## 검증

- 학교 구조 계약 통과: 문 42개, 문틀 부재 126개
- 프로덕션 빌드 통과
- 린트 오류 0, 기존 경고만 유지
- 인앱 참조 카메라의 3층 근접 렌더에서 회색 출입구 판이 제거되고 문 개구부와 바닥 마감이 분리된 것을 확인
