# 2층 인터폰 재확인 협동·무교착 단위

## 문제

2층 인터폰은 AI가 다른 교실의 기호를 읽고 플레이어가 전달하는 협동 구조였지만, 답이 틀리면 시스템이 남은 시도 횟수만 줄였다. 세 번 실패 뒤에도 내부적으로는 재시도가 가능하면서 HUD는 `남은 시도 0회`로 보여 진행이 막힌 것처럼 느껴졌고, AI는 오답 이후 아무 판단도 말하지 않았다.

## 수정

- 음성 실패 횟수는 통과를 막는 제한이 아니라 AI 힌트 강도를 높이는 기준으로 변경했다.
- 세 번 이상 실패해도 필수 미션은 잠기지 않으며 언제든 다른 표현으로 재시도할 수 있다.
- 서버가 첫 누락 또는 순서 불일치 묶음의 위치를 계산한다.
- AI 동료가 `N번째 묶음`, `색·도형 누락`, `순서 뒤바뀜` 중 확인된 사실만 질문으로 되돌린다.
- HUD는 남은 시도 0회 대신 AI 보고를 듣고 재시도할 수 있음을 안내한다.
- 실패 발화의 소리 핑과 2층 완전 추격은 그대로 유지해 무제한 재시도가 무료 행동이 되지 않게 한다.

## 협동 루프

1. AI가 떨어진 교실의 색·도형 순서를 관찰해 보고한다.
2. 플레이어가 인터폰에서 순서를 전달한다.
3. 누락이나 순서 오류가 있으면 AI가 처음 어긋난 묶음을 짚어 재확인을 요청한다.
4. 플레이어는 다른 표현으로 다시 전달한다.
5. 성공하면 1층 방화문이 열린다.

## 검증

- 층별 미션·WebSocket·AI·술래 선별 테스트 120개 통과
- WebSocket 통합 테스트에서 오답 뒤 `retry_available=true`, `exhausted=false`와 AI 확인 질문을 확인
- STT 실패가 누적돼도 필수 진행이 영구 잠기지 않는 단위 테스트 추가
