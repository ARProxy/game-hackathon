# 1층 CCTV 음성 관제·AI 원격 이동 단위

## 기획 이탈

기획 정본의 1층 대표 미션은 인간이 경비실 CCTV를 보며 화면을 볼 수 없는 AI에게 방향을 안내하는 관제 미션이다. 기존 구현은 AI가 원격 B 장치 앞에 자동으로 서고 인간이 A 장치에서 `E`를 한 번 누르는 동시 스위치였다. 음성, 관찰, AI 이해와 이동이 없어 옥상 이후의 핵심 재미가 사라졌다.

## 새 플레이 흐름

1. 인간이 1층 경비실 CCTV 콘솔에서 `E`를 눌러 관제를 시작한다.
2. HUD에 CCTV가 포착한 첫 안전 방향 표식이 나타난다.
3. 인간이 `Q` 음성 또는 텍스트로 `직진`, `왼쪽`, `오른쪽`의 의미를 우회 표현해 전달한다.
4. AI는 서버가 승인한 방향마다 실제 복도 체크포인트로 이동한다.
5. 교차로 도착 시 AI가 무전으로 멈춤·도착을 보고하고 다음 안내를 기다린다.
6. 잘못된 방향이면 AI가 막힌 통로를 보고하며 플레이어는 다른 표현으로 교정한다.
7. 세 안내가 끝나 AI가 원격 B 장치에 도착하면 인간이 A 장치에서 `E`를 누르고 두 장치를 함께 해제한다.
8. 성공하면 운동장 또는 지하 파이널 경로가 공개되고 두 술래가 광분한다.

## 의미 판정

고정 문장 하나만 받지 않고 다음 표현을 같은 의도로 처리한다.

- 직진: `직진`, `앞으로`, `곧장`, `복도 끝`, `계속 가`
- 왼쪽: `왼쪽`, `좌회전`, `서쪽`
- 오른쪽: `오른쪽`, `우회전`, `북쪽`

틀린 방향은 미션을 초기화하지 않는다. 플레이어는 추격 중 다시 설명할 수 있지만 인간 발화는 계속 술래의 소리 단서가 된다.

## AI·술래 계약

- AI는 관제 시작 전 원격 장치로 자동 직행하지 않고 첫 안내를 기다린다.
- 승인된 안내 뒤에만 다음 체크포인트를 목표로 삼는다.
- 마지막 체크포인트 도착 전에는 동시 장치를 작동할 수 없다.
- 교차로·장치 보고는 짧은 무전 모드로 전파된다.
- 1층의 추격자·차단자 2인 협공과 서버 포획 판정은 유지된다.

## 검증

- 1층·전체 수직 자동 플레이·AI·WebSocket·술래 선별 테스트 125개 통과
- 클라이언트 프로덕션 빌드 통과
- 캠퍼스 구조·충돌 계약 검증 통과
- 잘못된 방향 교정, 세 방향 승인, 체크포인트 목표 변경, 최종 장치 도착 전 잠금 테스트 추가
