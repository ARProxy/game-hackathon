# 파이널 월드·문·길찾기 권위 정합화 작업 기록

> 작업일: 2026-08-09  
> 작업 단위: 운동장·지하 파이널 실공간, 술래 길찾기, 방화문·미니맵 서버 권위  
> 상태: 구현·자동 검증 완료

## 발견한 진행 차단

- 지하 기계실의 세 칸막이가 출입구 없는 연속 벽이라 시작점에서 두 번째 이후 설비와 탈출구로 갈 수 없었다.
- 운동장과 지하에는 서버 술래 내비게이션 노드가 없어 추격자는 레거시 좌표로 폴백하고 차단자는 제자리 순찰에 빠질 수 있었다.
- 넓은 운동장의 열린 직선에서도 길찾기가 6m마다 가장 가까운 노드를 다시 선택해 앞뒤 왕복할 수 있었다.
- 옥상 방화문은 `active_floor`만 보아 전원 하강 뒤 서버가 옥상을 닫아도 열린 표시가 남았다.
- 미니맵은 현재 활성 층으로 가는 하강 경로만 표시하고, 서버가 허용한 직전 층 복귀 경로는 표시하지 않았다.

## 구현

- 지하 칸막이 세 곳에 실제 수동문과 통과 가능한 개구부를 만들었다.
- 지하 의미 슬롯 뒤에 급수 밸브, 배전반, 비상 발전기 설비를 실물 구조물로 배치했다.
- 운동장에는 북쪽 진입구와 남쪽 탈출구를 남긴 연속 펜스, 트랙 구획선과 3인 협동 장치 A/B/C를 배치했다.
- 운동장 8개 순환 노드와 지하 5개 설비실 연결 노드를 클라이언트 골조에서 생성하고 서버 충돌 계약으로 내보냈다.
- 서버 길찾기는 거리에 상관없이 벽 교차가 없는 목표를 직접 향하게 해 열린 공간의 노드 왕복을 제거했다.
- 단계 방화문은 `active_floor` 추정 대신 서버 `accessible_floors`에 출발·목적 층이 모두 있을 때만 열린다. 옥상 폐쇄가 끝나면 문도 닫힌다.
- 미니맵은 현재 미션을 첫 목표로 유지하면서 활성 층에서 직전 층으로 돌아가는 보조 경로도 함께 표시한다.

## 서버·클라이언트 공통 계약

- 운동장: 장벽 6개, 내비게이션 노드 8개
- 지하: 장벽 23개, 내비게이션 노드 5개
- 전체 compact school: 박스 1,897개, 원통 16개, 문 42개, 방 24개, 내비게이션 노드 97개, 서버 장벽 694개
- 운동장 협동 장치의 실제 좌표를 `FIELD_FINAL_STATION_A/B/C` 의미 슬롯과 자동 대조한다.
- 모든 내비게이션 링크가 벽을 통과하지 않고, 모든 노드 아래에 실제 보행 바닥이 있는지 검사한다.

## 검증

- 지하 입구에서 세 설비와 탈출구까지 서버 술래 이동 반복 검증 추가
- 운동장 입구에서 세 협동 장치와 탈출구까지 서버 술래 이동 반복 검증 추가
- 운동장·지하의 장벽/내비게이션 누락 방지 테스트 추가
- 서버 전체 테스트: `340 passed, 1 skipped`
- 클라이언트 프로덕션 빌드 통과
- 클라이언트 린트 오류 0개(기존 Fast Refresh·레거시 승강기 경고 유지)
- compact school 구조·충돌·의미 슬롯 계약 검증 통과

## 기획 경계

이번 단위는 새 메카닉이나 튜닝 수치를 만들지 않았다. 이미 정본에 확정된 파이널 경로, 3인 장치 위치, 지하 설비 순서, 현재·직전 층 접근 정책을 실제 이동 가능한 월드와 서버 권위 표현으로 완성했다.
