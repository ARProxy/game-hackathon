# 설정·AI 음성·접근성 구현 단위

- 기준일: 2026-08-09
- 정본: `game-design-v2.md` 5.4, `game-design-v4.md` 9~11장

## 실제 연결 범위

- 전체·효과·환경·AI 음성 음량을 분리하고 Web Audio 효과음, 환경 펄스, 브라우저 AI 음성에 각각 적용했다.
- AI 동료 자막을 Web Speech Synthesis로 즉시 발화한다. `whisper`, `shout`, `radio`, `intercom`, `silent` 모드에 따라 음량·속도·피치를 달리한다.
- AI 음성에 비공개 금기어가 포함되면 합성 직전에 `그 대상`으로 치환해 플레이어에게 정답을 누설하지 않는다.
- 마이크 입력 장치를 열거·선택하고 실제 선택 장치를 1.8초간 열어 입력 크기와 권한을 테스트한다.
- 한국어/영어 음성 인식 언어를 Q키 Push-to-Talk의 Web Speech Recognition 설정에 적용한다.
- 자막 표시·크기, 그래픽 품질, 그림자, 렌더 배율, 마우스 감도, Y축 반전을 실제 UI·Canvas·카메라에 연결했다.
- 광과민성 보호를 켜면 추격 붉은 경광의 강도를 낮추고 점멸 애니메이션을 없애며 후처리 변동도 줄인다.
- 시작 화면과 Esc 일시정지 화면이 하나의 영속 설정 저장소를 공유한다.
- 마이크 선택은 브라우저가 허용하는 실제 장치 입력 테스트에 적용된다. Web Speech Recognition 자체의 장치 라우팅은 브라우저 API가 제공하지 않으므로 인식은 OS/브라우저 기본 입력을 사용한다.
