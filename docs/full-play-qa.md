# 솔로 전체 플레이 QA

> 기준일: 2026-08-06  
> 범위: 타이틀 → 솔로 설정 → 온보딩 → 금기어 → 미션 → 주문 → 탈출/실패 → 결과

## 사고 흐름

전체 플레이 QA는 기능 존재 여부와 플레이 체감을 분리한다. 서버 이벤트 계약과 production build는 자동화로 반복 검증하고, 밝기·조작감·사운드·3~5분 플레이 시간은 실제 브라우저 플레이로만 완료 처리한다. 자동 테스트 통과를 실플레이 완료로 과장하지 않는다.

## QA 중 발견한 문제

### 개발 모드 WebSocket 초기 연결 경합

React Strict Mode가 effect를 설치 직후 한 번 정리할 때 아직 연결 중인 WebSocket을 닫아 브라우저가 경고를 출력한다. 이후 두 번째 연결은 성공하므로 진행 차단은 아니지만 실제 네트워크 장애처럼 보인다. 연결 생성을 다음 이벤트 루프로 미루고 cleanup에서 예약을 취소해 개발 모드에서도 소켓을 한 번만 만든다.

## 실플레이 확인 대기

- [ ] 타이틀부터 결과까지 승리 경로를 마우스·키보드로 직접 완주
- [ ] 금기어 빙결 후 AI 구조와 제한시간 실패를 각각 확인
- [ ] 틀린 후보 설명 → 확인 질문 → 표현 교정 확인
- [ ] 틀린 주문이 답을 노출하지 않고 추격 비용을 만드는지 확인
- [ ] 플레이 시간 3회 측정 후 중앙값이 3~5분인지 확인
- [ ] 조명, 보행, 발소리, 술래 방향음의 체감 확인
- [ ] 서버 미실행 상태에서 데모 모드 완주 확인

## 다음 판정

위 수동 항목에서 진행 차단 버그가 나오면 제출물 작업보다 먼저 수정한다. 시간만 짧거나 길다면 인위적 대기시간을 넣지 않고 탐색 거리, AI 확인 질문, 술래 압박과 미션 동선으로 조절한다.
