## 대조 결과

- ZIP의 `campus.js`와 현재 `client/src/game/campusV4Data.js`는 린트 주석 한 줄 외에 동일하다.
- ZIP의 `elevator.js`와 현재 `client/src/game/claudeDesign/elevator.js`도 빈 줄 외에 동일하다.
- `textures.js`는 현재 `textures.ts`에 Three.js 타입과 캐시 계약을 더한 형태로 이미 포팅되어 있다.
- 따라서 좌표 데이터를 다시 덮지 않고, 원본 렌더러와 달라진 해석 계층을 교정했다.

## 적용한 렌더 계약

1. 바닥·천장 `plates`를 원본처럼 두께 0.05m의 박스로 렌더한다.
2. `visuals.e` 발광 여부를 일반 표면과 분리해 유도등·표식이 실제 발광 재질을 사용한다.
3. 유리·물은 불투명 PBR 재질군과 분리한다.
4. 서버의 `accessible_floors`를 실제 렌더 가시층과 연결한다.
5. 개발용 숫자키 층 필터는 개발 모드에서만 서버 가시층을 덮어쓴다.

## 유지한 게임 계약

- 서버 의미 슬롯과 벽·스폰·미션 좌표
- Rapier 구조 충돌체와 바닥 지지면
- 인터랙티브 문 122개
- 엘리베이터 2대와 서버 층 이동 승인
- 현재 캐릭터, 미션, 술래와 수직 진행 상태
