## 2. 제출 폼용 소개

### 한 줄 소개

게임이 플레이어의 실제 대화를 몰래 학습해 금기어로 바꾸는 AI 음성 협동 학교 탈출 호러.

### 게임 설명

『얼음, 땡!』은 인간 1명과 독립 AI 동료 2명이 밤의 학교 옥상부터 아래층으로 내려가며 음성 퍼즐을 해결하는 3인칭 탈출 게임입니다. 말하면 술래가 소리를 추적하고, 플레이 중 자주 쓴 표현이 비공개 금기어가 되어 다시 말하면 얼어붙습니다. 플레이어는 AI의 우회 발화와 빙결 결과로 위험한 말버릇을 추론하고, AI의 오해를 다른 표현으로 교정해야 합니다. 옥상, 3층, 2층, 1층을 거쳐 운동장 또는 지하 파이널의 주문과 실제 게이트 통과까지 서버가 판정합니다.

### AI 활용 요약

로컬 Ollama는 인간 발화에서 서버가 추출한 후보의 순위를 추천하며, Kiwi와 결정론적 규칙이 금기어 적용을 확정합니다. AI 동료 두 명은 위치, 기억, 목표, 술래 목격과 구조 판단을 독립적으로 유지하고 모든 후보 행동을 비교합니다. 술래는 인간과 AI를 함께 대상으로 시야, 소리, 최근 기억과 탈출구 위협을 종합합니다. 생성 AI가 실패하거나 없어도 규칙 기반 폴백으로 전체 게임을 완주할 수 있습니다.

### 차별점

- 음성 채팅이 협동 수단이면서 퍼즐이자 위치 노출 위험이다.
- 사전 공개 목록이 아니라 플레이 중 말버릇이 비공개 금기어로 변한다.
- AI가 정답을 알려주는 대신 오해하고 질문하며 실제 행동을 바꾼다.
- 생성 모델은 추천만 하고 성공·실패는 검증 가능한 서버 규칙이 결정한다.

## 3. 60초 시연 영상 구성

| 시간 | 화면 | 전달할 메시지 |
|---|---|---|
| 0~5초 | 옥상 AI 신호 미션과 말버릇 관찰 | 게임이 실제 미션 대화를 학습 |
| 5~12초 | 3층 방송실 진입과 금기어 발화 | 미션에 얽힌 말이 함정이 됨 |
| 12~18초 | 얼음 카운트다운, AI 구조 대사 | 실제 빙결과 “땡” 협동 |
| 18~26초 | 붉은 시야, 술래 근접·추격 | 발견 상황에만 사이렌 경고 |
| 26~36초 | 2층·1층 음성 협동 | 기호 전달과 CCTV 안내 |
| 36~52초 | 운동장 동시 장치·주문·탈출 | 한 판의 협동 결말 |
| 52~56초 | 결과 화면의 금기어 세대 공개 | “게임이 내 말을 배웠다” |

최종 파일은 H.264 1280×720 30fps, AAC 48kHz stereo, 56초다. 마이크 권한 팝업이나 서버 터미널은 포함하지 않는다.

## 5. 제출 직전 명령

```bash
docker build -t ice-ddaeng:submission .
docker run --rm -p 8000:8000 ice-ddaeng:submission
```

다른 터미널에서 `curl http://localhost:8000/health`가 `{"status":"ok"}`를 반환하는지 확인한 뒤 브라우저에서 `http://localhost:8000`을 연다. 메모리 기반 세션이므로 배포 인스턴스와 worker는 각각 1개로 유지한다.
