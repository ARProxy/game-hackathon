## 1. 프로젝트 요약

### 한 줄 소개

**게임이 플레이어의 실제 대화를 몰래 학습해 금기어로 바꾸는 AI 음성 협동 학교 탈출 호러.**

밤의 학교 옥상에서 깨어난 플레이어는 두 AI 동료와 층별 방탈출 미션을 해결한다. 대화는 협동 수단이지만 모든 발화는 술래에게 소리 흔적을 남긴다. 플레이 중 자주 쓴 말과 현재 미션에 필요한 표현은 비공개 금기어 후보가 되고, 그 말을 다시 하면 즉시 얼어붙는다. 동료가 제한 시간 안에 “땡”으로 구조하지 못하면 탈락한다.

### 차별점

- 음성 채팅이 **협동 수단·퍼즐 입력·위치 노출 위험**을 동시에 담당한다.
- 고정 목록이 아니라 실제 대화와 미션 문맥으로 금기어가 계속 변한다.
- AI 동료는 정답 NPC가 아니라 관찰하고, 오해하고, 질문하고, 구조하는 행위자다.
- 술래는 인간과 AI 모두를 시야·청각·기억으로 추적하는 능동 사냥꾼이다.
- 생성 모델은 후보와 표현만 제안하고 성공·실패는 서버가 판정한다.

### 경험 목표

| 시간 | 플레이어가 느껴야 하는 것 | 이를 만드는 시스템 |
|---|---|---|
| 시작 1분 | 말을 해야 하지만 말하면 위험하다 | 옥상 협동 신호, 소리 핑, 비공개 관찰 |
| 첫 3분 | 학교가 내 말버릇을 배운다 | 동적 금기어 활성, 방송실 우회 설명 |
| 중반 | AI가 나와 별개로 판단한다 | 분산 탐색, 확인 질문, 구조 우선순위 |
| 후반 | 사냥이 공간을 압박한다 | 추격형·차단형 술래, 문과 LOS, 사이렌 |
| 결말 | 우리가 함께 살아나왔거나 누군가를 잃었다 | 개별 생존 판정, 최종 주문, 결과 회고 |

## 2. 세계관과 핵심 판타지

정전 이후 봉쇄된 학교. 교내 방송은 도망자들의 말을 수집하며 “말하면 얼어붙는 규칙”을 계속 다시 쓴다. 옥상의 안전한 침묵은 잠깐뿐이다. 방송실 문이 열리는 순간 네 발로 기어오는 변이 술래가 깨어나고, 아래층으로 갈수록 학교는 더 많은 단어와 더 많은 사냥꾼을 갖는다.

플레이어의 판타지는 강한 전투원이 되는 것이 아니다. **위험한 말을 피해 의미를 전달하고, 불완전한 AI 동료와 신뢰를 만들며, 누군가 얼거나 잡혔을 때 되돌아가 구조하는 것**이다.

## 3. 한 판의 흐름

    타이틀 / 방 생성·참가
       ↓
    옥상: 이동·발화·AI 지시 학습 / 인간 발화 3회 안전 관찰
       ↓
    첫 비공개 금기어 활성 / 3층 개방
       ↓
    3층 방송실: 의미 추론 음성 미션 / 첫 금기어 빙결과 AI 구조
       ↓
    2층 인터폰: AI가 본 색·도형을 규칙에 맞게 음성 전달
       ↓
    1층 CCTV: 인간이 화면을 보고 AI에게 방향 안내 / 술래 2인 협공
       ↓
    운동장 또는 지하: 분산 장치 → 최종 주문 → 실제 게이트 통과
       ↓
    결과: 생존자, 금기어 세대, 위반과 술래 강화 과정 공개

현재 층을 완료하면 다음 층이 열린다. 이미 연 층은 다시 방문할 수 있어 놓친 단서와 얼어붙은 동료를 구조할 수 있다. 아직 완료하지 않은 층과 파이널은 서버가 차단한다.

## 4. 층별 미션과 긴장 곡선

| 구간 | 공간·미션 | 협동의 핵심 | 술래 압박 |
|---|---|---|---|
| 옥상 | 물탱크·안테나 신호 순서 | 인간과 AI가 장치를 나눠 조작 | 포획 비활성, 불길한 예고 |
| 3층 | 방송실 증거 3개 비교 | 금기어를 피한 특징·관계 설명 | 변이 사냥개 첫 등장, 제한 사냥 |
| 2층 | 인터폰 색·도형 릴레이 | AI 관찰 → 인간 변환 발화 | 국지 정전, 청각 강화 |
| 1층 | CCTV 음성 관제 | 인간 화면 → AI 이동 지시 | 추격형 + 차단형 협공 |
| 운동장 | 조회대·설비·주문 | 개방 공간에서 유인·장치 분담 | 전 술래 광분, 출구 돌진 |
| 지하 | 배전반·분산 장치·주문 | 폐쇄 공간의 정보 전달 | 시야 제한, 길목 압박 |

서버가 라운드 시드로 옥상 입력 순서, 방송실 증거 위치, 인터폰 조합과 규칙, CCTV 경로, 파이널 분기와 장치 순서를 바꾼다. LLM은 사건 카드의 문장과 허용된 규칙 하나를 제안하지만 새로운 방, 좌표, 장치와 성공 조건은 만들 수 없다.

## 5. 비공개 동적 금기어

### 생명주기

1. 인간의 첫 유효 발화 3개는 안전한 관찰 구간이다.
2. Kiwi가 명사와 미션 관련 표현을 추출하고 서버가 허용 후보를 만든다.
3. Ollama가 빈도·최근성·미션 연관 후보의 순위를 추천한다.
4. 서버가 검증한 최대 3개 단어를 **다음 발화부터** 원자적으로 적용한다.
5. 활성 후 유효 발화 5개와 최소 45초를 모두 만족하면 갱신한다.
6. 이전 세대에서 최소 한 단어를 유지하고 한 번에 최대 두 단어만 바꾼다.
7. 변경 순간 화면 중앙을 가르는 붉은 선과 `금기어 변경` 경고만 보여준다.
8. 파이널 진입 시 세대를 잠그고 최종 주문을 보호한다.
9. 결과 화면에서만 실제 단어와 세대별 변화·위반을 공개한다.

### 정보 비대칭과 공정성

- 플레이 중 단어, 글자 수, 적중 단어와 교체 후보를 인간에게 공개하지 않는다.
- 현재 처리 중인 발화에 새 세트를 소급하지 않는다.
- 정답 문자열, 구조 명령과 최종 주문은 보호어로 둔다.
- 방향·재질·장치·장소처럼 우회 설명이 가능한 미션 어휘는 위험 후보가 될 수 있다.
- 높은 신뢰도의 정확·형태소 판정만 빙결시키고 낮은 발음 유사도는 재표현을 요청한다.
- 첫 위반부터 술래 속도 1.10배, 두 번째 1.25배와 청각, 세 번째 1.35배와 시야·추적 기억을 강화한다.

## 6. 얼음·땡·탈락의 협동 드라마

금기어 위반 즉시 화면에 서리 막과 얼음 균열이 번지고 이동이 멈춘다. 30초 구조 카운트다운이 시작되며, 가까운 AI는 위험 회피보다 구조를 우선한다. 먼 AI는 마지막 술래 위치와 경로를 피해 접근한다. 구조 반경에서 “땡” 판정이 나면 얼음이 깨지고 다시 움직일 수 있다.

AI도 술래의 실제 대상이다. 술래에게 잡힌 동료는 넘어지고 사라지며 `TEAM LINK LOST / AI 동료 제거됨` 경보와 음성이 플레이어에게 전달된다. 따라서 동료는 장식이 아니라 잃을 수 있는 전력이며, 결과 화면의 생존자 구성도 달라진다.

## 7. AI 동료 설계

각 동료는 현재 위치·시야, 조사 기록, 플레이어 지시, 술래 마지막 목격, 위험도, 구조 요청, 현재 목표와 목표 유지 시간을 독립적으로 가진다.

| 행동 후보 | 주요 평가 값 | 결과 예시 |
|---|---|---|
| 술래 회피 | 가시선, 거리, 최근 목격, 안전 노드 | 문 뒤로 후퇴하거나 다른 계단 선택 |
| 동료 구조 | 빙결 잔여 시간, 거리, 술래 위험 | 가까우면 즉시 “땡”, 멀면 우회 접근 |
| 지시 수행 | 명령 구체성, 대상 후보 점수, 신뢰도 | 확신하면 조사, 애매하면 확인 질문 |
| 미션 참여 | 현재 단계, 필요한 장치, 역할 공백 | 인터폰 수신, CCTV 경로 이동 |
| 추종·합류 | 층 차이, 목표 유지 시간, 팀 분산 | 임무를 마친 뒤 플레이어에게 합류 |
| 파이널 탈출 | 장치 상태, 게이트 위험, 생존자 | 유인·장치·탈출 중 효용이 높은 행동 |

AI가 색·모양·재질·쓰임새 설명을 받으면 모든 관찰 후보를 같은 기준으로 점수화한다. 최고와 차점이 비슷하면 임의 행동 대신 질문한다. 선택 이유와 신뢰도를 서버 이벤트로 남겨 오해와 교정이 플레이 안에서 드러난다.

## 8. 술래와 공포 설계

### 역할과 외형

- **S-01 추격자**: 길게 찢어진 몸, 과장된 네 다리, 노출된 갈비뼈와 척추 돌기, 벌어진 턱과 붉은 눈을 가진 변이 사냥개. 발견하면 머리를 비틀고 보폭과 턱 움직임이 난폭해진다.
- **S-02 차단자**: 접힌 인간형 실루엣과 차가운 탐조등. 직접 추격보다 계단·문·탈출구 길목과 강한 소리를 선점한다.

### 감지와 상태

    순찰/탐색 → 소리 조사 → 마지막 흔적 수색 → 직접 발견 → 추격
          ↑                                               ↓
          └──────── 시야 상실·기억 만료·문 차단 ────────┘

술래는 살아 있는 인간과 AI 모두를 후보로 보고 거리, 가시선, 소리 세기, 최근 기억, 빙결 상태와 탈출구 위협을 합성한다. 방송실 입장 직후에는 짧은 포획 유예가 있지만 그동안 낸 소리는 사라지지 않고 유예 종료 후 조사 목표가 된다.

화면 전체의 붉은 경보와 사이렌은 같은 층 술래가 약 8.5m 안에 있거나 인간을 직접 발견·추격할 때만 켜진다. 평상시에는 통일된 저음 BGM `exploration-dark-ambient.mp3`를 반복하고, 추격·빙결·금기어 변경은 짧은 효과음과 심박으로 층을 쌓는다.

## 10. 런타임 AI 프롬프트 상세

### 10.1 동적 금기어 후보 순위

입력은 최근 인간 발화 최대 12개, 현재 비공개 세트, 서버가 관찰한 미션 연관 후보와 전체 허용 후보다. 출력은 JSON 단어 배열 하나다.

    역할: 한국어 음성 협동 게임에서 실제로 자주 쓰며 다시 말할 표현 선택
    제약 1: 미션 연관 후보가 있으면 최소 하나 포함
    제약 2: 관찰 후보 밖의 단어 생성 금지
    출력: {"words":["단어1","단어2","단어3"]}

응답 후 서버는 허용 목록 일치, 두 글자 이상, 보호어·중복 제외를 검사한다. 미션 관련 관찰어를 첫 슬롯에 보장하고, 갱신 시 이전 단어 최소 하나를 유지한다. 모델 실패·잘못된 JSON·시간 초과에서는 `빈도×2 + 최근성 + 미션 가중치 4`의 로컬 순위를 사용한다.

### 10.2 라운드 사건 카드

    역할: 학교 공포 음성 협동 게임의 한 판 사건 카드 작성
    고정 플레이: 3층 특징 비교 / 2층 색·도형 변환 / 1층 CCTV 안내
    금지: 새 장치, 새 방, 새 정답, 좌표, 성공 조건
    허용 규칙: intercom_rule = reverse | rotate_left
    출력: 제목, 층별 브리핑 3개, 허용 규칙 1개, AI 한 문장 JSON
    옵션: temperature 0.35 / timeout 12초 / num_predict 420

서버는 제목·설명의 길이, 학교 문맥 필수어, 정답 누설 금지어와 규칙 열거형을 다시 검사한다. 하나라도 계약을 깨면 같은 시드의 검증된 사건 카드로 대체한다.

### 10.3 음성 입출력

Chrome Web Speech API의 `ko-KR` 최종 전사만 서버 판정에 사용하고 중간 전사는 HUD 피드백에만 사용한다. 음성 권한 또는 인식 실패 시 동일한 채팅 입력 경로를 제공한다. AI 음성은 브라우저의 한국어 Speech Synthesis 음성을 우선하며 캐릭터별 속도·피치·음량을 다르게 설정한다. 급한 구조·경고는 기존 음성을 중단하고 우선 재생한다.

## 11. AI 도구·프롬프트·활용 내역

| 단계 | 도구/입력 프롬프트의 의도 | 만들어진 결과 | 사람이 검증한 기준 |
|---|---|---|---|
| 문제 정의 | “AI가 실제 플레이를 바꾸는 협동 게임” | 음성·금기어·자율 동료의 결합 | AI가 장식이 아닌 규칙인가 |
| 기획 정합성 감사 | “최종 기획과 실제 플레이의 불일치와 퍼센티지를 보여줘” | 층 진행, 술래, AI 음성, 사건 밀도 갭 목록 | 정본 문서와 코드·플레이 교차 확인 |
| 공간 전환 | “학교 내부를 실제 3D로 탐색하고 싶다” | 2.5D에서 3D R3F/Rapier 학교로 전환 | 동선 가독성, 충돌, FPS |
| 동료 개선 | “말로 하는 미션은 AI 동료와 함께” | 관찰·질문·지시·구조 효용 모델 | 혼자 해결되지 않는가 |
| 금기어 개선 | “자주 쓰는 말이면서 미션 관련이어야 한다” | 미션 가중 동적 프로필과 안전한 폴백 | 비노출·소급 금지·완주 가능성 |
| 술래 개선 | “게리모드 SCP처럼 쫓고 돌변하면 괴팍하게” | 변이 사냥개 외형, 추격/차단 역할, 격앙 동작 | 무섭지만 문·LOS·유예가 공정한가 |
| 연출 개선 | “금기어 변경 때 화면 중앙에 빨간 큰 라인” | 금기어 변경 시네마틱, 빙결 균열, 팀 링크 손실 | 단어 내용은 누출하지 않는가 |
| 사운드 결정 | “exploration-dark-ambient.mp3로 통일” | 전 구간 단일 반복 BGM + 상황 효과음 | 음성 가독성과 최신 기획 반영 |
| 성능 개선 | “플레이와 영상 프레임이 끊긴다” | DPR 1 제한, 그림자·블러·할당 비용 축소 | 빌드, 실제 Chrome 60fps 캡처 |
| 제출 제작 | “최종 기획·AI 활용·애자일 사고·1분 실제 플레이” | 본 PDF와 Chrome 시연 영상 | 문서↔구현↔영상의 동일성 |

개발 과정에서 Codex는 저장소 분석, 기획-구현 갭 감사, 코드 수정, 테스트 실행, 성능 병목 제거, 제출 문서와 영상 제작에 활용했다. 사람은 공포 강도, 금기어 비공개 원칙, 단일 BGM, 마지막 시나리오와 제출 우선순위를 계속 결정했다. 자동 생성 결과는 정본 기획서, 실제 코드, 자동 테스트와 브라우저 플레이 중 둘 이상으로 확인한 뒤 채택했다.

## 12. 애자일한 기획 사고 과정

처음부터 기능 목록을 고정하지 않고 **가설 → 짧은 구현 → 실제 체감 → 불일치 기록 → 다음 우선순위**의 루프로 발전시켰다. 마감 직전에는 새 범위를 늘리기보다 60초 안에 핵심 재미가 보이는지를 완료 기준으로 삼았다.

| 관찰된 문제 | 가설 | 피벗/실험 | 얻은 기준 |
|---|---|---|---|
| 2.5D가 학교 탐색 정보를 한꺼번에 노출 | 시야 제한이 공포와 길찾기를 함께 만든다 | 3D 3인칭 학교로 전환 | 모르는 모퉁이가 게임 자원이다 |
| 큰 캠퍼스가 비어 보임 | 넓이보다 사건 밀도가 중요하다 | 수직형 단일 학교로 압축 | 매 층 미션·위협·장소성이 달라야 한다 |
| AI가 플레이어 주위를 맴돎 | 독립 기억과 목표가 있어야 동료로 느껴진다 | 후보 효용·목표 유지·확인 질문 추가 | AI의 선택 이유가 보여야 신뢰가 생긴다 |
| 고정 순찰 술래가 장식처럼 보임 | 감각·기억·역할이 추격 드라마를 만든다 | 소리 조사, 추격/차단, 문·LOS 계약 | 공포와 공정성은 동시에 설계해야 한다 |
| 공개 고정 금기어는 암기 문제 | 내 말버릇이 몰래 위험이 되면 매 판 개인화된다 | 플레이 중 관찰·비공개 세대 교체 | 변경 사실만 알리고 내용은 숨긴다 |
| 초기 영상이 바로 탈출해 재미가 약함 | 실패와 구조가 차별점을 가장 빨리 설명한다 | 의도적 금기어 → 빙결 → AI 구조 → 동료 희생 | 제출 영상도 실제 핵심 루프여야 한다 |
| 장소별 BGM이 산만하고 프레임이 불안정 | 하나의 음색과 이벤트 효과가 더 선명하다 | 옥상 선택곡으로 통일, 렌더 비용 축소 | 최신 인간 결정과 재생 안정성을 우선한다 |

### 최종 우선순위 원칙

1. 옥상부터 파이널까지 한 판이 막힘없이 끝난다.
2. 금기어 빙결과 AI 구조가 실제 서버 판정으로 일어난다.
3. 술래는 무섭지만 다른 층·벽 너머·문 개방 직후 억울하게 잡지 않는다.
4. 문서, 영상, 실제 플레이가 같은 규칙을 말한다.
5. LLM이 없어도 심사자가 전체 게임을 완주할 수 있다.

## 13. 기술 스택과 검증

| 영역 | 구현 |
|---|---|
| 클라이언트 | React, TypeScript, Vite, React Three Fiber, Three.js, Rapier, Zustand |
| 서버 | Python, FastAPI, WebSocket, 단일 권위 게임 세션 |
| 언어·생성 AI | Kiwi, Ollama `gemma3:4b`, JSON schema·허용 목록 검증 |
| 음성 | Chrome Web Speech STT, Web Speech Synthesis TTS, 텍스트 폴백 |
| 콘텐츠 | 서버 시드 기반 수직 미션, 3D 학교, 절차형 인스턴스 구조물 |
| 사운드 | `exploration-dark-ambient.mp3` 무한 반복, 추격·빙결·경고 효과음 |

제출 기준 자동 검증은 서버 전체 408개 테스트 통과, WebSocket 진행·금기어·동료·술래 계약, 클라이언트 lint와 production build, 학교 충돌·내비게이션 검증 통과로 확정했다. 최종 영상은 실제 Chrome 창에서 GPU 렌더링으로 재생하고 H.264 1280×720, 60fps, AAC 스테레오, 정확히 60.000초로 출력했다.

| 56~60초 | 게이트 통과와 결과 화면 | 누가 살아남았고 학교가 무엇을 배웠는지 공개 |

## 15. 안전·프라이버시·장애 대응

- 확정 발화는 현재 방의 메모리 상태와 최근 후보 분석에만 사용하며 외부 학습 데이터로 저장하지 않는다.
- 로컬 Ollama를 기본으로 하며 프롬프트에는 최근 발화와 게임 후보만 전달한다.
- 모델이 멈추거나 없어도 시드 템플릿과 로컬 순위로 모든 미션과 금기어가 작동한다.
- 생성 문장은 길이, 필수 문맥, 금지어, 열거형과 허용 후보 검사를 통과해야 한다.
- 위치, 문, 충돌, 빙결, 구조, 포획, 미션, 주문과 탈출은 서버가 재검증한다.
- Web Speech를 쓸 수 없거나 권한이 거부되면 Enter 채팅이 완전히 동일한 게임 입력으로 동작한다.

## 16. 최종 제출 메시지

『얼음, 땡!』은 AI를 “대사를 생성하는 NPC”로 사용하지 않는다. 플레이어의 언어를 비공개 위험으로 바꾸고, 동료의 오해와 구조를 실제 행동으로 만들며, 술래가 그 협동 소리까지 사냥하게 한다. 생성 모델의 예측 불가능성은 개인화와 표현에 쓰고, 게임의 공정성과 완주 가능성은 검증 가능한 서버 규칙이 책임진다.

**말해야 함께 살 수 있다. 하지만 내가 자주 한 말부터, 학교가 금지한다.**
