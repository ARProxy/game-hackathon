## 1. 완료 결과

현재 빌드는 타이틀에서 옥상으로 진입해 3층, 2층, 1층을 거쳐 운동장 또는 지하 파이널과 결과 화면까지 이어지는 서버 권위 게임이다. 이번 통합 패스에서는 반복 플레이, 비공개 금지어 피드백, 학교 장소성, 술래 공정성, 촬영과 배포 완성도를 우선 보강했다.

## 2. 서버 권위 무작위 미션

매 라운드 서버가 새 `mission_seed`를 만들고 검증된 미션 템플릿의 안전한 슬롯만 바꾼다. LLM이 자유롭게 정답이나 도달 불가능한 위치를 생성하지 않는다.

| 구간 | 라운드마다 달라지는 요소 |
| --- | --- |
| 옥상 | 기억 신호 입력 순서 |
| 3층 방송실 | 세 증거 후보가 놓이는 검증 위치 |
| 2층 인터폰 | 색상·도형 조합과 전달 순서 |
| 1층 CCTV | AI에게 안내할 이동 명령 순서 |
| 파이널 | 운동장·지하 분기, 탈출 경로와 지하 장치 순서 |

같은 시드는 같은 구성을 재현한다. 클라이언트는 `무작위 미션 #번호 · 매 판 새 구성`을 표시하지만 정확한 답, 증거 배치와 명령 순서는 받지 않는다. 개발 전용 촬영 모드만 안정적인 영상 구성을 위해 고정 시퀀스를 사용하며 production 빌드에서는 활성화되지 않는다.

## 3. 비공개 동적 금지어 UI

- 첫 언어 프로필 활성화 시 `학교가 당신의 말버릇을 학습했습니다` 알림을 표시한다.
- 주기 갱신 시 `금지어 규칙이 바뀌었습니다`를 약 4.2초 동안 표시한다.
- HUD는 관찰 중·활성·변화·파이널 봉인 상태를 지속적으로 설명한다.
- 현재 단어, 개수, 교체 후보와 적중 단어는 플레이 중 공개하지 않는다.
- 음성과 Enter 텍스트 채팅을 동일한 서버 프로필 입력으로 처리한다.

이는 기획 5의 `변경 사실은 알리되 내용은 비공개` 계약을 유지한다.

기획 6에서는 관찰된 후보 중 현재 학교 미션 의미 태그와 일치하는 단어를 첫 슬롯에 보장한다. 고정 정답 문자열만 보호하며, `신호`, `열쇠`, `금속`, `출입구`, `도형`, `방향`, `장치`처럼 같은 뜻으로 우회 가능한 미션 표현은 실제로 말한 뒤 위험 후보가 될 수 있다.

## 4. 학교 내부 디테일

활성 학교 맵의 인스턴싱 구조를 유지하면서 실제 기능 위치에 다음 요소를 추가했다.

- 층별 색상의 교실 문패
- 복도 게시판, 프레임과 종이 공지
- 아날로그 벽시계와 시곗바늘
- 소화기함과 소화기
- 음수대, 수조와 버튼
- 24개 방의 천장등과 출입구 스위치
- 교실·도서실·행정실의 소량 서류와 생활 흔적
- 외벽 창대·차양·층선과 중정 수직 피어
- 복도 천장 보·보호대·걸레받이, 정문 포털과 옥상 계단실 캐노피

새 요소는 주 이동축을 침범하지 않는 얇은 비충돌 인스턴스다. 서버 벽 881개, 내비게이션 노드 104개와 문 계약은 유지했다. 구조 검증 결과는 박스 3,556개, 실린더 42개, 문 37개, 방 24개다.

저장소에는 라이선스가 확인된 Kenney CC0 에셋이 있지만, 이번 패스는 기존 로우폴리 색면 스타일과 드로우콜 예산을 지키기 위해 외부 파일을 추가하지 않고 절차형 인스턴스를 사용했다.

## 5. 술래와 방송실 공정성

- 3층 제한 사냥은 방송실 입장 직후 즉시 포획하지 않도록 짧은 공정성 유예를 적용한다.
- 유예 중 발생한 방송 소리는 사라지지 않고 유예 종료 후 술래의 조사 목표가 된다.
- 제한 사냥의 시야·근접 감지·기억·청각 반경을 별도 계약으로 제한했다.
- 문 소리도 같은 층과 거리 조건을 통과해야 술래 신호가 된다.

따라서 방송실 문을 여는 순간 억울하게 잡히지 않으면서도, 미션 중 낸 소리는 실제 첫 추격으로 이어진다.

- 화면의 붉은 경고와 술래 음향은 같은 층 8.5~10m 또는 인간 직접 발견 때만 활성화한다.
- 술래에 맥동 그림자, 발광 눈, 저주파 호흡과 마찰음을 추가했다.
- 금기어 강화 임계값은 1·2·3회로 조정해 첫 빙결부터 경계 속도 1.10배가 적용된다.
- 빙결 이벤트가 `x/z`만 보낼 때 기존 `floor/y/zone`을 보존해 구조 후 층 진행과 위협 판정이 멈추지 않는다.
- 가까운 AI 한 명에게 자동 구조를 배정하고, 근거리 구조는 술래 회피보다 우선한다.
- 붉은 추격자는 심박·사이렌·괴성·돌진음, 차단자는 전기 잡음과 차가운 탐조등으로 접근 신호를 분리했다.
- 2층 첫 진입에는 14초 국지 정전이 발생해 술래 시야는 줄고 청각은 강화된다.
- 1층 첫 진입에는 두 번째 실루엣 사건이 발생해 양쪽 역할과 협공 시작을 명시한다.
- AI가 계단 모서리에 12초 이상 정체되면 서버 권위 층 이동 복구가 작동해 미션 완료 후 영구 교착을 막는다.

## 6. 제출 실행과 촬영

- FastAPI가 production 클라이언트, `/health`와 `/ws`를 한 origin에서 제공한다.
- 단일 Docker 이미지로 실행하며 메모리 기반 방 상태 때문에 worker와 인스턴스는 각각 1개를 사용한다.
- 현재 기획과 다른 고정 금지어 로컬 데모 폴백은 제거했다.
- 개발 환경에서만 동작하는 방송실·전체 플레이스루 촬영 디렉터를 추가했다.
- 카메라가 진행 방향을 따르도록 촬영 모드를 보정하고 옥상부터 파이널까지 확인 영상을 만들었다.
- 최종 제출본은 실제 Chrome GPU 창을 154.98초 동안 캡처한 뒤 정확히 60초로 편집했다.
- 옥상 팀 소개, 3층 술래 조우, 금기어 빙결과 AI 구조, 층간 음성 협동, 금기어 변경, 동료 포획, 운동장 주문과 탈출 결과를 한 흐름으로 담았다.
- 최종 영상은 선택한 단일 공포 BGM과 두 AI의 신호·구조·경고·탈출 한국어 음성을 믹스했다.
- 2분 32.8초 확인용 플레이스루에도 장소별 BGM과 AAC 스테레오 트랙을 포함해 기존 무음 문제를 제거했다.
