> 문서 버전: v0.1

## 1. 게임 한 줄 소개

**『얼음, 땡!』은 플레이어가 평소 자주 쓰는 말이 금기어가 되고, 그 말을 피해 AI 동료와 협력하며 술래에게서 탈출하는 음성 협동 게임이다.**

플레이어가 금기어를 말하면 즉시 얼어붙고 위치가 술래에게 노출된다. 동료가 가까이 와서 "땡"을 해주기 전까지 움직일 수 없으므로, 플레이어는 위험한 단어를 우회해서 말하고 서로의 의도를 해석해야 한다.

---

## 2. 기획 의도

일반적인 음성 게임은 플레이어가 정확한 명령을 말할수록 유리하다. 『얼음, 땡!』은 반대로 **가장 말하고 싶은 단어를 말할 수 없게 만들고**, AI가 생략과 우회 표현을 이해하게 한다.

이 게임에서 AI는 대사를 생성하는 장식적인 NPC가 아니다. AI 동료는 다음 정보를 종합해 플레이어의 의도를 추론하고 행동한다.

- 플레이어의 음성 발화와 우회 표현
- 주변 공간과 현재 보이는 프롭
- 진행 중인 미션과 게임 상태
- 금기어 발화 위험
- 술래의 위치와 동료의 빙결 상태

AI가 플레이어의 의도를 정확히 이해하거나 오해하는 결과가 이동, 미션 성공, 구조 또는 추격으로 직접 이어진다.

---

## 3. 핵심 재미

### 3.1 말하지 않고 설명하는 재미
플레이어는 "열쇠를 가져와"라고 말하고 싶지만 `열쇠`가 금기어라면 "문을 열 때 쓰는 반짝이는 작은 것"처럼 우회해야 한다.

### 3.2 서로의 의도를 해석하는 협동
AI 또는 다른 플레이어는 불완전한 설명과 공간 정보를 바탕으로 대상을 추론한다. 필요하면 위험한 단어를 피하면서 확인 질문을 한다.

### 3.3 실수가 추격으로 바뀌는 긴장
금기어 발화는 단순 감점이 아니다. 발화한 플레이어가 얼고, 술래가 그 위치를 파악해 접근한다. 동료는 미션을 계속할지 구조하러 갈지 즉시 선택해야 한다.

### 3.4 침묵을 깨는 마지막 외침
게임 내내 말을 조심하던 플레이어는 마지막 탈출 순간에 단서로 완성한 주문을 크게 외쳐야 한다. 이 외침을 들은 술래도 탈출구로 달려오므로 마지막 추격이 발생한다.

## 4. 핵심 플레이 루프

```
플레이어가 음성으로 동료에게 우회 지시
        ↓
AI가 발화와 공간 정보를 분석해 의도를 추론
        ↓
동료 이동 / 확인 질문 / 미션 오브젝트 조작
        ↓
미션 진행 또는 금기어 발화로 빙결·위치 노출
        ↓
플레이어가 표현, 이동 경로, 구조 여부를 다시 선택
```

## 5. 게임 목표와 승패 조건

### 승리 조건
1. 기본 미션을 수행해 최종 주문의 단서를 모은다.
2. 탈출 게이트를 활성화한다.
3. 게이트 앞에서 단서를 조합한 주문을 음성으로 외친다.
4. 문이 열린 뒤 술래에게 잡히기 전에 탈출한다.

### 실패 조건
- 팀 전원이 동시에 얼어 구조할 수 없는 상태가 된다.
- 빙결된 플레이어를 제한시간 안에 구조하지 못한다.
- 술래에게 잡힌다.

> MVP에서는 별도 관전자 시스템이 필요 없는 `팀 실패`를 우선 검토한다.

## 6. 플레이 인원과 목표 플레이 시간

### 사전 과제 MVP
- 인간 플레이어 1명 + AI 동료 1명 + 술래 1명
- 목표 플레이 시간: 3~5분

### 예상 플레이 흐름

| 구간 | 목표 시간 | 내용 |
| --- | --- | --- |
| 온보딩 | 20~30초 | 평범한 질문에 음성으로 답변 |
| 규칙 공개 | 10초 | 추출된 금기어와 빙결 규칙 확인 |
| 기본 미션 | 90~150초 | 우회 지시, 탐색, 빙결 및 구조 경험 |
| 최종 미션 | 30~60초 | 주문 외치기와 탈출구 추격 |
| 결과 | 10~20초 | 금기어 출처와 주요 플레이 기록 공개 |

## 7. 금기어 시스템

### 7.1 금기어 생성
게임 시작 전 평범한 질문으로 자연스러운 발화를 유도한다.
- "주말에 보통 뭐 해요?"
- "책상 위에 지금 뭐가 있어요?"
- "좋아하는 색이나 음식이 있나요?"

음성 전사에서 명사와 형용 표현을 추출하고 다음 기준으로 후보를 평가한다.
- 플레이어가 실제로 사용한 단어인가?
- 게임 중 다시 사용할 가능성이 높은가?
- 맵의 사물, 색, 방향 또는 행동과 연결할 수 있는가?
- 발음이 분명하고 음성 인식 오판 가능성이 낮은가?
- 부적절하거나 개인 정보에 가까운 단어가 아닌가?

적절한 후보가 부족하면 검증된 기본 금기어 풀을 사용한다.

### 7.2 제외어
- 얼음, 땡
- 플레이어 이름과 호칭
- 기본 이동 및 미션 진행에 반드시 필요한 단어
- 조사, 대명사, 감탄사
- 발음이 지나치게 짧거나 오인식 가능성이 큰 단어

### 7.3 MVP 규칙
- 한 판의 전체 금기어는 3개로 고정한다.
- 금기어는 모든 참가자의 발화에 적용한다.
- 한 판이 끝날 때까지 금기어를 변경하지 않는다.
- STT 전사 결과에서 완전 일치와 조사 결합 형태를 우선 판정한다.
- 판정 신뢰도가 낮으면 즉시 빙결시키지 않고 경고 또는 재확인 처리한다.

## 8. 빙결과 구조

### 빙결 발생
1. 0.4초 프리즈 연출
2. 캐릭터 이동과 상호작용 정지
3. 서리와 얼음 파티클 표시
4. 술래에게 해당 위치 핑 전송
5. 구조 제한시간 시작

### 구조
- 움직일 수 있는 동료가 빙결 캐릭터 가까이 접근한다.
- 구조 상호작용 또는 "땡" 발화로 빙결을 해제한다.
- 구조 과정에서 술래가 접근하므로 미션 진행과 구조 사이의 선택이 발생한다.

### 술래 반응
- 평상시에는 고정 웨이포인트를 순찰한다.
- 빙결 핑 발생 시 해당 위치로 걸어서 접근한다.
- 접근 속도는 구조할 수 있는 최소 시간을 보장하도록 조정한다.
- 술래가 시야 밖에 있어도 발소리와 휘파람으로 방향과 거리를 전달한다.

## 9. 미션 시스템

### 9.1 구조
```
온보딩 발화 수집 → 금기어와 대응 프롭 결정 → 기본 미션 수행 → 단서 획득 → 최종 주문 → 탈출
```
미션은 LLM이 자유롭게 생성하지 않는다. 검증된 템플릿에 금기어, 프롭, 위치와 문구를 삽입하는 데이터 기반 방식으로 구성한다.

### 9.2 기본 미션 T1: 금지된 물건 찾기
- 맵에 비슷한 후보 프롭 3개를 배치한다.
- AI 동료만 어떤 후보가 진짜인지 가까이에서 판별할 수 있다.
- 대상의 일반적인 이름은 금기어이므로 플레이어는 외형과 위치로 우회 지시해야 한다.
- 진짜 프롭을 회수하면 최종 주문의 단서를 얻는다.

### 9.3 기본 미션 T2: 떨어진 장치 동시 조작
- 한 캐릭터는 상자 앞에 대기, 다른 캐릭터는 반대편 구역의 레버를 작동
- 3초 안에 두 장치를 함께 조작해야 한다.
- 위치나 타이밍에 관련된 금기어 때문에 우회 표현이 필요하다.

### 9.4 기본 미션 T3: 제한된 설명 해석
- AI 동료만 기호, 색 또는 순서를 확인할 수 있다.
- AI가 금기어를 피한 표현으로 플레이어에게 설명한다.
- 플레이어가 설명을 해석해 장치에 답을 입력한다.

### 9.5 최종 미션: 주문 외치기
- 기본 미션 완료 후 탈출 게이트가 활성화된다.
- 플레이어는 게이트 앞에서 획득한 단서가 포함된 주문을 소리 내어 말한다.
- 최종 주문은 금기어 판정에서 제외한다.
- 주문이 감지되면 술래는 게이트를 최고 우선순위 목표로 삼는다.
- 단서 대부분이 포함되면 관대한 퍼지 매칭으로 문을 연다.

## 12. AI 시스템 설계

### 12.1 AI 역할

| AI 기능 | 입력 | 출력 | 게임 영향 |
| --- | --- | --- | --- |
| 금기어 후보 추출 | 온보딩 전사 | 검증된 단어 후보 | 규칙과 프롭 결정 |
| 의도 추론 | 발화, 주변 프롭, 미션 상태 | 대상, 행동, 신뢰도 | AI 동료의 실제 행동 |
| 제한된 응답 | 추론 결과, 금기어 | 짧은 확인 또는 우회 설명 | 협동 정보 전달 |
| 미션 세팅 | 금기어, 템플릿, 슬롯 | 구조화된 라운드 데이터 | 프롭과 미션 배치 |

### 12.2 구조화된 출력 예시
```json
{
  "intent": "inspect_prop",
  "targetPropId": "prop_key_candidate_02",
  "targetZone": "storage",
  "confidence": 0.82,
  "reply": "창고 구석의 반짝이는 물건을 확인할게.",
  "fallbackAction": "ask_clarification"
}
```

### 12.3 검증
- 허용된 의도와 행동만 실행
- 존재하지 않는 프롭 또는 접근 불가능한 위치 거부
- 신뢰도가 낮으면 확인 질문
- AI 응답에도 금기어 필터 적용

### 12.4 폴백
- AI API 실패: 키워드 기반 로컬 명령 해석
- STT 실패: 자막 입력 또는 선택형 명령 제공
- 미션 생성 실패: 사전 검증된 고정 라운드 데이터 사용
- 응답 지연: AI가 현재 위치에서 대기하고 상태 표시

## 13. 사전 과제 MVP 범위

### 반드시 구현
- 웹에서 실행 가능한 2.5D 맵
- 인간 1명, AI 동료 1명, 술래 1명
- 음성 입력과 금기어 판정
- 금기어 발화 시 빙결 및 위치 노출
- AI 동료의 이동, 대상 추론, 구조 행동
- T1 미션 1개
- 단서 획득과 최종 주문
- 승리 및 실패 화면
- API 또는 STT 장애 폴백

### 시간이 남으면 구현
- 가변 프롭 배치
- T2 동시 조작, T3 제한 설명
- 추가 술래 연출과 데코 프롭
- 플레이 기록 기반 결과 화면 강화

### 제외
- 실시간 온라인 멀티플레이
- 판 중 금기어 교체
- 자유 생성 미션, 절차 생성 맵
- 커스텀 캐릭터 모델링과 리깅

## 14. 30~60초 플레이 영상 구성안

| 시간 | 화면 | 전달 메시지 |
| --- | --- | --- |
| 0~5초 | 온보딩 질문에 "책상에 커피랑 열쇠가 있어요"라고 답함 | 내 말이 게임의 재료가 됨 |
| 5~10초 | `열쇠`가 금기어로 공개되고 맵에 후보 프롭 등장 | 개인화된 금기어와 맵 |
| 10~22초 | "반짝이는 작은 거 확인해줘"라고 AI 동료에게 지시 | AI가 우회 표현과 공간을 이해 |
| 22~30초 | 실수로 금기어 발화, 플레이어 빙결, 술래 방향 전환 | 말실수가 실제 위험으로 변함 |
| 30~40초 | AI 동료가 달려와 "땡"으로 구조 | AI 협동과 구조 |
| 40~50초 | 미션 성공, 주문 단서 획득, 게이트 활성화 | 완결된 목표 진행 |
| 50~60초 | 주문을 외치고 술래보다 먼저 탈출 | 음성 클라이맥스와 승리 |

- 실제 개발 스택과 배포 방식
- 금기어 공개 범위와 개인별 정보 비대칭
- 기본 미션을 한 판에 몇 개 제공할지
- 빙결 제한시간과 만료 시 처리
- 탈출 게이트의 고정 또는 가변 위치
- AI 동료가 금기어를 말했을 때 동일하게 빙결되는지
- 음성 입력을 상시 감지할지, Push-to-Talk으로 받을지
- 최종 주문의 정확한 성공 판정 기준
- 사용할 STT, LLM 및 TTS 공급자

## 16. 현재 기획의 성공 정의

플레이어가 3~5분의 한 판을 마친 뒤 다음 내용을 설명할 수 있으면 성공이다.

1. 내가 평소 사용한 말이 금기어가 되었다.
2. 그 단어를 피해 AI 동료에게 공간과 사물을 설명했다.
3. AI 동료가 내 불완전한 표현을 해석해 실제로 행동했다.
4. 말실수는 빙결과 술래의 추격으로 이어졌다.
5. 마지막에는 단서를 조합한 주문을 외치고 탈출했다.
