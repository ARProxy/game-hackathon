# 멀티플레이 제출 범위 고정 단위

- 기준일: 2026-08-09
- 구성: 인간 2명 + 독립 AI 동료 2명 + 술래

## 결정

층별 본편은 AI 두 명이 서로 다른 신호, 인터폰 판독, CCTV 원격 장치와 지하 설비를 맡는 구조다. 과거 방 설정은 인간을 4명까지 받아 AI를 0명까지 줄였지만, 이는 후반 AI 전용 역할을 수행할 actor가 사라지는 진행 교착을 만들었다.

제출 빌드는 모든 광고된 멀티 방이 실제로 완주 가능하도록 인간을 정확히 2명으로 제한한다. 두 인간의 캐릭터·이동·빙결·탈출은 서버 권위로 동기화되고, AI 두 명은 솔로와 같은 독립 행동 계약을 유지한다. 향후 3~4인 지원은 AI 전용 미션을 인간 대체 역할로 다시 설계한 뒤 별도 확장한다.

## 검증

- 세 번째 인간 참가를 서버가 `방이 가득 찼다`로 거부
- 두 인간이 모두 준비하면 `partner`, `partner-2` 두 AI를 포함해 시작
- 두 인간+두 AI가 서로 다른 옥상 A~D 스폰 사용
- 2클라이언트 위치 동기화와 전체 층 자동 완주 계약 유지
