# 추론형 최종 주문·결과 분석 작업 기록

> 작업일: 2026-08-09  
> 범위: 수직 본편의 주문 파편, 주문 제출 서버 계약, 결과 분석 UI

## 목표

HUD에 `달빛 · 교정 · 탈출`과 숫자 순서를 그대로 표시한 뒤 읽게 하던 흐름을 제거한다. 플레이어가 세 층에서 얻은 불완전한 단서의 뜻과 관계를 해석해 주문을 구성하고, 틀린 추론에는 술래가 듣는 실제 위험 비용이 발생하게 한다. 종료 후에는 게임이 어떤 대화를 금기어로 선택했고 그 결과 술래가 어떻게 강화됐는지 설명한다.

## 주문 파편 계약

수직 본편의 각 층은 정답 단어와 숫자 순서 대신 다음 공개 파편만 전송한다.

| 획득 층 | 기호 | 수수께끼 | 관계 |
|---|---|---|---|
| 3층 | ☾ | 밤하늘의 달에서 퍼지는 빛 · 두 글자 | 세로선의 맨 위에서 시작 |
| 2층 | ↺ | 틀린 답을 바르게 고치는 일 · 두 글자 | 달 표식 다음, 출구 표식 이전 |
| 1층 | ⇥ | 갇힌 곳을 벗어나 밖으로 나감 · 두 글자 | 세로선의 맨 아래에서 끝 |

- 네트워크 `vertical_stage_advanced.clue`에는 `word`와 `order`가 없다.
- HUD는 기호·수수께끼·상대 관계를 보여 주며 완성 답안을 렌더하지 않는다.
- 서버는 정답 `달빛 → 교정 → 탈출`을 비공개로 유지한다.
- 퍼지 발음은 허용하지만 세 답의 누락 또는 잘못된 순서는 실패한다.
- 실패 주문은 강한 `failed_spell` 소리 핑을 남겨 술래의 조사 목표가 된다.
- 최종 주문은 금기어 판정과 동적 프로필 수집에서 제외된다.

## 결과 분석 계약

서버 세션은 유효한 주문 제출에 대해 다음만 기록한다.

- 총 제출 횟수
- 실패 제출의 인식 개수
- 순서 유효 여부
- 실패 이유: `order` 또는 `incomplete`
- 성공 여부

라운드 종료 페이로드에서만 완성 주문과 분석을 공개한다. 결과 화면은 다음을 설명한다.

- 완성 주문과 제출·실패 횟수
- 각 실패가 순서 오류인지 단서 부족인지
- 동적 금기어 세대별 실제 단어
- 초기 대화 선택 또는 주기적 교체라는 선택 이유
- 각 세대 유지 시간과 가장 오래 유지된 세대
- 금기어 위반 누적 횟수
- 위반 임계점마다 발생한 술래 속도 배율, 청각 확대, 시야 확대
- 선택된 운동장/지하 파이널 경로

## 안전성과 복구

- 주문 답은 진행 이벤트, 파편, 파이널 준비 이벤트에 포함되지 않는다.
- 실패 결과는 정답 단어나 누락 단어를 알려 주지 않고 개수와 순서 문제만 알려 준다.
- 결과 분석은 `game_won` 또는 `game_over` 뒤에만 클라이언트 상태로 저장한다.
- 새 라운드를 시작하면 이전 결과 분석을 즉시 비운다.
- 대화가 충분히 쌓이지 않은 경우 결과 화면은 금기어 세대가 없음을 명시한다.
