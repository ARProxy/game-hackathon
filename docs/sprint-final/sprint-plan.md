# 최종 스프린트 계획 — 서버 100% 구현

> 시작: 2026-08-08
> 목표: 기획서 v3/v4 서버 구현율 100% + 멀티플레이 방

---

## 배치 순서 (5분 단위)

### Batch 1: 미션 프롭 시스템을 수직 진행에 연결
- session.setup_game()에서 수직 진행 시에도 round_data 생성
- 층별 미션 풀 정의 (각 층에 맞는 미션 템플릿)
- 프롭 → 메모 → 미션지 흐름 구현

### Batch 2: 2층 미션 — 인터폰 협동
- 2층 인터폰 미션: AI가 한 위치에서 기호를 읽고 음성으로 전달
- 플레이어가 다른 위치에서 정답 입력
- 금기어를 피해 설명해야 하는 구조

### Batch 3: 1층 미션 — 관제 장치 동시 조작
- 1층: 떨어진 두 장치를 제한시간 내 동시 작동
- AI와 플레이어가 각각 장치 담당
- 타이밍 동기화 검증

### Batch 4: AI 독립 동선
- 플레이어 층 이동 시 AI 강제 이동 제거
- AI가 독립적으로 층 이동 판단
- 이전 층 복귀 판단 (구조/단서 회수)

### Batch 5: 지하 파이널
- BASEMENT_FINAL 미션 로직
- 배전반/급수 밸브 순서 복구 미션
- AI 보고 기반 장치 상태 확인

### Batch 6: 멀티플레이 방 시스템
- 방 생성/참가/준비/방장
- 캐릭터 선택 + 중복 방지
- 플레이어 수에 따른 AI 충원
- 방 상태 동기화

### Batch 7: 멀티 게임 루프
- 다중 인간 플레이어 빙결/구조
- 플레이어별 금기어 정보 공개
- 개별 탈출 판정

### Batch 8: 테스트 + 문서화
- 전체 테스트 통과 확인
- 누락 엣지 케이스 보완
- 최종 문서 갱신
