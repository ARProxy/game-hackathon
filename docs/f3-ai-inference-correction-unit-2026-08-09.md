# 3층 AI 추론·오해·교정 본편 연결 작업 기록

> 작업일: 2026-08-09  
> 범위: 3층 방송실 미션, AI 동료 후보 판단과 물리 행동, 맵·서버·클라이언트 계약

## 목표

기획 4의 AI 음성 역할인 `관찰 → 판단 설명 → 저확신 질문 → 플레이어 교정 → 실제 행동`을 레거시 프롭 미션이 아니라 수직 본편의 3층 미션에서 끝까지 작동하게 만든다. 플레이어의 한 문장을 키워드로만 검사해 즉시 다음 층을 여는 기존 흐름은 제거한다.

## 확인한 원인

- 수직 본편은 `round_data = None`으로 시작해 기존 전체 후보 비교 로직을 사용하지 않았다.
- 3층 발화는 도구·출입구·개방 키워드만 있으면 AI가 움직이지 않아도 즉시 완료됐다.
- 수직 진행 기본 분기가 `runtime.command`보다 먼저 실행되어 플레이어가 내린 후보 조사 명령이 AI 이동 목표가 되지 않았다.
- 3층에는 AI가 실제로 확인할 후보 물체와 서버 의미 슬롯이 없었다.

## 구현 결과

### 맵 구조

- 방송실 작업대, 서쪽 지구과학실 실험대, 동쪽 서예실 전시대에 A/B/C 물리 후보를 배치했다.
- 후보 공개 ID는 의미를 유출하지 않는 `vertical_f3_candidate_a/b/c`로 고정했다.
- 각 후보는 물리 전시 위치와 별도의 AI 접근점을 가지며, 접근점은 3층 슬래브 위이고 서버 장벽과 겹치지 않는다.
- 기존 가구를 받침 구조로 재사용해 중복 콜라이더와 깊이 겹침을 만들지 않았다.

### 서버 권위

- 정답 이름·태그·설명·정답 여부는 `BroadcastInferenceMission` 안에만 둔다.
- 모든 발화는 세 후보를 같은 기준으로 점수화한다.
  - 단서 없음: 대기하며 추가 특징 요청
  - 동점 또는 낮은 격차: 상위 두 구역을 설명하며 확인 질문
  - 충분한 단서와 격차: 선택한 후보 위치를 AI의 실제 조사 명령으로 설정
- 오답 후보도 서버가 자동 정답으로 보정하지 않는다. AI가 해당 증거대 앞까지 이동해 3초간 확인한 뒤 실패를 보고한다.
- 플레이어가 재질·형태·쓰임을 교정하면 전체 후보를 다시 평가한다.
- 정답 후보를 실제 확인한 뒤에만 `floor_3 → floor_2` 진행을 허용한다.
- 위험 회피·구조·층 이동은 후보 명령보다 우선하고, 그 다음 순위에서 수직 본편 조사 명령을 실행한다.
- 동적 금기어 후보에서 3층의 필수 설명·오답 교정 명사를 보호해 미션 입력 자체가 새 금기어가 되는 교착을 막았다.

### 플레이 체감과 UI

- HUD의 후보 비교 카드에 세 구역의 점수·근거와 AI 확신도를 표시한다.
- AI 선언과 실제 목표가 같은 후보 ID·좌표를 사용한다.
- 오답 확인 뒤 현재 미션 문구가 해당 구역과 교정 방법을 구체적으로 안내한다.
- 정답 ID나 내부 이름은 네트워크 이벤트와 HUD에 노출하지 않는다.

## 대표 플레이 시나리오

1. 플레이어: “길쭉한 도구”  
   결과: A와 B가 동점이므로 AI가 색이나 쓰임을 더 묻고 움직이지 않는다.
2. 플레이어: “검은 길쭉한 빛을 비추는 도구”  
   결과: AI가 B를 선언하고 서쪽 증거대까지 실제 이동한 뒤 오답임을 보고한다.
3. 플레이어: “은빛 작은 금속이고 잠긴 출입구를 여는 도구”  
   결과: AI가 전체 후보를 다시 비교해 A로 이동·확인하고 2층 방화문을 연다.
