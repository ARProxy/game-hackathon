# 플레이어 보행 피드백 사고 흐름

## 관찰

이동 가감속과 카메라 안정화 이후에도 플레이어 모델의 모든 파츠는 정지 자세를 유지한다. 충돌 바디만 이동하므로 캐릭터가 바닥 위를 미끄러지는 인상이 남는다. 캐릭터 디자인은 팔이 없는 콩 실루엣이므로 일반 인간형 팔 스윙을 추가하면 기존 정체성이 깨진다.

## 판단

좌우 다리와 신발을 하나의 발 단위로 묶어 교차 이동시키고, 몸통에는 작은 상하·좌우 무게 이동만 준다. 애니메이션 강도와 발소리 주기는 키 입력 여부가 아니라 실제 Rapier 수평 속도를 기준으로 해야 벽에 막혔거나 감속 중일 때 피드백이 어긋나지 않는다.

## 구현 계약

- 캐릭터 파츠의 `leg`, `shoe`, `sock`을 좌우 발 그룹으로 분리한다.
- 실제 이동 속도 0~1 값을 보행 애니메이션 입력으로 전달한다.
- 좌우 발은 반대 위상으로 앞뒤·상하 이동하고 몸통은 작은 보폭 반동만 사용한다.
- 빙결 또는 조작 불가 상태에서는 보행 강도를 0으로 복귀시킨다.
- 발소리는 실제 이동 중이고 지면에 있을 때만 재생하며 좌우 음색을 미세하게 구분한다.
- 달리기와 스태미나는 술래 속도·감지·플레이 시간 전체를 바꾸므로 별도 밸런스 작업 전까지 추가하지 않는다.

## 성공 기준

걷는 동안 좌우 발의 교차가 보이고 정지하면 기본 자세로 자연스럽게 복귀해야 한다. 벽에 막힌 상태에서 발소리가 계속 반복되지 않아야 하며, 음량 설정을 따라야 한다. 빌드와 린트가 통과해야 한다.
