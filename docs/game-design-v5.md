## 0. 이 문서가 개정하는 것

기획 1~4의 `금기어 3개를 게임 전에 생성·공개하고 한 판 동안 고정한다`는 규칙을 폐기한다. 금기어의 본질은 외워서 피하는 제한 단어 퀴즈가 아니라, **게임이 플레이어의 대화를 몰래 관찰해 자주 쓰는 표현을 위험으로 바꾸고 플레이어가 결과로 규칙을 추론하는 것**이다.

기획 5가 명시적으로 개정하는 항목은 다음과 같다.

- 게임 전 금기어 수집용 질문 3개를 제거한다.
- 게임 전 `FORBIDDEN_REVEAL` 단계와 금기어 목록 공개를 제거한다.
- 현재 금기어, 개수, 교체 시각과 분석 후보를 인간 플레이어에게 공개하지 않는다.
- 금기어는 플레이 중 인간의 음성·텍스트 대화를 분석해 처음 형성되고 주기적으로 변경된다.
- Ollama/LLM은 후보를 추천하지만 실제 적용은 서버의 결정론적 검증기가 확정한다.
- 갱신된 금기어는 갱신을 일으킨 발화에 소급 적용하지 않고 다음 발화부터 적용한다.
- AI 동료는 서버의 현재 금기어를 알고 회피하지만, 인간에게 정답을 직접 말하지 않는다.
- 결과 화면에서만 금기어 변화 이력과 근거가 된 대화 경향을 공개한다.

공간, AI 동료, 술래, 층 진행, 미션과 최종 주문은 기획 1~4를 그대로 따른다.

## 1. 새로운 핵심 판타지

> 학교가 내 말버릇을 듣고 있다. 방금까지 안전했던 단어가 다음 순간 나를 얼릴 수 있지만, 무엇이 바뀌었는지는 직접 추론해야 한다.

플레이어는 알려진 금지 목록을 암기하지 않는다. AI 동료와 협력하기 위해 계속 말하면서도 다음을 판단한다.

- 내가 방금 어떤 표현을 반복했는가?
- 어느 말 뒤에 얼어붙었는가?
- AI가 왜 특정 단어 앞에서 말을 고쳤는가?
- 같은 뜻을 다른 방식으로 설명할 수 있는가?
- 지금 말하는 편이 침묵보다 가치 있는가?

## 2. 전체 흐름 개정

```text
타이틀 → 모드 선택 → 캐릭터 선택
→ 옥상에서 즉시 플레이 시작
→ 인간 발화 3회 관찰(금기어 미활성)
→ 첫 비공개 금기어 세트 활성화
→ 대화·채팅 누적 분석
→ 발화 5회 + 최소 유지시간 45초 충족 시 비공개 부분 갱신
→ 빙결 결과와 AI의 말 멈춤을 통해 플레이어가 위험 표현 추론
→ 파이널 진입 시 금기어 갱신 중지
→ 결과 화면에서 변화 이력 공개
```

관찰 구간은 별도 설문 화면이 아니다. 옥상 튜토리얼에서 이동, AI 지시와 장치 조작을 배우며 자연스럽게 말한 내용이 첫 프로필의 재료가 된다.

## 3. 서버 권위 상태

라운드는 다음 비공개 상태를 서버에 가진다.

```json
{
  "generation": 2,
  "currentWords": ["문", "오른쪽", "장치"],
  "recentUtterances": ["..."],
  "qualifiedUtteranceCount": 9,
  "utterancesSinceRotation": 5,
  "lastRotatedAt": 1720000000,
  "analysisPending": false,
  "history": [
    {
      "generation": 1,
      "activatedAt": 1720000000,
      "retiredAt": 1720000060,
      "words": ["문", "왼쪽", "열쇠"],
      "reason": "initial_profile"
    }
  ]
}
```

`currentWords`, 후보 점수와 분석 원문은 인간 클라이언트 상태에 보내지 않는다. 클라이언트는 다음 공개 상태만 받는다.

- `observing`: 아직 첫 프로필을 만드는 중
- `active`: 비공개 금기어 규칙이 활성화됨
- `shifted`: 말버릇 감시가 변했다는 분위기 신호
- `locked`: 파이널 진입으로 현재 규칙이 고정됨

## 4. 수집과 후보 생성

### 4.1 수집 대상

- 인간 플레이어가 확정한 음성 전사
- 접근성 텍스트 채팅으로 전송한 발화
- 발화 시각, 현재 층, 미션 단계와 반복 횟수

AI 대사, 시스템 자막, 최종 주문, 마이크 중간 전사는 프로필에 넣지 않는다.

### 4.2 영구 제외어

- `얼음`, `땡`
- 플레이어와 캐릭터 이름·호칭
- 조사, 감탄사, 대명사와 한 글자 토큰
- 구조·이동·접근성에 반드시 필요한 명령
- 최종 주문 조각과 현재 미션에서 반드시 그대로 말해야 하는 고유 문자열
- 개인정보, 욕설과 안전하지 않은 표현

### 4.3 Ollama/LLM의 역할

모델 입력은 최근 인간 발화, 서버가 추출한 허용 후보, 현재 미션 의미 태그와 이전 금기어 이력이다. 모델은 허용 후보 안에서 다음을 평가한다.

- 플레이어가 실제로 반복하거나 습관적으로 쓰는가?
- 현재와 가까운 미래의 협동에서 다시 말할 가능성이 높은가?
- 다른 표현으로 우회할 수 있는가?
- 음성 인식 오판 가능성이 낮은가?

모델은 JSON 후보와 이유만 반환한다. 서버는 허용 목록, 제외어, 중복, 최소 길이와 발음 안정성을 다시 검증한다. 모델이 월드 사실, 빙결 여부 또는 미션 정답을 결정하지 않는다.

### 4.4 폴백

Ollama가 없거나 시간 내 응답하지 않으면 Kiwi 형태소 분석으로 최근 명사·형용 표현의 빈도, 최근성, 재사용 가능성을 점수화한다. AI 장애는 금기어 갱신을 늦출 수 있지만 게임 진행을 멈추지 않는다.

## 5. 갱신 규칙과 공정성

### 첫 활성화

- 인간의 유효 발화 3개가 모이기 전에는 대화 기반 금기어로 얼리지 않는다.
- 세 번째 발화의 판정이 끝난 뒤 첫 세트를 만든다.
- 첫 세트는 네 번째 발화부터 적용한다.

### 주기 갱신

- 마지막 갱신 후 유효 발화 5개 이상
- 마지막 갱신 후 45초 이상
- 두 조건을 모두 만족했을 때 분석을 예약한다.
- 분석은 비동기로 실행하며 이동·추격·미션을 멈추지 않는다.
- 세 단어를 모두 바꾸지 않고 최소 한 단어를 유지하며 최대 두 단어만 교체한다.
- 동일 단어를 연속해서 다시 뽑는 것은 유지로 취급한다.

### 원자적 적용

각 발화는 시작 시점이 아니라 서버가 수신했을 때의 `generation` 하나로 판정한다. 분석이 완료되더라도 처리 중인 발화에는 새 세트를 소급 적용하지 않는다. 갱신은 해당 발화의 빙결·자막·미션 처리가 끝난 뒤 원자적으로 적용한다.

### 파이널

파이널 경로가 공개되면 금기어 갱신을 중지하고 현재 세트를 고정한다. 최종 주문은 금기어 판정과 프로필 수집에서 제외한다.

## 6. 플레이어 정보 계약

### 절대 보여주지 않는 것

- 현재 금기어 목록과 개수
- 빙결을 일으킨 정확한 단어
- 다음 갱신까지 남은 시간과 발화 수
- 분석 후보, 점수와 모델 추론

### 보여주는 것

- 대화가 학교에 감시되고 있다는 규칙
- 첫 프로필 활성화 시 짧은 방송 잡음·조명 흔들림
- 갱신 시 단어 없는 환경 신호와 `말버릇 감지 변화` 정도의 모호한 메시지
- 빙결 시 `방금 발화에 위험 표현이 포함됨`이라는 사실
- AI가 금기어 직전에 말을 멈추거나 우회하는 연출
- 결과 화면의 세대별 금기어와 변화 시각, 위반 횟수

플레이어가 자신의 직전 발화 자막을 보는 것은 허용한다. 다만 시스템이 어느 부분을 금기어로 판정했는지는 강조하지 않는다.

## 7. AI 동료 계약

- AI는 현재 세대를 서버에서 읽고 금기어가 포함될 응답을 발화 전에 다시 작성한다.
- AI는 금기어를 직접 알려주거나 첫 글자, 글자 수, 동의어 목록으로 정답을 누설하지 않는다.
- 회피 연출은 `그... 아, 다른 말로 할게`처럼 의미 전달을 유지한다.
- AI 발화는 인간 프로필 학습 데이터에 포함하지 않는다.
- AI의 회피 발화도 월드 소리이며 술래가 들을 수 있다.
- 회피에 실패한 문장은 송출하지 않으며 AI를 금기어 때문에 빙결시키지 않는다.

## 8. 빙결과 학습 피드백

금기어 빙결 이벤트는 클라이언트에 정확한 단어를 보내지 않는다.

```json
{
  "type": "freeze",
  "cause": "hidden_forbidden_expression",
  "generation": 2,
  "confidenceBand": "high",
  "position": {"x": 0, "z": 0}
}
```

정확한 `matched_word`, 형태소 단계와 모델 점수는 서버 로그와 결과 정산용 비공개 기록에만 남긴다. STT 판정 신뢰도가 낮으면 즉시 빙결하지 않고 서버 내부 경고 누적 또는 재확인을 사용한다.

## 9. 결과 화면

라운드 종료 후에는 학습 결과를 반전으로 공개한다.

- 세대별 활성 시간과 금기어 목록
- 어떤 말버릇 때문에 후보가 되었는지에 대한 짧은 요약
- 플레이어가 실제로 걸린 횟수
- 가장 오래 유지된 표현과 가장 자주 바뀐 표현
- 금기어 위반이 술래 강화에 미친 영향

원문 대화 전체를 기본 공개하지 않는다. 요약과 해당 단어 주변의 짧은 맥락만 사용한다.

## 10. 테스트 계약

- 첫 3회 발화는 새 금기어 세트 때문에 빙결되지 않는다.
- 세 번째 발화가 첫 세트에 포함돼도 세 번째 발화에 소급 판정되지 않는다.
- 네 번째 발화부터 현재 세트가 적용된다.
- 5회 발화와 45초 중 하나만 충족하면 갱신되지 않는다.
- 한 번의 갱신에서 최대 두 단어만 교체된다.
- 제외어와 최종 주문은 후보 또는 판정에 들어가지 않는다.
- 모델이 잘못된 JSON·미관찰 단어·중복을 반환하면 서버가 거부한다.
- Ollama 장애에도 로컬 폴백으로 게임이 계속된다.
- `game_started`, 일반 HUD, 빙결 이벤트에 정확한 현재 금기어가 없다.
- 파이널 진입 후 세대가 바뀌지 않는다.
- 결과 화면에만 전체 변화 이력이 나타난다.

## 11. 성공 정의

플레이어가 한 판 뒤 다음과 같이 말하면 성공이다.

1. 처음에는 무엇이 위험한지 몰라 평소처럼 AI와 대화했다.
2. 얼어붙은 발화를 비교하며 내 말버릇 중 무엇이 금기어인지 추리했다.
3. 안전하다고 생각한 표현도 시간이 지나 다시 의심해야 했다.
4. AI가 어떤 단어를 피하는 모습을 보고 규칙을 눈치챘다.
5. 대화를 줄이면 안전하지만 협동이 느려져 계속 말할 이유가 있었다.

핵심 문장:

> **게임이 내 말을 배운다. 나는 게임이 무엇을 배웠는지 모른다.**
