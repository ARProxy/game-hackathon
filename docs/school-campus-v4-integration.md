# 학교 캠퍼스 v4 통합 기록

## 입력 패키지 판별

- `uploads/SchoolCampus.tsx`는 기존 게임의 `SchoolCampus.tsx`와 바이트 단위로 동일한 호환본이다.
- 실제 신규 맵은 `campus.js`에 있는 120×120m 절차형 생성기다.
- 생성 결과는 충돌 박스 2,388개, 장식 박스 6,921개, 평면 531개, 원기둥 865개, 방 83개, 문 100개, 조명기구 185개다.
- 패키지의 HTML은 설계 검토용 뷰어이므로 게임 런타임에는 포함하지 않는다.

## 이번 통합 범위

- 게임 월드 지오메트리를 캠퍼스 v4 생성 결과로 교체했다.
- 기존 서버 라운드 판정과 트랩 컴포넌트는 회귀 방지를 위해 유지했다.
- 인간·AI 동료 2명·술래의 서버 권위 스폰을 v4 1층 순환 복도로 이전했다.
- 시작 카메라를 인간 스폰 근처로 옮기고 복도 조명·환경광·안개 노출을 v4 규모에 맞췄다.
- v4 내부 스폰과 정문·후문·체육관·대강당·주차장 게이트 5개는 서버 벽 계약 이전과 동시에 활성화한다.

## 렌더링 기본 예산

- 같은 색과 형상의 박스·평면·원기둥은 `InstancedMesh` 한 번으로 그린다.
- 단위 지오메트리는 모듈 전역에서 공유하고 인스턴스 행렬만 다르게 쓴다.
- 작은 가구와 장식은 시각 전용이며, 바닥 슬래브와 긴 벽만 약 300개의 복합 충돌체로 만든다.
- 185개 조명기구는 발광 메시로 배칭하고 실제 `PointLight`는 최대 18개만 사용한다.
- 인스턴스 묶음마다 경계 구를 다시 계산해 Three.js 절두체 컬링이 동작하도록 한다.
- 그림자는 인스턴스 수가 작은 묶음에만 허용한다.

## 후속 계약 작업

- v4가 제공한 트랩·미션·프롭·델타 슬롯은 기존 서버 상태 머신과 ID가 다르다. 좌표만 섞으면 판정과 화면이 어긋나므로 별도 계약 마이그레이션으로 진행한다.
- 문 100개는 현재 시각 메시로 들어왔으며, 다음 단계에서 근접 문만 활성화하는 개폐 풀과 서버 상태 동기화를 붙인다.
- 패키지의 절차형 캔버스 텍스처는 월드 UV 셰이더 패치까지 포함한다. 빌드 안정성과 GPU 메모리를 계측한 뒤 재질군 단위로 적용한다.
