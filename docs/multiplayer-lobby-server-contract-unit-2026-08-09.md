# 멀티플레이 대기방·서버 계약 구현 단위

- 기준일: 2026-08-09
- 목표: 시작 화면의 멀티플레이 선택을 실제 서버 권위 방·준비·AI 충원 계약과 연결한다.

## 구현 계약

- 클라이언트가 생성한 6자리 초대 코드와 WebSocket 경로의 방 ID를 서버의 실제 방 ID로 통일했다.
- 닉네임은 서버에서 공백을 정규화하고 2~12자 및 금지 문자를 검증한다.
- 방 생성, 참가, 캐릭터 선택, 준비 상태는 모두 서버 응답의 방 스냅샷을 화면에 반영한다.
- 멀티플레이 시작은 인간 2명 이상, 전원 캐릭터 선택, 전원 준비, 방장 요청을 모두 만족해야 한다.
- 제출용 협동은 인간 2명+AI 동료 2명(`partner`, `partner-2`)의 총 도망자 4명으로 고정한다.
- 게임 시작 직전에 서버 세션의 불필요한 예약 AI를 제거해 대기방 표시와 실제 게임 인원을 일치시킨다.
- 배포 빌드에서는 타이틀 클릭 개발용 빠른 시작 진입을 숨겼다.
