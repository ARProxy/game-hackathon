# 옥상 기억 신호 입력 소유권 수정 단위

## 증상

플레이어가 옥상 신호 콘솔에서 E를 눌러도 미션이 안정적으로 진행되지 않고, 거절 안내와 정상 진행이 섞일 수 있었다. 점멸 순서를 놓치면 같은 라운드에서 다시 확인할 방법도 없었다.

## 원인

- 옥상 전용 입력 처리기가 `signal_id`를 포함한 정상 요청을 전송했다.
- 동시에 상위 공용 미션 처리기도 같은 E 입력을 받아 `signal_id` 없는 요청을 전송했다.
- 특히 중앙 콘솔은 공용 미션 좌표와 겹쳐 한 번의 E 입력이 두 WebSocket 요청으로 분기됐다.
- 옥상 컴포넌트를 반환하더라도 상위 컴포넌트의 Hook은 이미 실행되므로 공용 이벤트 리스너는 계속 살아 있었다.

## 수정

- 진행 단계가 `rooftop_intro`일 때 공용 E 입력 처리기를 즉시 종료한다.
- 옥상에서는 `RooftopSignalObjectives`가 E 입력을 독점한다.
- 옥상 전용 E/R 입력에서 같은 키 이벤트가 다른 전역 처리기로 전달되지 않도록 즉시 전파를 중단한다.
- `R` 키로 현재 라운드의 1→2→3 점멸을 처음부터 다시 재생한다.
- HUD에 `R · 점멸 순서 다시 보기`를 상시 표시한다.

## 검증

- 프로덕션 빌드 통과
- 린트 오류 0, 기존 경고만 유지
- 옥상 서버 좌표·완료 WebSocket 테스트 2개 통과
- 인앱 실제 게임에서 R 입력 후 `1번째 · 동쪽 신호` 점멸이 다시 시작되는 것을 확인
