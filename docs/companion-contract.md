# AI 동료 독립 목표 계약

> 기획 정본: `game-design.md`의 음성 협동과 `game-design-v2.md` 10장

## 핵심 규칙

- AI 동료의 목표와 위치는 서버가 판정하며 클라이언트는 표현과 짧은 이동 예측만 담당한다.
- 명령이 없을 때 플레이어를 공전하지 않고 현재 미션의 미확인 후보 구역을 독립 탐색한다.
- 자율 탐색은 후보 위치와 발견 사실만 보고한다. 정답 판별은 플레이어의 우회 설명과 후보 비교 결과가 있어야 시작한다.
- 목표 우선순위는 `즉시 포획 위험 회피 → 구조 요청/시간 경과 → 게이트 → 플레이어 지시 → 미확인 후보 탐색 → 보고 대기`다.
- 목표 상태는 `EXPLORE_ZONE`, `INSPECT_CANDIDATE`, `REPORT_FINDING`, `AVOID_SEEKER`, `RESCUE_TEAMMATE`, `REGROUP`, `MOVE_TO_GATE`, `ESCAPE`다.

## 기억과 피드백

- 서버는 발견한 프롭의 위치·구역·외형, 후보별 확신도와 매칭 단서, 마지막 술래 목격 위치·시간, 현재 명령, 구조 요청과 마지막 의도를 세션에 보관한다.
- 후보에 도착하면 구역·색·형태를 포함한 발견 보고를 한 번만 전송하고 다른 미확인 후보 탐색을 계속한다.
- 플레이어가 얼면 위치와 상태를 서버에서 직접 읽어 구조 목표로 전환한다. `E` 요청은 즉시 우선순위를 올리고, 요청이 없어도 5초 뒤 구조를 맡는다.
- 술래가 7m 안에서 벽 없이 보이면 현재 작업을 중단하고 반대 방향으로 회피한다.
- 술래 목격 위치는 4초 동안 위험 기억으로 사용하며, 시야를 잃어도 즉시 원래 작업으로 복귀하지 않고 팀에 마지막 위치를 보고한다.
- 일반 목표는 최소 1.5초 유지하며 회피·구조·게이트 같은 긴급 이벤트만 즉시 중단시킨다.
- 조사에는 3초가 필요하며 도착·시간·대상은 서버가 검증한다.

## 게임성 보호

- AI의 독립성은 자동 정답 해결을 의미하지 않는다. 탐색 결과와 인간의 위험한 음성 설명이 결합돼야 미션이 진행된다.
- 구조는 실제 이동을 요구하고 술래 회피가 더 높은 순간에는 지연될 수 있어 무료 성공이 아니다.

## P1 연결

- AI의 트랩·금기어 빙결, 인간의 AI 구조 상호작용과 AI 개별 탈출 결과는 `team-risk-contract.md`를 따른다.
