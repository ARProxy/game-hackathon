# 두 파이널 무교착 자동 플레이 검증

- 기준일: 2026-08-09
- 범위: 옥상 시작부터 운동장/지하 파이널 탈출 개방, 승리·부분 승리·패배 서버 결과

## 운동장 완주

1. 옥상 기억 신호 순서 완료
2. 모든 도망자의 실제 옥상 계단 하강과 옥상 폐쇄
3. 3층 후보 비교·물리 조사·정답 확인
4. 모든 도망자의 3층→2층 계단 통과
5. 2층 인터폰 AI 도착·기호 순서 전달
6. 모든 도망자의 2층→1층 계단 통과
7. 1층 CCTV 방향 관제·AI 체크포인트 이동·동시 장치
8. 모든 도망자의 1층→운동장 경계 통과
9. 인간과 두 AI의 서로 다른 최종 장치 집결
10. 추론형 주문 성공과 탈출 개방

## 지하 완주

운동장과 동일한 옥상→3층→2층→1층 전체 흐름을 반복한 뒤, 지하 계단 경계를 통과한다.

1. 인간이 배전반 명령을 발화하고 AI 1이 실제 위치에서 작동
2. 인간이 밸브 명령을 발화하고 AI 2가 실제 위치에서 작동
3. 인간이 발전기를 직접 작동
4. 올바른 순서 완료, 추론형 주문 성공, 지하 탈출구 개방

## 결과 계약

- 전원 탈출: `vertical_school_escape` 승리
- 인간만 탈출하고 AI가 탈락: `vertical_partial_escape` 부분 승리
- 술래 접촉 우선: `caught_by_seeker` 패배, 탈출 이벤트보다 포획이 우선
- 전원 빙결/인간 전원 제거: 패배 이벤트 중복 없이 한 번만 종료
- 잘못된 주문: 답을 노출하지 않고 큰 소리 핑과 재시도 유지
