# 서버 권위 일시정지 사고 흐름

클라이언트 렌더만 멈추면 서버 술래·AI·빙결 제한시간은 계속 진행된다. 따라서 일시정지는 서버 세션 상태이며 인간 플레이어의 `pause_game`·`resume_game` 요청으로만 전환한다. 정지 중 행동은 거부하고 술래·AI tick을 건너뛴다. 재개 시 빙결 시작 시각을 정지 시간만큼 이동해 남은 구조 시간을 보존한다.

클라이언트는 서버의 `game_paused` 승인 뒤에만 Rapier 물리, 이동, AI 표현, 카메라와 음성을 멈춘다. Esc 메뉴는 전체 음량·감도·자막 설정과 현재 실제 키 배치를 함께 보여준다. 데모 transport도 같은 이벤트를 내보내며 예약된 연출 타이머를 정지 중 반복 보류한다.
