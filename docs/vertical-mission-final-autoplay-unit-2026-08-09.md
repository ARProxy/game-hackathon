# 층별 미션·파이널 무교착 작업 기록

> 작업일: 2026-08-09  
> 작업 단위: AI 층 역할 유지, 협동 미션 정보, 술래 등장 연출, 파이널 자동 플레이  
> 상태: 구현·자동 검증 완료

## 문제

- 인간이 직전 층으로 잠시 돌아가면 활성 층의 AI까지 따라가 미션 장치와 정찰 위치를 비웠다.
- 운동장 AI의 스테이션 활성화가 음성 자막 전달 성공 여부에 묶여, 금기어 회피나 음성 억제 시 파이널이 영구 정지할 수 있었다.
- 인터폰·동시 장치·지하 상태 보고는 AI 음성이 억제되면 플레이어에게 준비 상태가 전달되지 않았다.
- 인터폰 정답 색·도형이 현재 금기어와 겹치면 플레이어가 정답을 말하는 순간 빙결되어 필수 미션이 불공정해질 수 있었다.
- AI 발화의 회피가 실패한 레거시 경로에서는 AI가 금기어로 빙결될 수 있어 v5 정본과 충돌했다.
- 단계가 바뀌어 술래가 실제로 등장해도 일반 층 이동 자막 외에 첫 등장·협공·광분의 사건 피드백이 부족했다.

## 구현

- AI가 현재 활성 층에서 협동 역할을 수행 중이면 인간의 직전 층 복귀를 따라가지 않고 위치를 유지한다.
- 인간이 다시 활성 층으로 내려오면 기존 층 이벤트를 정상 소비해 다음 단계 이동은 계속 수행한다.
- 운동장 스테이션 조작을 AI 음성 전달과 분리해, 자막·TTS 억제 여부와 무관하게 서버 행동을 완료한다.
- 인간이 AI에게 내린 행동 명령도 AI 응답 발화가 억제되어도 실제 목표 수행은 유지한다.
- 인터폰 도착, 1층 동시 장치 준비, 지하 장치 상태를 별도 서버 이벤트로 전파한다.
- 인터폰 정답 시퀀스는 현재 금기어와 겹치지 않는 색·도형에서만 생성한다.
- 동적 금기어 후보 보호 목록에 모든 인터폰 정답 어휘를 포함해 플레이 도중 충돌도 막는다.
- AI의 위험 발화는 모든 모드에서 발화만 폐기하며 금기어 빙결이나 비공개 단어 노출을 발생시키지 않는다.
- 3층 첫 실루엣, 2층 완전 추격, 1층 지하 충격음과 두 번째 실루엣, 파이널 광분을 `seeker_phase_event`로 전파한다.
- 클라이언트는 각 사건과 AI 준비·설비 상태를 자막으로 표시한다.

## 자동 플레이 계약

새 결정적 자동 플레이는 다음 전체 경로를 한 번에 통과한다.

1. 인간 중앙 + AI 동·서 옥상 신호
2. 전원 3층 하강과 옥상 폐쇄
3. 3층 의미 전달과 2층 개방
4. 2층 인터폰 AI 판독·인간 답변
5. 1층 인간 A + AI B 동시 조작
6. 전원 운동장 진입과 3인 스테이션 활성화
7. 최종 주문 성공과 `escape_open` 전환

지하 경로의 장치 순서·리셋·주문·개별 탈출은 기존 WebSocket 폐루프 테스트와 함께 유지된다.
