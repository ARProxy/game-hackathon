# 실제 월드 계약 기반 미니맵 재구축 작업 기록

> 작업일: 2026-08-09  
> 작업 단위: 실제 학교 구조·현재 목표·AI 위치를 반영하는 미니맵  
> 상태: 구현·자동·브라우저 검증 완료

## 사용자 관찰

- 미니맵이 현재 게임 월드와 전혀 연관 없어 보인다.
- 지도에 보이는 학교 형태와 실제 ㅁ자 건물 구조가 다르다.
- 미션이 어디에서 진행되는지 지도만으로 알 수 없다.

## 원인

1. 미니맵은 실제 맵 계약을 읽지 않고 과거 ㄷ자 구조의 좌표·사각형을 컴포넌트에 하드코딩했다.
2. 현재 미션 phase와 `verticalMapContract`의 의미 슬롯을 연결하지 않았다.
3. AI 표식은 시작 시 받은 `players` 좌표를 사용하지만 AI의 매 판단 틱 위치는 `companion_intent.partner_position`으로만 갱신된다.
4. 모든 층에 동일한 범위와 도식을 사용해 옥상·실내·지하·운동장의 차이가 사라졌다.

## 구현 결정

- F1~F3 방, 건물 외곽, 중정, 문은 `COMPACT_SCHOOL` 단일 정본에서 그린다.
- 옥상은 실제 외곽과 중정 보이드가 있는 ㅁ자 링으로 그린다.
- 지하와 운동장은 해당 월드 범위에 맞는 별도 view를 사용한다.
- 현재 phase, 활성 층, 플레이어 층으로 현재 미션 장치 또는 층 이동문을 결정해 목표 표식을 표시한다.
- 옥상에서는 서버가 알려 준 `nextSignalId`만 현재 목표로 표시한다.
- AI 위치는 같은 층 actor 상태와 최신 `companionIntents` 서버 좌표를 합성한다.
- 술래 위치는 실시간으로 표시하지 않는다. 탐색과 공포가 무력화되지 않도록 마지막 목격 정보도 이번 기본 지도에는 넣지 않는다.

## 완료 조건

- 지도 제목과 형상이 실제 ㅁ자 학교 계약과 일치한다.
- 각 실내층의 8개 방과 중정, 문 위치가 데이터에서 파생된다.
- 옥상 신호 진행, 층 미션, 다음 층 이동문, 최종 출구가 현재 상황에 맞게 표시된다.
- 두 AI 표식이 같은 층에서 실시간 서버 위치를 따라 움직인다.
- 술래의 실시간 위치는 노출되지 않는다.
- 맵 계약, 클라이언트 빌드·린트, 서버 전체 회귀 테스트가 통과한다.

## 기획 교차 감사

- 기획 2: AI의 실제 독립 동선을 지도에서도 확인할 수 있다.
- 기획 3·4: 렌더·충돌·미션 슬롯·미니맵이 동일한 학교 좌표 계약을 사용한다.
- 기획 5: 숨겨진 금기어와 술래 위치를 UI 편의 때문에 공개하지 않는다.
